# 怎样显示“朋克英语”来源署名

本版PDF每一页都有同一个默认关闭的图层：**来源署名｜朋克英语**。正常阅读时不显示；主动开启后，所有页面会显示“朋克英语”和文档编号。

## 方法一：在支持图层的阅读器中开启

1. 下载PDF，用Adobe Acrobat Reader或支持PDF图层的福昕阅读器桌面版打开。
2. 打开左侧的**图层**面板。若面板未显示，可在“视图／显示或隐藏／侧边面板（导航窗格）”中找到“图层”；各版本菜单位置可能不同。
3. 找到**来源署名｜朋克英语**，勾选它或点亮前面的眼睛图标。
4. 当前PDF的全部页面都会显示署名。再次关闭该图层即可恢复普通阅读。

浏览器或手机内置预览器可能没有图层开关。这时可以换用上述阅读器，或使用方法二。阅读器可能记住你主动开启的显示状态；正式下载文件本身的默认状态是关闭。

## 方法二：生成一个“显示署名”的副本

保留原文件不动，在安装了Python和PyMuPDF的电脑上，将本目录中的`reveal_attribution.py`和`provenance.py`放在一起，运行：

```bash
python -m pip install PyMuPDF==1.26.6
python reveal_attribution.py 原文件.pdf 显示署名副本.pdf
```

生成的副本将署名设为默认显示，便于在没有图层面板的阅读器中查看。它是验证用副本，文件校验值会与正式原文件不同。脚本禁止覆盖输入的原文件。

## 辅助核对信息

- 在“文件属性”中可查看创建者、主题和文档编号；自有小册子的作者栏也记录为“朋克英语”。参考素材保留原有作者字段，并额外记录整理发布来源。
- PDF内还嵌入XMP来源信息、源文件SHA-256及文档编号。`manifest.json`列出每份署名版的校验值，发布记录另核对GitHub附件的SHA-256。
- 署名图层、元数据及文件校验记录用于辅助溯源，不能单独证明原创，也不是不可删除的版权锁。
