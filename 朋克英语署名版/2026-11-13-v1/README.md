# 考研学人 · 朋克英语来源署名版

本版将本系列现有的178个相关PDF路径统一生成来源署名版，并新增已认可书封的单页PDF和带该封面的70篇合订本，共**180个PDF文件、177份不同内容的文档**。其中包括两种排序的70篇分册、7册合订本、整本合订PDF、目录、对照文本及相关参考资料。不是新增180篇文章。

每页都加入默认关闭的**来源署名｜朋克英语**图层。正常阅读的文字与页面像素已逐页核对，保持原样；开启后可看到署名及文档编号。原始参考资料保留已有作者字段，额外添加整理发布来源。

新合订本共**475页**：书封1页、目录7页、正文小册子467页。沿用用户指定的新顺序，目录显示页码、70处跳转和书签已随新增封面调整。

正式下载：[GitHub Release](https://github.com/alienalgorithm/postgraduate-vocabulary/releases/tag/punk-english-pdfs-2026.11.13-v1)。附件只含PDF或仅含PDF的ZIP：

- `PUNK-ENGLISH-70-STORIES.pdf`：475页新封面合订本。
- `70-PDF-BOOKLETS-PUNK-ENGLISH.zip`：新顺序的70份分篇小册子，文件名保持01—70及中英文标题。
- `ALL-PDFS-PUNK-ENGLISH.zip`：全部180份相关PDF署名版，按来源分类。
- `PUNK-ENGLISH-COVER.pdf`：已强化“考研重点词汇”的单页书封。

显示方法见[查看隐藏署名](查看隐藏署名.md)。需要对外分发时使用本版下载文件。此前版本与原始归档保留，便于追溯，未回写历史Git标签或旧Release。

`SOURCE-INVENTORY.json`记录原始PDF路径和Git对象；`manifest.json`记录全部输出、文档编号与SHA-256；`核验`目录保存逐文档、逐页验证结果。所有177份不同文档共2484页均验证默认显示不变、图层可主动开启。

后续制作的新PDF在交付前同样经过本目录`provenance.py`的署名处理与检查。署名和校验记录能辅助溯源，不能单独证明原创或保证不能被移除。
