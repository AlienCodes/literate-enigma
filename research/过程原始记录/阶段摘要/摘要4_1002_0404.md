2. Key Technical Concepts:
   - Speaker verification (SV) ensemble scoring:
     - Models: ReDimNet2-B6 (vb2+vox2+cnc2, lm; Interspeech 2026, MIT), 3D-Speaker ERes2NetV2 zh 200k, ERes2Net-base zh 200k; CAM++ zh_en as alternate.
     - Pipeline: silero-vad v4 (k2-fsa ONNX: x[1,512], h, c) speech-only extraction, with VAD padding 0 s.
     - Features: numpy Kaldi fbank (80 mel, povey window, preemph 0.97, 20 Hz–Nyquist, snip_edges, global mean norm); WeSpeaker models use scale 32768.
     - Inference: onnxruntime CPU with session.set_denormal_as_zero (fixes a 25x denormal slowdown).
   - Scoring and calibration:
     - AS-norm with top-100 against a cohort of 480 people (400 EN Speech Commands + 80 ZH).
     - Two-sided calibration: 0% = impostor 95th percentile; 100% = median of own held-out clips.
     - Duration-aware 100% standard (g50_short for 1.5 s and 3 s crops); uncapped pct_raw used for ranking.
     - natural_range (p10/p25/p90) and effective target max(85, min(99, p25)).
     - Judge signature → cached sentences are re-scored when the standard changes.
   - Metrics: EER, minDCF(0.01). Robustness measured in % units.
   - Model distribution: GitHub release sv-models-1 (prerelease, never clobbered). sha256 is pinned for all files; selftest vector for ReDimNet2. Mirrors ghfast.top / gh-proxy.com, plus hf-mirror for sherpa models.

     - V5 not public: GitHub main 48b1a01 (2026-08-18) has no v5; latest release 20250606v2pro.
     - V4 is fine-tunable via s2_train_v3_lora.py with lora_rank, pretrained gsv-v4-pretrained/s2Gv4.pth plus vocoder.pth.
