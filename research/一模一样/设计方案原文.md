# 「一模一样」 tier (internal key `identical`): final implementable spec

This spec merges the verified ideas from the three designs (search, model, perception) and applies both judges' corrections. Everything rejected by the judges is listed in §0.3 and must not be built.

Facts used throughout:
- **Measured on the teacher's data:** 1004 kept lines, 984 train and 20 val. 559 lines contain English, 2080 English words in total, which is 6.1 % of all syllables. 112 lines have no final punctuation. 20 questions. 15 sources. One real training run took 30.6 min.
- **Measured on the dev CPU (4 cores):**
  - full 3-model judge: 0.64–0.74 s per 5 s candidate;
  - eres2net-base-zh alone: 0.142 s;
  - F0: 21 ms; LTAS: 4 ms; speech_activity: 2 ms;
  - Viterbi over 300×6 candidates: 3 ms;
  - batching replica: 1004/1004 teacher lines give exactly 4 identical fragments.
- Every other time or VRAM figure in this spec is an **estimate**.

## 0. Decisions

### 0.1 Settled conflicts between the designs

| Topic | Decision |
|---|---|
| Name | Key `identical`, label 「一模一样」, placed after `perfect` in `QUALITY_ORDER`. |
| Default | `auto`, empty, `自动`, `none` or any unknown value resolves to `identical` on every VRAM tier (high/mid/low/none). |
| Web default | On every page load the generation radio and the new training radio 「训练方式」 are both set to `identical`. The web UI does not read `synth.quality` from config (it never did), so an old hand edit cannot silently downgrade her. |
| CLI default | With no `-q`, the CLI uses config `synth.quality`. `auto` or missing means `identical`. The exact legacy line written by v0.1.0–v0.1.3 is treated as `auto`. Any other explicit value is honoured, and the CLI prints a Chinese note saying so. |
| `similarity.target_pct: 99` | It is copied into every user config.yaml, so `identical` ignores it. Its targets are relative to her natural range. Only `synth.tiers.identical.*` overrides them. |
| Training | A training mode `identical` (default) and `standard`. Standard means the old training amount. The text front-end fix and the final-「，」 fix apply to both modes because they are data corrections. |
| Batch size in training | Probed, with spill detection. Epochs are scaled to keep the update count of the batch-4 deep plan: `ceil(E·b/4)`, capped (SoVITS ≤ 48, GPT ≤ 50). Save intervals scale the same way, so checkpoints sit at the same update positions. This is stated honestly: each clip is seen b/4 times more often, so the overfit risk rises, and selection over all checkpoints guards against it. |
| V4 | Optional, gated (files + `peft` + mid/high VRAM + download succeeds). It is a contender in selection only. It becomes the model for the **whole lecture** only if it measurably wins on her val (paired bootstrap P ≥ 0.9 and CER not worse; permanent rule 11). No per-sentence mixing of V4 (48 kHz) with v2ProPlus (32 kHz), because the bandwidth jumps would be audible and the 16 kHz judge cannot see them. |
| Per-sentence model choice | Only between two v2ProPlus checkpoints that tie in selection (same bandwidth). |
| Val set | Stays at 20. Coverage is added with 24 built-in text-only test sentences. |

### 0.2 Kept (verified)

1. text_lang/prompt_lang = 'zh' whenever the text contains any CJK character (bug fix for all tiers).
2. A mixed zh/en training text front end (VoiceTwin 1A), with a self-check and a fallback.
3. Final 「，」 for training lines without final punctuation.
4. A feature stamp that includes the front end and an audio signature.
5. Training batch probe with spill detection; step-down OOM ladder; 2-part feature extraction; GPT num_workers; trained-count audit; disk guard; measured GPU utilisation; per-phase timing.
6. Fresh/extend/skip run semantics. The previous model is kept as a competitor.
7. Deep selection in 3 stages (all checkpoints, all items, several seeds, final stage under identical conditions). Failures count as the worst score. Paired bootstrap. Speed recalibration. LOO calibration of the ranking weights. Reference audition.
8. Several candidates per real api_v2 request: N copies separated by `\n`, cut0, `batch_size=N`, speed 1.0001 to force per-fragment VITS, strict exact-zero split, self-check with a tolerance, OOM halving, B auto-tuned on measured candidates/s.
9. A producer thread plus a scoring cascade.
10. Reference bank + per-sentence shortlist (kind with chunk awareness, length, English share, paragraph position, measured prior). Arms: reference × aux {3,0} × top_k {15,5}, plus a CER-rescue preset.
11. Timbre term = consensus lower bound capped at her natural p90. Mixed CER (Paraformer for CJK, Whisper for English words, deletions + substitutions only).
12. Minimum budget + targets + plateau stop. Top-K store; redo continues the search; re-ranking without the GPU.
13. TwinProfile measured on the full sources. Pause measure-and-correct (still exact zeros). Per-sentence constant loudness gains. Floor-relative tail trim, scoring on delivered audio. Viterbi continuity within the gate class. Same-seed tempo refinement as an extra candidate. Prosody-contour features weighted only by measurement.

## 1. What the tier does, stage by stage

### 1.1 Data (in place; never re-slice; never touch clip ids or her 138 corrections)

**A. Read-only material audit** (`voicetwin/data/audit.py`), shown on the training page. Measured counts only:
- sources with `denoised=True` and with `separated=True` (from sources.json);
- train clips with `forced_cuts > 0`;
- lines without final punctuation;
- lines containing English, and their English word count;
- questions in train and in val;
- suspect rows.

If any training clip came from a denoised source, the page says so. Nothing is changed automatically.

**B. Training list export.** A saved text with no final mark gets 「，」 (zh) or `,` (en) instead of 「。」/`.`. The manifest is untouched.

**C. Mixed zh/en training front end** (§1.2 step 2). This is the largest verified gap: today 2080 English words are never trained.

**D. TwinProfile** (`twin_profile.json`). CPU only. Runs after prepare, after review save/confirm, and lazily at generation. It measures her habits from the cleaned full sources `raw/<sid>.wav` plus the clip records:
- pause distributions per punctuation class, aligned by DP;
- unbiased sentence pauses;
- prosody features per group;
- an expected-duration model;
- loudness spread;
- onset/offset decay;
- consecutive-unit deltas;
- inner-pause p97;
- LTAS (report only).

**E. Reference bank** (`refs_bank.json`, lazy WAVs). Built from all eligible confirmed train clips, with features and precise-judge embeddings. references.json and the other tiers are untouched.

### 1.2 Training (mode `identical`, the default)

1. **Export.** export train.list (with the 「，」 rule). Then decide the run state:
   - `fresh`: material, front end or audio changed. Archive the old run and record `previous_selected`.
   - `extend`: material unchanged and the planned epochs exceed the last run. Resume to the new epochs; the old checkpoints stay candidates.
   - `skip`: material unchanged and already trained with the same plan. Go straight to selection.
2. **Features.** Run 1A as the VoiceTwin mixed runner, falling back to official 1A. Then 1B, SV and 1C, each as **2 parallel parts** on GPU 0 (1 part on low/CPU). Merge the outputs.
3. **Batch probe.** Run the official scripts on the 128 longest clips:
   - SoVITS candidates {4,5,6,8}, GPT candidates {4,6,8,12}, each capped at N/4;
   - choose the batch with the highest measured samples/s whose peak memory.used ≤ total − 0.3 GB, with no OOM and a throughput gain ≥ 5 %;
   - stop at the first OOM or spill.
   If the probe fails, use today's formula.
4. **SoVITS.** At batch 4: 24 epochs, saving every 2. With a probed batch b: `ceil(24·b/4)` epochs (≤ 48), saving every `max(1, round(2·b/4))`. On OOM, step down one batch size at a time (at most 3 retries).
5. **GPT.** At batch 4: 20 epochs, saving every 1. With b: `ceil(20·b/4)` (≤ 50), saving every `max(1, round(b/4))`. `num_workers = clamp(cpu_count−2, 2, 8)`. OOM ladder as for SoVITS.
6. **Optional V4 LoRA** (gated; §2 P9).
7. **Trained-count audit.** Count the files and rows actually produced and parse the s2/s1 logs. Measured result: 「实际参加训练：音色 X 条、语气 Y 条（共 N 条）」. Warn if either is below 98 %. Report English phones trained (ARPAbet token count).
8. **Measured bookkeeping:** nvidia-smi peak memory and average utilisation, seconds per phase and per epoch, weight file sizes (disk guard).

### 1.3 Picking the best model (deep selection; automatic after training and on 「重新挑选最佳模型」)

**Items.** The 20 val clips (with real recordings; still the 100 % calibration anchor) plus 24 built-in test texts with no recording: 8 questions, 8 Chinese sentences with English examples, 8 long sentences of 40 or more syllables.

**Stages.**
- **Stage A (GPT screen):** SoVITS fixed at the epoch nearest the middle of the run. Every GPT checkpoint with epoch ≥ 4 × 44 items × one request of B=2. Keep the top 3.
- **Stage B (SoVITS screen):** the best GPT × every SoVITS checkpoint with epoch ≥ 4 (plus V4 SoVITS if trained) × 44 × B=2. Keep the top 3.
- **Stage C (final, under 一模一样 generation conditions):** 3×3 combos + `previous_selected` + the best V4 combo (if any).
  - Per item: 2 shortlisted bank references (excluding the item's own clip and identical text) × 4 candidates, aux 3, preset P0.
  - The production judge picks one candidate without seeing the ground truth.
  - That pick is then scored against the truth.

**Scores.**
- Per val item: `S = T + R_real − 3·CER − 0.8·|ln(voiced_gen/voiced_real)| − 0.3·(1 − r_F0)`.
- Per test text: `S = T − 3·CER − 0.8·|ln(voiced_gen/expected)|`.
- A failed synthesis gives S = −3.0.
- Stage A uses a CER weight of 4. Stage B uses a T weight of 1.5.

**Decision.**
- Paired bootstrap over items (2000 resamples). If P(best > 2nd) < 0.8, keep both as `two_checkpoints` (v2ProPlus family only).
- The old model stays selected if it ranks first.
- V4 is selected only if P(V4 best > v2PP best) ≥ 0.9 and mean CER ≤ v2PP + 0.01.

**Afterwards.**
- Speed recalibration from the winner's val items.
- LOO calibration of the ranking weights on the stage-C candidates.
- Reference audition with the winner.
- Everything is stored in `models.json[gptsovits]["identical"]`.
- If deep selection throws (other than a cancel), the standard 4×3 selection runs, so a selection always exists.

### 1.4 Preparation at generation time (stage 「准备「一模一样」」)

This runs only when the item is missing or stale:
- twin_profile;
- reference bank;
- the `identical` block.

A missing or stale `identical` block happens with models trained by older versions or with standard mode. In that case a mini-calibration runs on the **selected** checkpoint: stage C on that one checkpoint over the 20 val items, giving speed, weights and the reference audition. Old models therefore get 一模一样 generation without retraining.

### 1.5 Reference choice per sentence

1. `kind_eff` is `seg.kind` only for the **final** chunk of a long sentence; earlier chunks use `statement`.
2. Score every bank reference:
   `match = 1.2·[kind==kind_eff] − 1.0·|ln((syl_ref+1)/(syl_seg+1))| − 1.5·|en_ref − en_seg| + 0.3·[para_initial_ref == para_initial_seg] + 1.0·prior_z − 0.3·[max inner pause of ref > 0.9 s]`
   - `prior_z` is the audition prior's z-score shrunk 50 % toward the base-score z. With no audition, it is the base-score z.
   - Exclude references whose normalised text equals the sentence.
3. Greedy diverse pick of R references:
   - take the best;
   - then the best from a different source with match ≥ top − 1.0;
   - then the next best.
   - If `en_seg ≥ 0.15`, make sure at least one reference has `en_ref ≥ 0.15` when one exists.
4. A user-forced reference (UI) overrides the shortlist.
5. Aux set for main reference r: the top-3 bank references by prior_z with the same language, kind statement, a different source, 4.0–9.8 s, and id ≠ r.
6. prompt_lang = 'zh' if the reference text contains CJK, else 'en'. prompt_text is the saved manifest text.

| Field | Value |
|---|---|
| Presets | P0 = {T 1.0, top_k 15, top_p 1.0} (abe9843 default). P1 = {T 1.0, top_k 5, top_p 1.0} (20250606v2pro default). P2 (rescue only) = {T 0.6, top_k 15, top_p 0.8}. |
| Fixed | repetition_penalty 1.35. text_split_method cut0. parallel_infer True. sample_steps / super_sampling sent but ignored by v2ProPlus. |

| B start | high 12, mid 8, low 2, none 1. |
| B auto-tune | The first 6 requests alternate B0/2 and B0. Keep the larger B only if its measured candidates/s is ≥ 1.05× the smaller one's (catches Windows spill). |
| B on OOM | Halve B down to 1. Then free the ASR GPU memory and retry once at B=1. Then use the existing fatal path. |

### 1.7 Search budget and stopping (per sentence)

**Phase 1 (explore).** One request per arm, grouped by reference for prompt-cache reuse:

| Machine | Arms |
|---|---|
| mid/high | A1 (r1,P0,aux3), A2 (r1,P1,aux3), A3 (r1,P0,aux0), A4 (r2,P0,aux3), A5 (r2,P1,aux3), A6 (r3,P0,aux3) |
| low (R=2) | A1–A5 |
| CPU | A1, A2, A4 |

Arms that become identical when aux is unsupported (dummy) are de-duplicated.

**Extra arms.**
- If no fully scored phase-1 candidate passes `cer_retry_threshold`: add (r1,P2,aux3) and (r2,P2,aux3).
- If the median of `voiced_gen/(expected/mult)` over fully scored candidates is off by more than 8 %: add a speed arm (best arm, speed × clip(ratio, 0.9, 1.1)).

**Phase 2.** The top-2 arms by arm score (mean of the arm's top-2 full totals), 1 request each.

**Phase 3.** The best arm, one request at a time.

**Stop** when either holds:
- (i) candidates ≥ `min_candidates`, the best meets the **search target** (CER pass and consensus r ≥ natural p50 = 100), and the best total improved by less than 0.02 over the last 8 candidates;
- (ii) candidates ≥ `max_candidates`.

Give up only if 2 consecutive requests returned nothing and there are no candidates.

| | high/mid | low | CPU |
|---|---|---|---|
| min / max candidates | 40 / 64 | 16 / 32 | 6 / 12 |

**Tempo refinement.** After stopping, for the best candidate (and the runner-up if within 0.02): if `|ln(voiced_gen/(expected/mult))| > max(0.03, 0.5·σ_resid)`, resend **the identical request** (same copies, B, seed, references, aux, sampling) with only `speed' = speed × clip(ratio, 0.88, 1.12)`, and take the same row.
- Tag it `refined` if `|voiced_new·speed'/speed − voiced_old|/voiced_old ≤ 4 %`; otherwise it is an ordinary candidate.
- It is scored like any candidate.

**Seeds.** Request j uses `base_seed + idx·7919 + j·104729`, plus a random offset on redo. Candidate id = (seed, row).

### 1.8 Ranking and gates

**Cascade.**
- **Quick stage** (every candidate):
  - voiced/expected must be in [0.6, 1.6];
  - no inner pause > max(1.2, her inner-pause p97);
  - not near-silent;
  - one member (eres2net-base-zh) pct_raw.
  - `quick = 2.0·min(q_pct, cap)/100 − 0.4·dur_dev`.
- **Full stage:** a candidate is fully scored if its quick total is within the current top 12, or it is the best of its arm, up to 24 per sentence. Full scoring = all 3 members (reusing the VAD-prepared speech) + F0 + mixed CER.

**Full total.**
- `T = 2.0·min(pct_raw − 0.5·spread, natural_p90)/100` in precise mode. In fallback mode the term is today's.
- `− 1.0·CER`
- `− 0.4·dur_dev`, where `dur_dev = |ln(voiced_gen/(expected/mult))|`
- `− 0.2·pitch_dev` (as today)
- `− w_pros·prosody_z` (default 0; calibrated)
- `− w_ltas·ltas_d` (default 0; calibrated)
- the issue penalties as today, with the long-pause threshold set to her p97.

**Reported `met`** requires all of:
- CER: errors == 0 or cer ≤ `cer_target` (strong 0.03 / weak 0.06);
- consensus pct ≥ natural p25;
- every member pct ≥ that member's natural p10;
- `in_normal_range`;
- duration z within ±2;
- not near-silent.

In fallback mode it uses 99 one-sided, as 完美 does.

**Pick.** `max(cer_ok, met, total)`. Near-ties (Δ ≤ 0.02) are broken by the non-timbre part (duration + prosody + accuracy). Then the document-level Viterbi pass (§1.9) can swap within the same gate class.

**Stored per sentence:** the top-6 candidates (FLAC + features + embeddings). Redo appends a new search, and the stored candidates compete, so the best total never drops. A change of judge, profile or weights re-ranks the stored candidates with no GPU.

**Two-checkpoint pass B.** If selection kept two checkpoints: pass A runs the full search with checkpoint 1. Pass B runs checkpoint 2 with the 2 best arms × 1 request × B for every sentence. Each sentence picks across both, with 2 weight switches per document.

### 1.9 Assembly (exact digital silence)

1. **Edge trim.** Threshold = `max(speech95 − 45, noise3 + 12, −70)`, capped at `speech95 − 15`. Lead pad 30 ms. Tail pad = clip(her median offset decay, 30, 120) ms. First and last samples are 0. Scoring uses this delivered audio, padded with 0.3 s of zeros on each side for analysis only.
2. **Viterbi continuity.**
   - States: the stored candidates in each sentence's best gate class.
   - Node score: the full total.
   - Edge cost: `0.03 · Σ_f min(((Δ_f − μ_f,type)/σ_f,type)², 9)` for f ∈ {F0 median in semitones, log rate, mean timbre cosine distance}, with type ∈ {clause, sentence, paragraph} taken from her consecutive units.
   - On redo, only the redone sentences are free.
3. **Pauses.**
   - Target = inverse CDF of her measured distribution at u ~ U(0.2, 0.8), with `random.Random(base_seed+i)`.
   - Classes: `clause` (between chunks of one sentence) uses her comma distribution; `sentence` uses all sentence-end pauses re-measured on the sources; `paragraph` uses u ∈ [0.85, 0.97] of the sentence distribution.
   - Explicit `[停顿=x]` is kept. The pause is divided by the speed multiplier as today. With n < 8 measurements it falls back to today's `_pause`.
   - Then **measure and correct**: render, detect each inter-sentence gap with the same detector that measured her, shift the following starts by `clamp(target − measured, ±0.15 s)` (gap ≥ 0.08 s), re-render. Two passes. Timed (SRT) mode is unchanged.
4. **Loudness.**
   - `d_i` = speech loudness of sentence i minus the median over sentences.
   - Shrink by `min(1, σ_her/σ_gen)`, clamp to her p05..p95, and apply as a constant per-sentence gain.
   - Compute the global gain to `profile.loudness.source_lufs`.
   - A sentence that would peak above −1 dBFS gets its own gain lowered. There is no limiter and no whole-file scaling.
   - The final LUFS is measured and reported.
5. **Render** into an all-zero buffer as today (`_render`). Everything between sentences is exact zeros.
6. **Variants.**
   - A = raw.
   - B = `denoise_light` **only for sentences whose in-speech floor** (p10 of frame dB in the voiced region) is > −60 dBFS; other sentences are identical to A.
   - Recommendation = duration-weighted mean full total without ASR; a tie goes to raw.
7. **Output.** WAV PCM16 (MP3 keeps today's warning), SRT, and report.json with a `search` block. The summary contains only measured numbers.

### P3. Her measured habits and the reference bank (CPU only)

**New `voicetwin/style/twin_profile.py`** (`TWIN_PROFILE_VERSION = 1`)
- `source_gaps(wav, sr) -> List[(start, end)]`: frame_rms_db with hop 10 ms and window 40 ms, `auto_silence_threshold`, minimum silent run 12 frames (120 ms).
- `align_pauses(text, clip_pauses) -> List[(mark_class, dur)] + hesitations`:
  - a Needleman–Wunsch DP between mark positions `frac = syllables_before / syllables` and pause positions `frac = (pause_center − voiced_start)/voiced_span`;
  - skip cost 0.08 on each side; a match is accepted when |Δfrac| ≤ 0.12.
- `clip_features(wav, sr, text)`, using `f0_track` frames with times:
  - `f0_med_st` (vs her global median);
  - `f0_range_st` (p90 − p10);
  - `decl_slope` (st/s, linear fit over voiced frames);
  - `final_slope` (last 300 ms voiced, st/s);
  - `energy_range_db` (p90 − p10 voiced);
  - `onset_ms` and `offset_ms` (from 30 dB below peak to the floor);
  - `ltas22` (one-third octaves 100 Hz–12.7 kHz after resampling to 32 kHz).
- `build_twin_profile(project) -> dict`, written atomically to `workspace/<voice>/twin_profile.json`:
  - `pauses`: classes `comma`（，,）, `enum`（、）, `colon_semi`（：；:;）, `sentence` (inner sentence ends and clip-final gaps pooled, re-measured on `raw/<sid>.wav` from the clip `start/end`), `hesitation` (per 100 syllables + durations). Each has quantiles p05…p95, n, and P(pause|mark).
  - `inner_pause_p97`.
  - `prosody`: groups kind {statement, question} × en-share bins {<0.10, 0.10–0.30, ≥0.30}, with mean/sd per feature and n. Fallbacks when n < 8: question → statement (except `final_slope`), bin → all.
  - `duration_model`: NNLS `voiced_s ≈ e + a·n_cjk + b·en_syllables + c·n_digits + d·n_clause_punct` over kept clips, with `r2`, `resid_sd_log`, `n`, and `ok = n ≥ 50 and r2 ≥ 0.3`; otherwise the global rate is used.
  - `loudness`: per-clip speech loudness minus its source median: sd, p05, p95.
  - `edges`: median onset/offset ms, `breath_fraction` (recorded only).
  - `deltas`: consecutive same-source units with gap < 2 s, by type {sentence, clause}: mean/sd of Δf0_med_st and Δlog_rate. The `timbre` field is filled by the bank builder.
  - `ltas`: per-band mean and sd.
  - `source`: `"raw"` | `"clips"` (fallback when `raw/<sid>.wav` is missing).
  - `signature = sha1(_manifest_sig + saved texts + version)`.
  - Every statistic carries its n. If n < 8, the value is `null`.
- Called after `build_profile` in `workflows.py` (prepare ~L443, review save/confirm ~L528, profile ~L748) and lazily by the identical preparation.

**`data/references.py`: add `build_reference_bank(project, records, judge=None) -> List[dict]`**
- Eligibility: keep, split train, not deleted, saved text, lang zh/en, `forced_cuts == 0`, raw 3.0–11.0 s, `ends_sentence` (every question clip qualifies).
- After `trim_silence(pad_ms=80)` the clip must be 3.2–9.8 s (api limit 3–10 s at 16 kHz).
- Features: `syllables`, `en_ratio` (Latin syllables / all), `kind`, `rate`, `dur`, `source`, `start`, `gap_before`, `para_initial` (gap_before ≥ her sentence-pause p85), `max_pause`, `base` (`_score`), `f0_med`, `self_pct`.
- Precise embeddings are cached in `cache/bank_emb.npz`, keyed by id + file size + mtime.
- `bank_sig = sha1(sorted id|text)`.
- WAVs go to `references/bank/<id>.wav`, written lazily on first use with `atomic.tmp_for/finish`.
- Old bank files are deleted only during prepare.
- `references.json` is untouched.
- The bank builder also fills `twin_profile.deltas.timbre` (cosine distances of consecutive units).

  - `r_F0` via `librosa.sequence.dtw` on 20 MFCCs (10 ms hop), Pearson r of semitone F0 along the path, omitted when fewer than 20 aligned voiced frames;
  - the bootstrap (`_paired_bootstrap(a, b, n=2000, seed=1234) -> P`);
  - V4 gate;
  - speed: the median of `voiced_gen/voiced_real` over the winner's val items (≥ 8, else 1.0), clip(0.8, 1.25), deadband 0.03, written to both `speed` and `identical.speed`;
  - results per model as mean ± SE, n_items, n_seeds, val/test sub-means;
  - `info["selected"]` = the winner. It applies to all tiers (it is the best measured model).
- `audition_references(cfg, project, backend, sim, items, bank)`:
  - the top-24 bank references by base score (at most 3 per source) × 6 spread val items (excluding each reference's own clip) × 1 request B=4 (P0, aux 3);
  - `truth = R_real − 2·CER − 0.8·|ln dur ratio|`; `prior = mean over items of best-of-4 truth`;
  - skipped when val has fewer than 6 items.
- `prepare_identical(cfg, project, backend, progress)` (called by the Narrator): build or refresh twin_profile and the bank. If the `identical` block is missing or stale (`run_stamp`/`selected` changed), run stage C on the selected checkpoint only + calibration + audition.

**New `voicetwin/synth/calibrate_rank.py`** (numpy/scipy only)
- `calibrate(cands_by_group) -> {weights, version, gain, adopted}`.
- truth = `z(R_real) − z(F0-DTW RMSE in semitones) − z(|ln dur ratio|)`.
- Grid: `w_rate ∈ {0.2, 0.4, 0.8}`, `w_pros ∈ {0, 0.15, 0.3}`, `w_ltas ∈ {0, 0.04}`, `cap ∈ {p90, none}`.
- Objective: mean within-group Spearman, leave-one-item-out.
- Adopt only if the mean LOO gain over the defaults is ≥ 0.05.

## 8. Risks and fallbacks

| Risk | Fallback / mitigation |
|---|---|
| OOM in api_v2 with a big B | Halve B to 1; free the ASR GPU memory and retry once; then the existing fatal path with the Chinese 显存不够 explanation. The session remembers `max_ok_batch`. |
| Windows VRAM spill (slowdown, not OOM) | B auto-tune keeps a larger B only at ≥ 1.05× candidates/s. The training probe watches peak memory and throughput. |
| Split ambiguity (internal digital-silence run ≥ 0.3 s, merged short texts) | Strict count check and replica; fall back to single requests; counted in the report. |
| Self-check flakiness (cuDNN nondeterminism) | Tolerance (length ≤ 1 %, r ≥ 0.99), 2 seeds. A failure only disables batching at speed 1.0. |
| Producer thread errors | The exception is forwarded through the queue and re-raised with the same message. Cancel stops both threads and cleans up tmp files. |
| Winner's curse (max of noisy scores) | Consensus LCB, cap at her p90, min + plateau stop, near-tie broken by non-timbre cues. The summary states that the score is optimistic. |
| The same 20 val clips used for selection, audition and calibration (optimistic bias) | Shrinkage of the prior, LOO with a 0.05 margin, bootstrap. Stated in models.json and the UI. |
| Precise judge models not installed | One-sided fallback as today (no cap/LCB/member floor, target 99), with a Chinese note that the judge is limited. |
| Mixed 1A fails on her bundle | Official 1A fallback, reason shown, retried next time without forcing a fresh run unless it succeeds. |
| Late epochs overfit (more passes at a larger batch) | Every saved checkpoint (epoch ≥ 4) is evaluated; early checkpoints and the old model stay candidates. |
| Deep selection fails mid-way | Resumable cache; on error the standard 4×3 selection runs, so the training never shows as failed. |
| Disk full from dense saving | Disk guard doubles the save interval with the measured MB. Candidate store failure is non-fatal (K=1). |
| V4 anything (download, peft, OOM, bundle mismatch) | Skip with a reason; v2ProPlus results stay. Switched only on a clear measured win (rule 11), whole lecture only. |
| Style jumps between sentences from more reference variety | Viterbi continuity relative to her own measured deltas, within the gate class. |
| Soft-tail trim keeping vocoder hiss | Floor-relative threshold (noise3 + 12 dB); CER/duration checks; silence between sentences guaranteed by `_render`. |
| Pause correction failure | Keep the uncorrected layout and log it. Sentences never overlap (gap ≥ 0.08 s). |
| twin_profile, bank or audition missing or stale | Lazy preparation stage; each missing measurement falls back to 完美's behaviour for that piece, with 「没测出来」. |
| Very slow default on weak or CPU machines | Smaller caps, no pipeline on CPU, ETA projected from measured speed, the suggestion 「着急可以改选「均衡」」. Nothing is blocked. |
| Old hand-edited config `quality: X` | Honoured by the CLI with a note. The web always starts at 一模一样. The exact legacy default line is treated as auto. |
| Exact digital silence | All assembly steps are placement into a zero buffer, per-sentence constant gains, and fades inside segments. Denoise only changes the inside of sentences. Tests assert exact zeros in both variants. MP3 keeps today's warning. |
