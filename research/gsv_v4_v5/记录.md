# GPT-SoVITS V4 / V5：老师要求"用最好的模型"的调研记录

## 老师的要求（2026-10-01）

老师看了官方 wiki《GPT‐SoVITS‐features(Latest‐Including‐v5)》，要求"就用最好的模型，现在就要用 V5"，
并说明讲课录音基本是录音棚音质：没有杂音，只有老师的声音，句子之间完全静音。

## 官方说明的要点（wiki 原文）

- v5：基于 v4，SoVITS 扩散模型用同款 5k 小时训练集精致蒸馏，大幅提升音色相似度；新版声码器大幅降低高频混叠。
  SeedTTS 中文测试集 SIM：v4 0.735，v5turbo 0.782，v5dev 0.805（真人互比 GT 0.755）——这是**零样本**（不微调）的成绩。
- 路线选择：V2Pro(Plus) VITS 路线适合音质一般的训练集；**V4/V5 diffusion 路线适合高音质训练集**，更忠实于参考音频，
  高音质下合成音质上限更高。
- "V4 版本的 SoVITS 可供用户微调，微调场景下音色相似度和 V5 不会有多少区别"；
  "V5 版本的 SoVITS，Zero Shot TTS 音色相似度最高"；"基于 v5 版本的少量样本微调暂未进行研究和实验"。
- v4、v5 声码器可以混用，v5 声码器效果无脑高于 v4。
- 模型版本对应：v4 = v3 的 GPT + v4 的 SoVITS（diffusion）；v2Pro/v2ProPlus 也用 v3 的 GPT；v5 = v3 的 GPT + v5 的 SoVITS。
  同属 v2 音素的 GPT 和 SoVITS 可以混搭（底模和微调后的模型都适用）。

## 现在能做的：V4 微调（官方说微调后和 V5 相似度差不多）

老师装的 `20250606v2pro` 整合包本身支持 V4 训练（`webui.py` 的版本选项有 v4）：
- 预训练模型：`GPT_SoVITS/pretrained_models/gsv-v4-pretrained/s2Gv4.pth` 和 `vocoder.pth`（Hugging Face lj1995/GPT-SoVITS，需要下载）；
  GPT 用 `s1v3.ckpt`（和 v2Pro 一样，已有）；v3/v4 不需要 s2D（判别器）。
- 数据准备：和 v2 一样（文本、hubert 32k、语义 token），不需要 v2Pro 的 SV 特征。
- SoVITS 训练：`GPT_SoVITS/s2_train_v3_lora.py --config`（配置用 `s2.json`，`train.lora_rank` 默认 32，可选 16/32/64/128）；
  默认 2 轮、最多 16 轮（官方注释："训太多=作死"）；每批数量默认 显存 GB // 8（比 v2 的 //2 小很多）。
- 权重保存到 `SoVITS_weights_v4` / `GPT_weights_v4`。
- 推理：`tts_infer.yaml` 的 v4 配置（`vits_weights_path` 指向 v4 权重），diffusion 推理比 v2 慢，有采样步数参数。
