## 一、10-01 03:43 — 第一条要求：做一个完美复刻我声音的程序（→ v0.1.0）

**03:43 老师 #1**：嗓子哑了没法录课，有以前录好的视频和音频；要一个程序**完美复刻我的音色、语气、节奏**，只要中文和英文；
"不论从全网调用资源还是你自己去造"，用尽所有手段；**做好的程序要及时上传到 GitHub，要及时保存**。

**做了什么（03:44 – 04:36）**
- 03:44 先把三个候选的开源声音克隆项目的源码拉下来读：GPT-SoVITS、Qwen3-TTS、index-tts（读训练和推理的接口）。
  - ❌ 失败：拉代码时有一部分下载被网络代理拦了（`curl: (56) CONNECT tunnel failed, response 403`，报错 E1）。
    原因：开发机的网络只允许部分网站。解决：改用 `git clone`（允许），够读源码。
- 选型：**GPT-SoVITS v2Pro 微调为主引擎**（用老师的录音训练专属模型，最像本人）；Qwen3-TTS、IndexTTS 2.5 零样本克隆作为备选；
  dummy 引擎给测试用。理由写在 `开发记录.md`。
- 03:58 第一批代码推送到 GitHub（项目骨架、配置、音频 / 文字工具、切片、字幕）。之后每写完一块就推送一次：
  - 04:04 素材处理流水线：语音识别、降噪、按停顿 / 字幕切片、过滤不是本人的片段、挑参考音频、风格分析、打分
  - 04:10 引擎：GPT-SoVITS 训练 + api_v2 推理、Qwen3-TTS、IndexTTS2.5、dummy；独立 Python 环境之间用 JSON 行协议通信
  - 04:16 生成引擎：讲稿解析、每句生成多次挑最像的、按你的习惯停顿、缓存和只重做某几句、字幕 SRT；自动挑模型版本、语速校准
  - 04:18 命令行和工作流；04:22 中文网页界面（gradio）；04:25 测试；04:29 Windows / Linux 安装程序；04:32 预训练模型下载；04:35 中文 README 和 CI

**测试和结果**
- 04:23 单元测试 16 个通过、端到端 7 个通过、模拟 GPT-SoVITS 集成测试 2 个通过；04:35 全部 **28 个测试通过**。
- 用模拟声音跑通整条流程；声纹模型能把混在素材里的别人的声音挑出来剔除；安装脚本在干净环境里跑通。

**失败、原因、解决**
- 04:20 E2：重启网页测试时 shell 自己被杀掉（退出码 144）。原因：用 `pkill -f` 按命令行匹配进程，匹配到了自己。
  解决：改用 pid 文件、只 `kill <pid>`。**这个错误后来又犯了 3 次（04:54、10:16、10-02 00:42），之后写成了硬规定。**
- 04:28 E3：一次写多个安装脚本时，Python 里嵌套的三引号字符串没闭合（语法错误）。解决：改用写文件工具逐个写。
- 04:30 E4：探测 hf-mirror、ModelScope 能不能访问——都被拦（403）。结论：**开发机下载不了真实模型，真实训练没法在这里测**，如实告诉老师。
- 测试副作用：模拟测试往系统 Python 里写了 `users.pth`。解决：测试里改成假函数，并删掉那个文件。
- 发现 gradio 的 `SelectData` 类型注解在 `from __future__ import annotations` 下会失效 → 网页代码里去掉这一行。

**发布**
- 04:36 建 PR #2（草稿）；04:44 CI 的 8 项检查全部通过，合并进 master（老师 #2 要求"成为主程序"）。

  - **移动 GPT-SoVITS 文件夹或换电脑后，程序会悄悄改用没训练过的底模**（声音变得不像）→ 加 `_locate_weight` 按文件名重新找回训练好的模型，有测试。

- ❌ 06:13 E6：PDF 里"一、生、用、长"等常用字**搜索和复制出错**（变成 ⼀ ⽣ ⽤ ⻓ 这类"部首"字符）。原因：字体的字符映射表把这些字映射到了康熙部首码位。

- ❌ 06:16 E7：开发机没有 `pdftoppm`（把 PDF 页面转成图片检查用）。解决：改用 Python 库渲染检查。

- ❌ 截图裁剪位置偏了：元素坐标是相对滚动后的窗口算的 → 截图前先滚到顶部。
- ❌ 字体文件从 raw.githubusercontent 下载被拦 → 改用 git 稀疏克隆 notofonts/noto-cjk。
- 05:40 加评估测试时 1 个失败（误报停顿），修好后 32 通过；06:27 全部 **33 通过、1 跳过**。
