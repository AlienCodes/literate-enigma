# 随机操作脚本（文字校正）

用程序自带的母本随机挑几句、按对照表随机改错几个字，再随机点按钮（一键校正、采用、撤销、自己改、撤销这一行、这句没错、
查找替换、撤销替换、自动查错字、保存、上传母本……），每一步以后检查有没有出问题。

| 脚本 | 检查什么 |
|---|---|
| `fuzz6_随机操作.py` | 老师撤销过的不再改回来、老师自己改的不被改掉、没有出错（第四次检查以后写的） |
| `fuzz7b_对比.py` | 第五次检查的人写的「对比」：同一个状态走两条路结果必须一样（自己下载的文字当母本上传 = 不上传；连点两次 = 点一次；保存前后显示一样） |
| `fuzz8_对比_真按钮.py` | 在上面的基础上，采用 / 撤销用真正的按钮点：采用再撤销 = 原样、撤销再采用 = 原样，并且记下程序「拒绝改」的次数 |

用法（要 pypinyin 和 jieba，和整合包一样）：`python fuzz8_对比_真按钮.py 种子 步数`，例如 `python fuzz8_对比_真按钮.py 2 40`。
最后一行 `seed 2 problems 0 refused 0` = 没有问题、没有拒绝。结果见 `结果.txt`。
