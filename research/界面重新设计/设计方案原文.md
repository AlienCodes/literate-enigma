## Part A　给老师看的说明

### 一句话
以后网页就是一条路：**① 准备素材 → ② 校对文字 → ③ 训练模型 → ④ 生成讲课音频**。
最上面有一条「步骤条」，告诉你每一步的情况：做完了是 ✅，现在该做的是 👉，正在做的是 🔄，还不能做的是 🔒。旁边有一个「去做这一步 →」按钮。
每一页只有一个最显眼的大按钮。要选的东西都已经替你选好了最好的（⭐），不选也可以；想换的话点一下就换。
**你要过的功能一个都没有删，只是换了位置。**

### 打开网页时
- 最上面一行：「🎙️ 声音分身 VoiceTwin v18」（v18 永远不变），右边是圆角长方形的模型型号小框（还是从模型文件里检测出来的），再右边是一行显卡状态。绿色表示正常；红色时会写「原因」和「怎么办」。
- 「现在用的声音」：只能从已有的声音里选，不能直接打字，所以打错一个字也不会悄悄多出一个空的声音。要做新的声音，点「➕ 新建声音」→ 写名字 → 点「✔ 建好」。如果名字和已有的很像，电脑会先问你一句。
- 「🎙️ 我的声音库（共 N 个）· 现在用：我的声音」：每次打开都会自动展开。点一行就选中这个声音，也可以试听。「用的模型」这一列写看得懂的名字，例如「v2ProPlus（像你本人 71.6%）」，不再写 s2-g6。
- 步骤条，例如：
  「① 准备素材 ✅ 16.4 分钟 → ② 校对文字 👉 → ③ 训练模型 🔒 → ④ 生成讲课音频 ⬜」
  「👉 下一步：把红色的句子看一看，最后点绿色的「✅ 确认训练素材」」［去做这一步 →］
- **网页会自己停在你该做的那一步。**
- **训练做到一半关了网页也没关系**：再打开时，网页会自己停在「③ 训练模型」，进度条自己接上。不用再点「开始训练」，也绝对不会重新开始。

### ① 准备素材
1. 第一个框是「放讲课视频的文件夹（推荐）」。打开放视频的文件夹 → 点窗口最上面的地址栏 → 复制 → 粘贴进来。上次填过的路径会自动填好。
2. 文件不大的话，也可以点开「或者：直接上传文件」，把文件拖进去。
3. 视频里有背景音乐，就勾上「视频有背景音乐」。
4. 点橙色大按钮「**开始准备素材**」。下面会出现彩色进度条，写着大约几点做完。这段时间可以去做别的事，但不要关黑色窗口。
5. 做完以后：
   - 结果只写三行：可用多少分钟、多少条、要注意的事。
   - 右上角提示「✅ 素材准备好了！下一步：校对文字」。
   - 网页自动翻到「② 校对文字」。

   （以前做完会叫你「去训练」，其实应该先校对、确认。这个错误已经改掉。）

### ② 校对文字
最上面还是你要的那个算式：「🎯 用来训练的句子：1008 − 3（你删除的）− 1（程序判断不能用的）= 1004 条（66.9 分钟）」。
下面一行小记号：「🔴 可能有错 2 条 · 💾 没保存的修改 0 条 · ⬜ 还没确认」。
再下面一行告诉你「👉 现在：……」该做什么。页面上分三步：

- **第 1 步　自动改错字**
  - 点「📝 一键全部文字校正」。
  - 用过以后，按钮自己变成灰色的「✅ 这批素材已经一键校正过了」。每批素材只能用一次，这个规矩不变。
  - 准备素材的时候，电脑已经自动找过一遍错字。想让它再找一遍，点小按钮「🤖 再查一遍可能的错字」。
- **第 2 步　看一看、听一听、改一改**
  - 表格上面有一行颜色说明：红 = 可能有错　蓝 = 改过　绿 = 你打的字　紫 = 删除了　灰 = 不能用　橙色行号 = 会用来训练。
  - 勾上「只看可能有错的（2 条）」，就只显示这几句。点一行就能听，播放器就在表格下面。
  - 改字的办法都和以前一样：
    - 双击「文字」改字，整句都能看全，按回车就改好了；
    - 点蓝色的「采用」；
    - 「⋯ 选项」里有「保存这一行」「删除这一行」（会再问你一次）、「撤销删除」。
  - 同一个错字有很多处：用表格上面黄框里的「🔍 查找（例如：借词）」和「替换成（例如：介词）」，按钮和以前一样。
  - 没用的「id」那一列不再显示；表头也不会再被误点打乱顺序。
- **第 3 步　保存、确认**
  - 表格下面还是长条的「保存修改」，它下面是绿色的「✅ 确认训练素材」。
  - 点确认的时候，没保存的修改会先自动帮你保存。
  - 要用来训练的句子，行号会变成橙色。这时网页不会自动翻页，让你看清楚。
  - 确认好以后会出现「下一步：③ 训练模型 →」。

### ③ 训练模型
- **还没确认训练素材时**：
  - 「开始训练」是灰的，点不了。上面写着「🔒 还差一步：先到「② 校对文字」点最下面绿色的「✅ 确认训练素材」」，旁边有「去「② 校对文字」 →」。
  - 不会再一打开这一页就弹出「没有开始训练」吓你一跳。
- **可以训练时**，这一页只有一个大按钮「**开始训练**」。要多久只写实际量过的时间：
  - 训练过一次，就写「上次在你电脑上实际用了 31 分钟」；
  - 第一次训练，就写「开始以后，进度条会算出大约几点做完」。
  - 不再写没量过的「通常 30~90 分钟」。
- **做完以后**：显示「✅ 训练好了（实际用了 31 分钟）。电脑挑出最像你的是 v2ProPlus：像你本人 71.6%」，下面一行告诉你这个数字怎么看。以后有了 V4，会多一张表，中文、英文的实测分数分开写。
- **收起来的「⚙️ 更多选择（一般不用改）」里有**：
  - 训练方式（默认「一模一样」）；
  - 「也训练 V4 模型来比较」；
  - 「重新挑选最佳模型」，写明什么时候用：升级以后，或者上次挑选没做完；
  - 电脑自动定好的训练计划；
  - 给帮你的人用的数字框。

### ④ 生成讲课音频
- **左边**：
  - 粘贴讲稿，或者上传 txt / Word / md 文件；
  - 写文件名（可以不填）。
  - 上传 .srt 字幕时，会出现黄色提示「🎬 现在是给视频配音：按字幕的时间生成，讲稿框里的字这次不用」，旁边有「✖ 不用字幕，改用讲稿」。以前这个模式是悄悄切换的，现在看得见。
- **右边**：
  - 语速拉杆：往左更快、往右更慢，中间 0 = 和你原声一样，这些都不变；
  - 「▶ 试听（快速，只听语速）」；
  - 收起来的一行「⚙️ 质量和模型：一模一样 · ⭐ 自动（v2ProPlus）· WAV —— 一般不用改」。不用点开，就知道现在用的是什么。换成别的设置时，外面会写「现在选的是「均衡」；下次打开网页会自动回到「一模一样」」；
  - 大按钮「**🎙️ 生成讲课音频**」，不用往下翻就看得见。
- **做完以后**：
  - 结果最多四行：
    - 音频多长、一共几句；
    - 整篇像你本人多少；
    - 「⚠️ 第 2、7 句可能不够好」，旁边一个按钮「🔁 重做这 2 句」；
    - 保存的文件名。
  - 「版本 A：未去杂音」「版本 B：去杂音」两个播放器并排，⭐ 推荐的已经替你选好。想换，就在「最终用哪个版本」里点另一个。以前多出来的那个重复的「结果」播放器不要了。
  - 两个下载按钮「⬇️ 下载音频（WAV）」「⬇️ 下载字幕（.srt）」。下载到的永远是你选定的那个最终版本。
  - 「每一句的情况（一共 8 句）」：点一句就能听这一句。
  - 想一次重做好几句：在表格下面填句子编号（例如 3,5,8-10），点「🔁 重做这几句」。

### 怎么选用哪个模型（以后才有，要你点头同意）
- 在「⚙️ 质量和模型」里多一个「用哪个模型生成」，每次打开网页都已经选好「⭐ 自动」：
  - 「⭐ 自动：用实测最像你的（现在是 v2ProPlus，71.6%）」
  - 「只用 v2ProPlus（实测 71.6%）」、「只用 V4（实测 …%）」、「只用 IndexTTS25（不用训练；实测 …%）」
  - 「三个都生成，比较以后推荐」：三个模型各读一遍整篇。结果里并排写出每个模型的分数，⭐ 推荐的那个已经选好，你可以在「最终用哪个模型读的」里换成别的。
- 分数全是实际量出来的，没量过的写「（还没实测）」。用不了的模型不会出现在选项里，下面一行写明原因和怎么办，例如「V4 还没训练」。
- 「③ 训练模型」里有一个「以后生成默认用」：⭐ 自动 / v2ProPlus / V4 / IndexTTS25。选回「⭐ 自动」，就是恢复自动。

### 亲耳挑（以后才有）
- 在「每一句的情况」里点一句，下面会出现这一句的小窗：现在用的版本，加上这一句存下的其他版本（最多 5 个）。每个都写着像你本人多少，旁边有一个「换成这个」。
- 点「换成这个」以后：
  - 电脑会把整篇重新拼好，句子之间还是精确的数字静音，A、B 两个版本都会重拼；
  - 下载的文件也跟着换掉；
  - 表格里这一句会写「👂 你亲耳挑的」。以后重做别的句子时，你挑过的不会被冲掉。
- 都不满意，就点「🔁 只重新生成这一句」。
- 选了「三个都生成」的话，小窗里会多一组「别的模型读的这一句」，上面写着提醒：不同模型的声音粗细不一样，同一篇里混着用，可能听出忽亮忽暗。
- 文件名最后写实际用到的模型，混着用时写「_V4和v2ProPlus」。

### 偶尔才用的两页（放在最右边，颜色淡一些）
- 「🔎 鉴别（可选）」：机器打分、观众盲听测试、批改答题卡都在这一页。原来的「④ 试试像不像」也并进来了：只能上传音频，不再显示录音按钮。
- 「🩺 环境检查」：最上面一行告诉你「✅ 一切正常」，或者「❌ 有 1 件事要处理：点「⬇️ 下载缺少的模型」」。很长的检查清单收起来了，是给帮你的人看的。

## Part B — Engineering spec (English)

### B0. Non-negotiables (bind every item below)
- Every UI text is Chinese and says why and what to do. Never show an unmeasured number and never promise 100%. Keep the honest notes.
- The web title stays 「声音分身 VoiceTwin v18」: do not touch `APP_TITLE_VERSION="18"`, `PAGE_TITLE` or the hidden `vt-version`.
- Exact digital silence everywhere. That includes pick re-assembly. WAV is the default.
- Gradio is 4.24.0 on Python 3.9. No `@gr.render`, no `gr.Timer`, no Modal, no Sidebar, and no `from __future__ import annotations` in app.py.
- Do not break:
  - the REVIEW_JS bridge: `#vt-clips`, `#vt-clip-action`, `#vt-clip-action-btn` hidden by the `.vt-bridge` CSS class (never `visible=False`), `__COLS__` taken from `CLIP_HEADERS`, `#vt-find-q/-r/-all/-status`, `#vt-tr-files`, `#vt-tr-btn`, `#vt-dl-txt`, `#vt-dl-txt-btn`;
  - `stream_task` with one global task;
  - `_settled` (0.6 s);
  - `GUARD_JS`;
  - the 1.2 s gap between the first two yields;
  - the concurrency ids `vt-review` and `vt-find`;
  - output tuples built by name with `self._o(*_OUT)`.
- Keep every feature she asked for. Each one appears in the migration table B13.
- Model names are always `v2ProPlus`, `V4`, `IndexTTS25` (she decided this on 10-03). Mixed files are named `_V4和v2ProPlus`, never with `+`.

Step-state rules. These live in the new pure module `voicetwin/webui/guide.py`, built from `_material_stats`, the review state, `wf.training_blocker_for`, `load_models` and `current_task()`:

| Step | done | now | locked |
|---|---|---|---|
| ① | usable material > 0 | no material | — |
| ② | confirmed, not stale, no unsaved edits | ① done and ② not done | ① not done |
| ③ | a picked best model exists | ② done and ③ not done | `training_blocker_for` is non-empty |

### B10. Cross-page behaviour

**Auto-follow a running task, with the guarantee that it never starts one.**
1. Add `follow_current(kind, voice)` to `tasks.py`:
```python
def follow_current(kind, voice):
    with _LOCK:
        cur = _CURRENT
    if cur is None or not cur.alive() or cur.kind != kind or cur.voice != str(voice or ""):
        yield "", {"done": True, "idle": True, "bar": ""}
        return
    yield from _follow(cur, "", attached=True)   # never creates a _Task / thread
```
   It replaces `stream_task(..., _attach_missed)` on the follow path, because in the finish race that call spawns a phantom no-op task and overwrites `_CURRENT`.
2. Each `do_X` gets a `follow_only=False` keyword. When it is True:
   - if not `self._attaching(kind, v)`: `yield self._o(*X_OUT)` (all `gr.update()`) once and return;
   - else iterate `follow_current` through the same rendering code;
   - if the final state is `idle`, it renders nothing.

   This applies to: `do_prepare`, `do_proofcheck`, `do_textfix`, `do_train` (covers `train` and `select`), `do_generate`, `do_speed`, `do_pick`, `do_verify`, `do_blind`, `do_eval`, `do_download`.
3. Wiring, in one helper `_wire_follow(dep)`:
   - for each kind: `dep.then(_settled(partial(self.do_X, follow_only=True)), X_inputs, X_OUT, **heavy)`, followed by that kind's existing post chain;
   - every post-chain step is wrapped in `_only_if(kind)`, which returns no-op updates unless `kind_state == kind`. This avoids reloading the 1008-row table on every page open.
   - `dep` is (a) the `on_load` event and (b) `watch_btn.click(self.which_task, None, [tabs, kind_state, voice])`.
   - `heavy` gives `concurrency_limit=None`, so a 30-minute follower never blocks other events (the existing test enforces this).
4. Fallback if the browser test fails: keep only `watch_btn`; the banner then says 「点「👀 看进度」」.
