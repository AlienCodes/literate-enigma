# 声音分身 VoiceTwin 开发记录

按版本记录：老师提了什么要求、做了什么、试过但没用的方案、遇到的问题和怎么解决的。
较大的专题另有单独的记录（例如 `sv_benchmark/记录.md`：声纹打分的全部测试过程）。

> 从 v0.1.7 起，开发过程中会**随时把代码和记录推送到 GitHub**（先备份，做完再合并发布），不再只在最后一次性提交。

## v0.1.0 ~ v0.1.3：基础功能

- 目标：用老师自己的讲课视频 / 录音克隆老师的声音（老师嗓子哑了，需要用自己的声音生成讲课音频）。
- 选型：GPT-SoVITS v2Pro 微调（最像本人）为主引擎；另外支持 Qwen3-TTS、IndexTTS 零样本克隆；dummy 引擎给测试用。
- 流程：① 准备素材（提取音频、降噪、按字幕或静音切片、语音识别、过滤不是本人的片段）→ ② 训练 → ③ 生成（每句多做几遍挑最像的）。
- Windows：整合包模式（装进 GPT-SoVITS 整合包的 runtime）和独立 .venv 模式；安装程序 install_windows.bat；
  国内下载用 hf-mirror；发布流程 release.yml（GitHub Actions 打包 Windows 压缩包）。
- 文档：详细 PDF 手册（后来按老师要求停止制作）→ 简短的《快速上手》。
- v0.1.3：片段数量和编号、显卡检测修正、安装程序桌面图标提示、隐藏 gradio 升级提示。

## v0.1.6（0.1.4 / 0.1.5 没有单独发布）

老师的要求和落实：
- 所有耗时任务都有进度条（颜色：绿 = 正常、黄 = 3 分钟没进度、红 = 出错、灰 = 停止、实心绿 = 完成）；
- 网页顶部一直显示显卡状态；所有表格有编号和总数；声音库；
- 训练参数全自动、最高质量；质量档位增加「完美」：每句最多试 20 次，同时做「未去杂音 / 去杂音」两个版本让老师选；
- **绝对静音**（老师明确要求固定住）：生成的音频没有任何背景音、底噪，句子之间是精确的数字静音；
  老师否决了"对齐录音环境声"的方案；
- 每个候选、每句、每个版本都显示"像你本人（%）"，低于 85% 淘汰；
- ⑤ 鉴别：机器打分排名 + 观众盲听测试；语速拉杆；校对表标红可能的错字；
- 发布前浏览器实测发现 gradio 4.24 的流式更新竞态（「只重新生成第几句」变成 `[]`），用 `_settled` 修复。
- 文档：老师说不需要 99 页的长手册，只保留简短的《快速上手》。

## v0.1.7（进行中）：精准声纹打分

老师要求："像你本人"的检测程序必须非常精准、绝对靠谱，不能随便拿一个普通程序。

- 全部测试过程、数据来源、淘汰的模型和原因见 `sv_benchmark/记录.md`；
- 结论：ReDimNet2-B6（2026 年最新、用中文数据训练）是所有测试里最准的单个模型；
  最终用 ReDimNet2-B6 + ERes2NetV2 + ERes2Net-base（都用中文训练过）三个一起打分。
  用正式程序本身复测：2 秒中文短句 EER 0.05%（余弦 0.01%），4~5 秒中文 0.01%；
  停顿改成绝对静音、去杂音、音量变化对同一个人的分数影响都在 1~3 个百分点以内；
- 淘汰：不带中文训练数据的 ReDimNet2（中文差很多）、3D-Speaker 英文 CAM++（中文完全分不出）、按音量判断人声
  （对绝对静音和环境声处理不一致）、resemblyzer（太老）；
- 产品改动：只看人声（silero-vad，人声前后不多留）、三个模型一起打分、AS-norm、两头校准（0% = 陌生人，
  100% = 你自己的真实录音）、短句子按同样长度的录音校准、模型下载带 sha256 校验、「完美」档达标线按你自己真实录音的
  波动范围定、以前生成好的句子自动重新打分；
- 过程中发现并修好：ReDimNet2 中文版 CPU 上慢 25 倍（denormal）、测试联网下载、Windows 上文件修改时间精度不够。

### 老师问：是不是有更好的模型？（2026-10-01）

老师看到 GPT-SoVITS 官方 wiki 列出了 v4、v5。查证结果：
- 我们用的是 GPT-SoVITS v2ProPlus + 用老师的录音微调。官方原话：微调时"V2 和 V2Pro(Plus) 差异不会有多少"；
  v3/v4/v5（diffusion 路线）适合录音棚级的高音质训练集，"一般音质的训练集 v3/v4 不行"——讲课视频的录音多半属于一般音质。
- v5 的优势是**零样本**（不微调）相似度最高（SeedTTS 中文测试 SIM 0.78~0.805，真人互比 0.755）；
  官方写明"基于 v5 的少量样本微调暂未进行研究和实验"；查了 GitHub 主分支（最新提交 2026-08-18），**还没有 v5 的代码**。
- v4 可以微调，微调后和 v5 差不多，但同样只适合高音质录音。
- 官方也说：论文分数和宣传都是浮云，只有用自己的数据测出来的结论才真实。

决定：v0.1.7（精准打分）发布后，v0.1.8 做"自动比较不同模型"：用老师留出来的真实录音句子，
分别用 v2ProPlus 微调 / v4 微调 / IndexTTS2.5 零样本 /（v5 代码公开后）v5 生成同样的句子，
用精准打分 + 错字检查自动挑最像的，并把对比表给老师看。

### 老师确认：继续用 v2ProPlus，先把 v0.1.7 做完（2026-10-01）

老师要求必须确定用的是最新、最强的版本。依据：官方 wiki 版本顺序 V1<V2<V3<V4<V2Pro(Plus)<V5，v2ProPlus"超 v4 的性能"、
相似度比 v2Pro 略高；V5 还没公开；GitHub 最新发布 20250606v2pro。程序默认一直是 v2ProPlus（`default_config.yaml`）。
v0.1.7 加了一项"环境检查"：显示 GPT-SoVITS 模型版本，是 v2ProPlus 时 ✅，不是时 ⚠️ 并说明怎么改；训练日志里也写明版本。

## v0.1.8：老师的安装截图里发现的问题 + 顶部显示模型型号（2026-10-02）

老师发来 v0.1.7 的安装过程截图（第 2~7 步），逐条检查：
- **安装成功**，环境检查 20 项里 17 项正常、3 项是可选组件（demucs、Qwen3-TTS、IndexTTS），显卡 RTX 5070 Laptop 8 GB、
  PyTorch 2.7.0+cu128 能用显卡、精准声纹模型下载成功、GPT-SoVITS 模型版本 v2ProPlus。
- **真正的问题：桌面图标没建成**（`Unable to save shortcut "...\OneDrive\Desktop\???? VoiceTwin.lnk"`）。
  原因：老师电脑的「非 Unicode 程序的语言」不是中文，Windows 的快捷方式组件 WScript.Shell 把中文文件名转成 ????，
  `?` 不能出现在文件名里，所以保存失败。v0.1.3 时老师就问过"桌面上没有图标"，当时猜是安全软件拦截——**猜错了**，
  这次截图里的 ???? 才找到真正原因。修法：先用英文文件名建好，再用 PowerShell（支持中文）改名移到桌面；
  安装路径里有中文时读回来核对目标位置，不对就不放桌面、提示手动创建。用模拟这种电脑的 PowerShell 测试：
  旧代码复现了一模一样的报错，新代码通过。
- **红字 ERROR**：`voicetwin 0.1.7 requires librosa>=0.10, but you have librosa 0.9.2`。整合包（v2pro-20250604-nvidia50）
  自带 librosa 0.9.2。程序只用到 `librosa.yin` 和 `librosa.feature.mfcc`，0.9.2 里都有；用和整合包完全相同的版本
  （Python 3.9、librosa 0.9.2、numpy 1.23.4、scipy 1.9.3、noisereduce 2.0.1）跑全部测试：654 个通过、1 个失败，
  失败的是一个测试的浮点容差太紧（差 2e-6），不是程序问题；放宽后 659 个全部通过。所以把要求改成 `librosa>=0.9.2`，红字消失。
  另外确认 noisereduce 2.0.1 的 `reduce_noise` 参数和我们用的一致（实际调用一次也正常）。
- **黄字 WARNING**（voicetwin.exe 不在 PATH）：不影响使用，pip 加 `--no-warn-script-location` 不再显示。
- **环境检查前面的英文警告**（funasr 的 SyntaxWarning、rotary_embedding_torch 的 FutureWarning）：第三方库导入时打印的，
  不影响使用；环境检查期间关掉警告显示。

老师又要求：**在「声音分身 VoiceTwin v0.1.7」右边显示正在用的模型型号**（v2ProPlus / v4 / v5），而且必须是检测出来的，不能乱写。
- 做法：和 GPT-SoVITS 自己判断版本的方法完全一样（`GPT_SoVITS/process_ckpt.py` 的 `get_sovits_version_from_path_fast`）——
  官方底模按文件开头 8192 字节的 MD5 认；训练出来的模型按文件开头 2 个字节的版本标记认（05 = v2Pro，06 = v2ProPlus，04 = v4 LoRA……）；
  旧格式按文件大小。读的是**这个声音生成时实际要用的那个 SoVITS 模型文件**（训练好的；还没训练就读底模）。
- 对照表除了内置一份（和官方 2026-08-18 主分支一致），还会从老师整合包里的 `process_ckpt.py` 读一遍：
  以后官方出了 v5，新的版本标记不用等声音分身更新就能认出来；两边都不认识就显示「版本读不出来」，不猜。
- 训练过但模型文件找不到时，如实写「找不到训练好的模型文件，现在用的是底模」。
- 浏览器实测（gradio 4.24、电脑宽度和手机宽度）：标题右边显示「模型：GPT-SoVITS v2ProPlus」，换声音、训练完都会重新读；
  第一次手机宽度下标签被挤出屏幕（gradio 的标题是不换行的 flex），改成允许换行后正常。

## v0.1.9：安装窗口里中文全部变成「?」（2026-10-02）

老师升级 v0.1.8 时发来截图：安装窗口里**所有中文都显示成「?」**（安装本身在正常进行，模型也在下载）。
- 原因：截图的窗口标题是「Administrator: C:\WINDOWS\System32\cmd.exe」——这次是右键「以管理员身份运行」，Windows 打开的是
  **老式黑色窗口**；老师电脑的「非 Unicode 程序的语言」不是中文，这种窗口的默认字体没有中文字，中文就全部变成「?」。
  v0.1.7 时老师是直接双击，打开的是新式的 Windows Terminal（带标签页的窗口），它会自动找有中文的字体，所以正常。
  安装程序的文字编码本身没有变（UTF-8 带 BOM、chcp 65001），是没有防住这种窗口。
- 修法（三层）：
  1. `install_windows.bat`：不在 Windows Terminal 里、而且电脑上有 Windows Terminal 时，自动在 Windows Terminal 里重新打开安装程序
     （有参数、已经在里面、已经换过一次时不换，避免来回打开）；
  2. `install_windows.ps1`：还是老式窗口时（没有 Windows Terminal 的电脑），用 Windows 接口把窗口字体换成「新宋体」（NSimSun，
     没有就换宋体 / MS Gothic）；Python 程序（`voicetwin` 命令、网页启动窗口）也做同样的事（`utils/winsys.py`）；
  3. 都不行时，窗口开头有一行英文提示（中文显示不出来）：关掉窗口、直接双击 install_windows.bat，不要用「以管理员身份运行」。
- 测试：批处理的逻辑检查；C# 部分用 PowerShell 实际编译；Windows 自动测试里实际运行 install_windows.bat（没有 Windows Terminal、
  已经在 Windows Terminal 里两种情况）；Python 换字体用假的 kernel32 测（换栅格字体、找不到新宋体换宋体、本来就有中文不动、
  不是黑色窗口不动、Windows Terminal 里不动、失败不报错）。开发机没有 Windows 黑色窗口，**真正的效果要在老师电脑上确认**。
- 《快速上手》常见问题加一行；两套环境测试 668 / 672 个通过。
