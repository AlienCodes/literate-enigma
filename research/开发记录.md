# 声音分身 VoiceTwin 开发记录

按版本记录：老师提了什么要求、做了什么、试过但没用的方案、遇到的问题和怎么解决的。
较大的专题另有单独的记录（例如 `sv_benchmark/记录.md`：声纹打分的全部测试过程）。

> 从 v0.1.7 起，开发过程中会**随时把代码和记录推送到 GitHub**（先备份，做完再合并发布），不再只在最后一次性提交。

---

## v0.1.0 ~ v0.1.3：基础功能

- 目标：用老师自己的讲课视频 / 录音克隆老师的声音（老师嗓子哑了，需要用自己的声音生成讲课音频）。
- 选型：GPT-SoVITS v2Pro 微调（最像本人）为主引擎；另外支持 Qwen3-TTS、IndexTTS 零样本克隆；dummy 引擎给测试用。
- 流程：① 准备素材（提取音频、降噪、按字幕或静音切片、语音识别、过滤不是本人的片段）→ ② 训练 → ③ 生成（每句多做几遍挑最像的）。
- Windows：整合包模式（装进 GPT-SoVITS 整合包的 runtime）和独立 .venv 模式；安装程序 install_windows.bat；
  国内下载用 hf-mirror；发布流程 release.yml（GitHub Actions 打包 Windows 压缩包）。
- 文档：详细 PDF 手册（后来按老师要求停止制作）→ 简短的《快速上手》。
- v0.1.3：片段数量和编号、显卡检测修正、安装程序桌面图标提示、隐藏 gradio 升级提示。

## v0.1.6（0.1.4 / 0.1.5 没有单独发布）

老师的要求和落实：
- 所有耗时任务都有进度条（颜色：绿 = 正常、黄 = 3 分钟没进度、红 = 出错、灰 = 停止、实心绿 = 完成）；
- 网页顶部一直显示显卡状态；所有表格有编号和总数；声音库；
- 训练参数全自动、最高质量；质量档位增加「完美」：每句最多试 20 次，同时做「未去杂音 / 去杂音」两个版本让老师选；
- **绝对静音**（老师明确要求固定住）：生成的音频没有任何背景音、底噪，句子之间是精确的数字静音；
  老师否决了"对齐录音环境声"的方案；
- 每个候选、每句、每个版本都显示"像你本人（%）"，低于 85% 淘汰；
- ⑤ 鉴别：机器打分排名 + 观众盲听测试；语速拉杆；校对表标红可能的错字；
- 发布前浏览器实测发现 gradio 4.24 的流式更新竞态（「只重新生成第几句」变成 `[]`），用 `_settled` 修复。
- 文档：老师说不需要 99 页的长手册，只保留简短的《快速上手》。

## v0.1.7（进行中）：精准声纹打分

老师要求："像你本人"的检测程序必须非常精准、绝对靠谱，不能随便拿一个普通程序。

- 全部测试过程、数据来源、淘汰的模型和原因见 `sv_benchmark/记录.md`；
- 结论（截至目前）：ReDimNet2-B6（2026 年最新、用中文数据训练）是所有测试里最准的，
  和 3D-Speaker 的模型组合后在 2 秒短句上的错误率从单模型的 1.2% 降到 0.87%（英语）、0.04%（中文）；
- 产品改动：只看人声（silero-vad）、几个模型一起打分、AS-norm、两头校准（0% = 陌生人，100% = 你自己的真实录音）、
  模型下载带校验、「完美」档达标线按你自己真实录音的波动范围定、以前生成好的句子自动重新打分。
