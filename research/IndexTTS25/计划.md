## 二、已经做好的（都在开发分支上，测试通过）

- **IndexTTS 接口照官方真实写法改好**（`voicetwin/backends/indextts.py`、`voicetwin/backends/workers/indextts_worker.py`，
  对照官方 commit d9e41aa）：
  - 不让它启动时去编译显卡扩展（`use_cuda_kernel=False`，Windows 上一般没有编译工具）；不加载情绪模型（省大约 1 GB 显存）；
  - 有一个汉字就按中文（ZH）读，中英夹在一起也是 ZH；
  - 采样参数用 IndexTTS 自己的默认（0.8 / 0.8 / 30），不用给 GPT-SoVITS 调的那一套；
  - 语速 `duration_factor` 限制在官方的 0.5~2.0；
  - 8 GB 显卡：官方会把超过 40 个字的句子切开、中间插 200 毫秒静音；我们默认一句话一口气生成（语调连贯），真的显存不够才这一句用官方的切法；
  - 写完检查音频文件真的写出来了；缺的东西（程序、它自己的 Python 环境、模型文件、辅助模型）一条一条说清楚，都指向「重新双击 install_windows.bat」；
  - 缺辅助模型时先从魔搭（ModelScope）下载，魔搭没有的用 hf-mirror。
- **报错说明**：以前说「可选引擎，换回 GPT-SoVITS」，现在说「IndexTTS25 没有装好，还不能生成，重新双击 install_windows.bat」。
- **测试**：`tests/test_indextts_backend.py` 8 个（用 `tests/fake_indextts` 里参数签名和官方一模一样的假 IndexTTS 真的启动 worker，
  检查传过去的每一个参数、低显存切法、没写出文件时报错）；相关的旧测试 197 个通过。
- **环境实测**：IndexTTS 的环境里 numpy 是 2.2.6（官方锁定）、librosa 0.10.2.post1、transformers 4.52.1；我们的网页用的 gradio
  4.44.1 能和它们装在一起（10-05 实测）。整套旧测试在这个环境里跑（只有 gradio 4.44 的内部写法和 4.24 不一样的测试要改，已改两个）。

## 三、下周要做的（按顺序）

### 1. 生成（「一模一样」改成适合 IndexTTS）
- IndexTTS 一次只生成一个版本（GPT-SoVITS 能一次同时生成好几个）：每句的版本数要重新定（现在 40~64 个会太慢）；
  按老师电脑上实测的速度定，先试少一点（例如每句 3 段参考录音 × 几个版本），生成以后显示实际用时。
- 每句换几段老师自己的录音当参考（只用前 15 秒；不需要录音的文字），按声纹挑最像的、检查有没有读错（识别模型不再从整合包里找，
  用魔搭下载的 Paraformer）；句子之间照样是精确的数字静音、按老师的说话习惯放停顿。
- 语速校准：准备素材以后（或第一次生成前）自动用几句没参加挑参考的录音量一次 IndexTTS 的语速，「语速 0 = 和你原声一样」才准。
- 一句话不要太长（官方建议的切法：标点处），英文单词多的句子要看实际效果。

### 3. 安装程序（不要整合包）
- 一个环境：uv + Python 3.11 + 官方 index-tts 代码（固定在测过的 commit）+ torch 2.8 cu128（RTX 50 要 CUDA 12.8）+ VoiceTwin 自己的东西
  （gradio 4.44.1、声纹打分用的 onnxruntime、识别用的 funasr）。

## 四、风险（要跟老师说清楚的）

1. **效果不能打包票**：没找到 IndexTTS 和微调过的 GPT-SoVITS 的公开对比；有用户觉得 2.5 比 2.0 退步（issue #781、#801），长句后面会变慢（#800）。
2. **8 GB 的 RTX 50 没人实测过**：官方在 4090 上测的最高用量 5.48 GB（bf16、不开情绪模型），应该够。
3. **开发电脑没法真跑**：没有显卡，连不上魔搭、Hugging Face、download.pytorch.org。第一次真跑在老师电脑上，可能要来回修一两次。
   老师可以在环境设置里放开 modelscope.cn，那样能在开发电脑上用 CPU 先跑一两句。
4. **生成速度没测过**：4090 上 RTF 约 0.2（官方）；老师的显卡上要实测，一句一个版本地生成，版本数多了会很慢。
5. 没有官方的 Windows 整合包，网上个人做的都没法核实，所以安装程序从官方代码 + 魔搭自己装。
