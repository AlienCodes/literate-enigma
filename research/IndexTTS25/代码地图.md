## 1. 引擎怎么选
- `default_config.yaml:55` `backend: gptsovits` → 要改成 `indextts`；`:119-126` 是 `backends.indextts`。
- `backends/base.py:552-572` 引擎注册和 `get_backend`（没给名字时默认 `"gptsovits"`，567 行）；`workflows._backend_class`（119-124）。

  单选框 `t_backend`（4719，② 高级设置）、`s_backend`（4758，③ 高级设置）；鉴别（盲测）用的是 `cfg.backend`（2564-2567 → `workflows.py:1451`）。

## 2. 现在选 IndexTTS 会怎样
- **生成能用**：`run_narrate` 不查训练和确认（1179-1216）；`Narrator` 只要 `references.json`（engine.py 621、1879-1892），所以只要做过「① 准备素材」。
- 网页一直叫你去训练：`_voice_status_md`（app.py 1208-1246）只认 `models.json[*].selected`；`do_prepare` 的下一步说「去 ② 训练」（3099-3112、`PREP_NEXT` 139）。
- 声音库已经能认出不需要训练的引擎（`workflows.voice_library` 376-405）。
- 顶上的模型型号显示「IndexTTS」（`workflows.model_badge` 302-352），要固定写「IndexTTS25」。

| 东西 | 位置 | 选 IndexTTS 时 |
|---|---|---|
| 一次同时生成好几个（api_v2 batch） | gptsovits.py 3699 等 | IndexTTS 没有（`supports_batch=False`），一个一个生成；`BatchTuner` 关掉（engine 985-995） |
| 每句几段参考录音（3 路） | search.py 174-203、260-277；engine 1018-1047 | 能用，和引擎无关 |
| 副参考 aux refs | engine 863-864、1030 | IndexTTS 没有 |

| 准备「一模一样」的小校准 | select.py 1614-1625、1667-1673 | 跳过（只给训练过的引擎）；声音画像、参考录音库照样建 |
| 语速校准 | engine 808 读 `models.json[indextts].speed` | 只有 `select_and_calibrate`（select.py 151-295，和引擎无关）会写；网页从来不给 IndexTTS 调，要加 |
| 采样参数 | engine 154-164；search 620-629 | 是给 GPT-SoVITS 调的（temperature 1.0、top_k 15/5），要按引擎分开 |

| 报告里的 batch_stats、speed_trick | engine 1756、1779-1827、2216-2228 | 只和 GPT-SoVITS 有关 |
| 说明文字 QUALITY_NOTE / TIER_NOTES | engine 107-130 | 提到训练，要改 |

和引擎无关、照样用的：档位和限制、打分（`IdenticalScorer`、`SimilarityJudge`）、搜索、连贯性挑选、停顿和音量拼接、去杂音版本、报告、说话习惯统计、文件名带模型名。

## 4. 参考录音
- `data/references.py`：`select_references`（42-160）、参考录音库 `build_reference_bank`（318-449）；挑选靠文字判断句子类型（问句、感叹句）、
  句末、英文比例等（search.py 150-203），**合成时不用文字**（IndexTTS 不需要）。所以校对表现在不是必须的，只影响挑参考录音。
- 长度 3.5~9.5 秒是 GPT-SoVITS 的规矩（default_config 47-51），IndexTTS 只用前 15 秒，可以放宽。
