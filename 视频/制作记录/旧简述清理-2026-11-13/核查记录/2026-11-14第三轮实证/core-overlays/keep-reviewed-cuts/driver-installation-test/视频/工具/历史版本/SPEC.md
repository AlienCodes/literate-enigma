# 视频字幕脚本规范（每篇一个 JSON）

## 用途
16:9 视频：一句英文一屏，按意群拆成 2–4 段从上到下排列，每段英文下紧跟对应中文；朗读时当前段高亮。

## 拆分规则
1. 英文原文一字不改（含标点、大小写），各段按顺序拼接必须还原整句。
2. 在逗号、分号、冒号、从句/介词短语边界处断开；每段英文 3–14 个词，尽量 6–12；短句（≤12 词）可整句一段。
3. 中文段只译本段英文内容，不得加入其他段或原文没有的信息（例：不得写"在脸上"）。可调整中文语序以通顺，但每段中文必须独立可读、与英文段一一对应。

## 翻译三原则（用户最终要求，优先级从高到低同时满足）
1. **精准**：重点词的中文必须准确表达它在本文这句话里的意思和语法作用（词性/功能对应）。
2. **地道**：中文要像中国人写的好文章，用自然的搭配和习语（如 in broad daylight → 光天化日之下），不得翻译腔。
3. **通顺**：每段中文读起来顺口、不别扭；宁可调整非重点词的语序和措辞，也不让句子生硬。
三者冲突时：精准不可牺牲；在保证精准的前提下选最地道、最顺的说法。形容词/副词在中文里作修饰语时，"的/地"按中文习惯取舍（如"逻辑推理"比"逻辑的推理"地道则不加），但加粗中文必须清楚体现修饰功能，绝不能把形容词译成动词或副词。

## 重点词单位
若加粗词在句中构成短语动词或固定搭配（rubbed on、begged to differ、in fairness），高亮整个意群：英文写成 **rubbed on**，中文对应整个搭配（**抹上**）。只扩展到与该词构成固定意义的小品词/介词，不扩大到普通宾语。

## 重点词翻译（最重要）
英文里加粗的 **word** 在中文里写成 **中文**(word)，颜色相同。要求：
1. **词性必须一致**：
   - 形容词 → 中文形容词，带"的"写进加粗：earnest → **真心实意的**；undue → **过分的**；sheer → **十足的**
   - 副词 → 带"地"写进加粗：generously → **慷慨地**；partially → **部分地**
   - 名词 → 中文名词：conviction → **信念**（不是动词"深信"）；disbelief → **怀疑/不信**（名词）
   - 动词 → 中文动词，时态由上下文体现：raided → **抢劫了**；quizzed → **测试了**
   - 过去分词作定语/状语 → 保持分词功能：rubbed (on) → **抹上的/涂抹上去的**
   - 短语（in fairness, begged to differ）→ 对应的中文短语
2. **语境义精准**：取该词在本句中的确切意思（如 render 此处 = "使……成为"；damning = "足以定罪的"）。
3. 加粗中文必须是该英文词本身的对译，不能把相邻词的意思吞进去，也不能只译一半。
4. 每段内重点词的中文语序可调整，但必须在本段中文里出现且只出现一次。

## 输出格式（JSON）
{
 "no": "01",
 "title_en": "...", "title_zh": "...",
 "sentences": [
   {"para": 1, "chunks": [
       {"en": "Their only **camouflage** was lemon juice,", "zh": "他们唯一的**伪装**(camouflage)是柠檬汁，"},
       ...
   ]},
   ...
 ]
}
- 段落号 para 从 1 开始；英文正文所有句子按顺序全部收录。
- 标题单独由程序处理，不放进 sentences。

## 逐词对位（v3，用户最新要求）
每个 chunk 增加字段 "align": [[en_group, zh_group], ...]，表示英文在上、中文正对在下的对位单元。
1. **先保证整体通顺**：把一个 chunk 的所有 zh_group 按顺序连起来，必须正好是这一段地道、通顺、精准的中文（就是该 chunk 的 "zh" 去掉标记后的文字）。
2. **能对就对，不能对就合并**：中文语序与英文一致的地方，尽量细到单词或固定搭配一一对位（Their→他们的, only→唯一, camouflage→伪装, lemon→柠檬, juice→汁）。中文需要调换语序才通顺的地方，绝不为了对位而打乱中文，而是把那几个英文词合成一个对位单元，下面放对应的整段中文。
3. **重点词**：尽量让重点词（或其固定搭配）自成一个单元；做不到时它可以和相邻词在同一单元里，但单元内仍用 **word** 和 **中文**(word) 标注，以便着色。
4. 英文里没有中文对应的虚词（the, a 等）可以并入相邻单元，或 zh_group 为空字符串。
5. 所有 en_group 按顺序以空格连接 = 该 chunk 的 en（含 ** 标记）。
6. 宁可单元大一点，也不能让中文变成逐字硬译的"翻译腔"。
