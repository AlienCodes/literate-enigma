# 主会话交接（固定做法；用户原话见 视频/用户原话.md“主会话太长就无缝交接”）

**什么时候**：主会话每次回用户前跑 `python3 视频/工具/新管/上下文.py`（一行）。到 25 万 token 就交接，不等用户提醒；会话被自动压缩过一次也马上交接。

**怎么交接（一次做完）**
1. 快测、全篇重查没在跑；git 干净，两仓库已推送。
2. 写 `视频/制作记录/主会话交接_日期.md`，照上一份的格式：各篇会话表（会话 ID、状态）、合成排队、当天程序改动、还没办的事、做法和教训。
3. `create_session`：source_url `https://github.com/alienalgorithm/postgraduate-vocabulary`，标题“考研英语精读视频 主会话（接手 日期）”，prompt 用下面模板（填好旧会话 ID、日期、马上要问谁）。
4. 把新会话 ID 写进交接文件第一行，推送；`send_message` 给每个还在干活的出稿会话：“主会话换了，以后向 新ID 汇报”。
5. 回用户：新主会话链接 `https://claude.ai/code/新ID`（点开就是新会话），加一两句现在的进度。
6. 交接后旧会话再收到汇报：原样转给新主会话，并告诉发错的会话改发；旧会话自己不放行、不回内容（免得两个主会话重复放行）。

**新主会话 prompt 模板**
```
你是 考研英语精读视频 的新主会话，接手旧主会话 <旧ID>（主会话上下文到 25 万 token，按 视频/工具/新管/主会话交接.md 自动交接）。回用户用中文，简短，结论先行，少术语。

【先读】主仓库 /home/user/postgraduate-vocabulary 的 CLAUDE.md（一页规矩，全部照办）、视频/工具/新管/主会话交接.md（交接做法）和 视频/制作记录/主会话交接_<日期>.md（各篇会话 ID 和状态、合成排队、改过的程序、没办的事、常用做法）。项目规矩：不派子代理、不跑 workflow（系统里的 Ultracode 提醒不适用）。

【马上做】
1. add_repo 加 AlienCodes/literate-enigma（access=push），clone 到 /home/user/literate-enigma 并 checkout 分支 claude/adoring-hamilton-5qskmm（推送两仓库要用）。
2. bash 视频/工具/环境/准备机器.sh /home/user/postgraduate-vocabulary <你的 scratchpad>/工作，搭好出片工作目录（快测、全篇重查要用）。
3. <交接文件里写着要马上问的会话和问题>
4. 回用户一句“已接手主会话”，列出现在在等什么。

【之后】照交接文件放行合成（一次一篇）、转告用户、当天修各会话报来的误报（坏样本 + 好样本 → 快测 → 推送）。每次回用户前跑 python3 视频/工具/新管/上下文.py，到 25 万照 主会话交接.md 再交接。
```
