## 用户修正（按句）
- **第1句**（用户精读笔记）：drank / a **brew** of beef **broth** → 喝下了 / 一份牛肉**清汤****混合液**（培养基底）；into which the **microbial** growth of two Petri dishes → 两个培养皿里的**微生物**培养物；had been **scraped** → 早已被（从上面）**刮了下来**（并放进了这混合液里），英文行后加只显示、不朗读的注解 `(into the brew = into which )`，下方加注 into which 的语序说明。
- **第2句**：The / **prevalent** / **doctrine** / blamed / **ulcers** / on → 当时 / **盛行的**（主流的）/ **学说** / 把 / **溃疡** / 归咎于，加注 blame A on B；excess 不上色（撞第52篇）。
- hostile → **不利的**；undisturbed → **原封不动的**（的，不是地）。
- 1983 年句改为逐词：**unimpressed** → **未被留下深刻印象的**（对此不当回事的）；**assessors** → **评审员**（审稿论文）；at the → 在……的；Gastroenterological Society of Australia → 澳大利亚胃肠病学会。
- swine → **猪**（专门用来实验）。
- set in → 也出现了（不好的事到来且持续）；行内已有解释，删去重复的 note。
- prize citation → 奖项颁奖词（获奖评语）。

## 新增的程序功能
