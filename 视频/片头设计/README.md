# 片头「朋克英语」标志设计：流程与结果记录

## 用户要求（2026-10-05）
1. 视频里**不写篇号**：去掉片头顶部"考研英语精读 · No.XX"小标签和右下角篇号水印。
2. 在片头标题页加上「朋克英语」四个字的标志，要像商标，要好看。**只出现在片头标题页**，其他地方都不出现。
3. 先做 5 个不同风格的版本，**5 版都做成视频**，用户自己先看；然后由评委选出最好的 3 版。
4. 整个流程（成功的、失败的）和所有文件都要及时上传 GitHub。

## 目录
- `A_stamp/` … `E_ransom/`：每一版的设计程序 `title_logo.py`，下载的字体，以及三张测试标题页 `t01.png`、`t02.png`、`t03.png`。测试标题页用第01、02、03篇的标题做，长、短标题都有。另有 4K 测试 `t03_4k.png`、标志特写 `logo_crop.png`，以及设计师迭代时留下的对比图。
- `视频/03_<版本>.mp4`：用这一版片头做的第03篇视频（1080p 草稿）。
- `title_variant_video.py`：只换片头的出片程序（见下）。
- `工作流/`：设计工作流程序 `设计工作流.js`、运行日志 `运行日志.jsonl`、5 位设计师的完整报告 `设计结果.json`（含字体来源、摆放位置、每轮迭代与自评）。

| 版本 | 风格 | 状态 |
|---|---|---|

| B_neon | 霓虹灯：粉红霓虹灯管字（站酷庆科黄油体），青色霓虹角框，带一点 RGB 错位，居中放在中文标题下方 | 设计完成，视频已出 |
| C_graffiti | 涂鸦：马善政毛笔字，亮粉渐变 + 黄色细描边 + 深色外框投影，油漆滴痕、喷溅点和小闪光，微微右上倾斜，下方小字 PUNK ENGLISH；居中放在中文标题下方 | 设计完成，视频已出 |
| D_wordmark | 高级字标：App 图标式标志，左边黄→橙渐变圆角方块（微倾斜）内有深色闪电，右边站酷庆科黄油体白色「朋克英语」，下方青绿小字 PUNK ENGLISH；居中放在中文标题下方 | 设计完成，视频已出 |
| E_ransom | 剪贴拼贴：四个字各剪在一块不同颜色的撕边纸片上（黑底白字、荧光粉、米白纸、亮黄），微斜、贴纸胶带，下方一条黑色打标签机胶条 PUNK ENGLISH；居中放在中文标题下方 | 设计完成，视频已出 |

## 过程记录（含失败和调整）
1. **第一次运行设计工作流**（运行编号 `wf_46e3053c-a28`）：5 位设计师各做一个方向，每人在自己的目录里复制 `title2.py` 改出新片头，不改动原程序；然后 2 位评委打分，前三名再按评委意见打磨。
2. **中途停止并改流程**：用户要求 5 版都先做成视频给自己看，再由评委选前三。原流程的"打磨"会直接覆盖前三名的原版文件，用户就看不到原版了。所以在设计阶段停止了工作流：当时 A、B 已完成，C、D 正在做，E 还没开始。随后把工作流改成"只做设计"，并用同一运行编号续跑：A、B 直接沿用已完成的结果，C、D、E 重新开始。
3. **出视频的方法**：`title_variant_video.py` 复用第03篇草稿视频已经渲染好的正文画面和配音，只替换第一张标题页，再按与 `make_video.py` 完全相同的编码参数合成。这样 5 支视频除了片头完全一样，便于对比。
   - 自测：用原来的 `title2.py` 跑一遍，生成的标题页与原视频的标题页逐像素一致，视频参数也一致（1920×1080、30fps、AAC 48kHz）。
4. **5 支视频全部完成并上传**（A、B、C、D、E 按设计完成顺序逐个出片、发给用户、上传）。每支视频的标题页都核对过与设计稿逐像素一致，时长均为 152.6 秒。
5. **评委评选**（工作流运行编号 `wf_4ad1ff24-c8c`）：3 位评委独立打分，分别从品牌设计、考研学生手机观看、视频剪辑三个角度评分。每位评委看到的 5 版顺序不同，避免排在前面的占便宜。评委看的是从视频里截出的标题画面（`评审素材/*_video_title.png`）、手机尺寸缩小图（`*_phone.png`）、片头之后的第一屏（`*_video_next.png`），以及同一设计用在第01、02篇标题上的效果。评分项和权重：好看 25%、标志质量 20%、朋克感 15%、手机上看得清 15%、主次与协调 15%、不同标题下的一致性 10%。三位评委的总分相加后排名，再由一位挑错员专门找前三名的毛病，复核排名。结果写在本文件。
6. **用户选定 E 拼字版，评选提前结束**：用户看完 5 支视频后直接选定 E 拼字版，说"不用弄了"，评选工作流随即停止。停止时 3 位评委中已有 2 位交卷，挑错员还没开始。这两位评委都独立把 E 排第一，第二名都是 D 高级字标版（得分见 `工作流/评选结果-部分.json`）：

   | 版本 | 评委甲总分 | 评委乙总分 |
   |---|---|---|
   | E_ransom 拼字 | 7.95 | 8.35 |
   | D_wordmark 高级字标 | 7.40 | 7.70 |
   | C_graffiti 涂鸦 | 6.35 | 6.15 |
   | A_stamp 印章 | 5.50 | 6.55 |
   | B_neon 霓虹灯 | 5.25 | 4.10 |

   评委对 E 的意见：最有朋克味、最让人记得住，手机上也看得清。小问题有两点：「英」字手写体偏细；胶带颜色有点脏，在小屏上略显零碎。用户选定后未做修改，原样采用。
7. **正式启用**：E 版程序替换 `工具/title2.py`，只把字体路径改为 `fonts/`（`资源/字体/`）。改后的标题页与设计稿逐像素一致，4K 也测试通过。第01、02、03篇视频都用新片头重新生成（1080p 草稿）。
8. **片头特效小样**（用户问"视频开头要不要做个特效"）：建议做，但短而克制，只动片头、不改配音和时间轴。小样 `特效小样/片头特效小样.mp4`（第03篇片头加第一屏前 1.5 秒），程序 `特效小样/title_anim.py`，关键帧 `特效小样/关键帧.png`。动画约 1.5 秒：
   - 英文标题逐行淡入并轻微上移；
   - 中文标题黄色色块轻弹出现；
   - 四张纸片按 朋→克→英→语 依次放大落下、回弹、旋转归位，像贴纸"啪"地贴上；
   - 两条纸胶带落下，最后 PUNK ENGLISH 标签条从左滑入。

   动画最后一帧与静态片头一致：全画面只有 1 个像素差 4 个色阶，平均差 0.002。等用户看完决定是否用到所有视频。
