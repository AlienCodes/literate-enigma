# 踩坑总表（所有出过的问题 · 每次做视频/文本前必读）

> 这是第01、02篇制作过程中**真实出过的每一个问题**的汇总。每条都写清：出了什么问题 → 为什么 → 以后怎么防。
> 每做一篇，开工前通读一遍；交付前按文末《交付前检查单》逐项打勾，并运行 `python3 视频/工具/check_all.py NN`。

## 一、翻译（用户最看重：精准、地道、通顺）

| # | 出过的问题 | 原因 | 以后怎么防 |
|---|---|---|---|
| T1 | rubbed on 译成"涂抹在**脸上**" | 擅自添加原文没有的信息 | 只译原文有的内容；需要补充的放进括号说明，且要用户认可 |
| T2 | earnest 译成"真心实意**地**"（副词） | 没核对词性 | 形容词→"…的"，副词→"…地"，名词→名词，动词→动词，逐个核对 |
| T3 | conviction 译成"深信"（动词） | 同上 | 同上 |
| T4 | before 被放在"之后才"上面 | 意思方向弄反 | before/after、increase/decrease、more/less 这类逐个核对方向 |
| T5 | logical reasoning、quarter of scorers、statistical mirage 的中文横跨两个英文词 | 对齐不精细 | 每个中文只放在它对应的英文正下方；一组中文不能混入别的词的意思 |
| T6 | 逻辑的推理、高成就者、得分者 等生硬译法 | 字面硬译 | 先写出一句通顺精准的整句，再往英文上对 |
| T7 | 为了逐词对齐把中文拆得不通顺 | 硬对 | 能对就对，不能对就合并成一组；绝不为对齐牺牲通顺 |
| T8 | 读者看不懂"隐形墨水""为什么以为自己隐形" | 缺背景 | 需要背景知识的地方加括号说明（单独一行放在译文正下方） |
| T9 | Detractors 句整句塞一个格子 → 用户要求改回逐词 | 偷懒合并 | 长句优先拆成意群逐词对照，必要时加括号解释句型（如 trace A to B） |
| T10 | 用户审定的译法和我的译法不同 | — | **用户亲自给出的译法一律优先**，原样采用，只统一标点 |
| T11 | 重点词漏标（accomplice、ink、invisible、calls for、link、roughly） | 只标了原文加粗词 | 用户点名的词立即加为重点词，同步到视频/文本/文章/速查表 |
| T13 | "half as strong as" 下面单放"……的一半"，整句读不通 | 比较/倍数结构（half as…as、twice as…as、more than…）英中语序相反，硬拆 | **比较/倍数结构必须和被比较的对象合成一组**，中文从头到尾连读要通顺；先写整句再对齐 |
| T14 | depend on 只给 depends 上了色，on 没上色 | 被其他词隔开的短语（depends partly on、take…into account 等）只标了一半 | **不连续短语两部分都要加粗、同色**：en 写 `**depends** partly **on**`，zh 写 `**取决于**(depends on)`；程序 unify_colors 自动让两部分同色，速查表按完整短语 depend on 列出 |
| T15 | 用户在同一句上连续多次改译（raw link 句改了 5 次） | 初稿没先写通顺整句、没想清"关联性"指什么 | 涉及抽象概念（关联性、相关性、强度）时，译文要统一用词（全篇统一"关联性"），并在括号里说明指的是什么和什么之间的关系 |
| T16 | 数字说明算错（"下降 2/3"却写"剩 40%"） | 照抄未核算 | 括号里的数字一律核算：下降 2/3 → 剩约 33% |
| T12 | 新加重点词与其他篇撞词（invisible↔06、roughly↔15/26、shrank↔23/61、high achievers 的 high↔21、a few dozen 的 few↔46） | 加词前没查全部文章 | **【用户定的保留/去掉规则】新加的重点词（含短语里任何一个实词、含同根词），只要在其他篇加粗过，一律直接去掉，并提醒用户；文章原稿自带的旧撞词保留不动。用户明确点名要保留的（如第02篇 a few dozen），写进脚本的 `allow_clash` 例外名单。** `check_all.py` 已自动检查（对比原稿 fc50170），撞词即报错 |

## 五、声音与停顿

| # | 出过的问题 | 原因 | 以后怎么防 |
|---|---|---|---|
| A1 | 句尾"电磁音" → 误把 cameras 的 /z/ 尾音切掉 | 把真实擦音当杂音 | 句尾只去 <0.05s、低于峰值 25dB、且与语音有间隔的杂点 |
| A2 | 背景"电子声波音" | Kokoro 在 4800/9600Hz 有固定音调 | AF 陷波去除（保留在 B 方案里） |
| A3 | 声音沙哑、音质不高 | Fenrir 占 50%；6.5kHz −4dB 发闷；24kHz | **B 方案**：Michael75%+Fenrir25%、0.95、去压低、轻补偿、48kHz、AAC |
| A4 | 行与行之间停顿太多，像机器人 | 每行单独合成+固定 0.6s | **整句连贯合成**，只在 , ; : 处停 0.6s，行间不停 |
| A6 | 第01篇 "ink," 结尾的 /k/ 音被切掉 | 去尾程序把"闭塞停顿后的短爆破音"（k/t/p，约 0.03s）当成杂点删掉 | 去尾只删与语音间隔 ≥0.25s 的孤立杂点；**k/t/p/s/z 等词尾辅音一律不能切**；每次生成后扫描所有片段，确认去尾报告为空 |
| A7 | B 方案仍有一点沙哑颗粒感；试过 D（压高频）结果**发闷**，用户否决 | D 把 10kHz 以上切掉、7kHz 压 3dB，声音失去亮度 | **用户定：原声（B）什么都不改，只加一道轻降噪 `afftdn=nf=-40:nr=4` 去颗粒感**（F 方案）。以后调声音只做最小改动，不动音色和亮度 |
| A5 | 停顿参数多次调整 | — | 定稿：标点 0.6s；句号 0.7+0.3=1.0s；段间再 +0.5s；标题后 1.2s |
