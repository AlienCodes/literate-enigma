# 视频与音频硬性条件（每支视频、每篇文章必须全部满足）

> 用户原话："音频的质量是我们的精髓……坚决不能出现任何瑕疵……以后做任何的音频和视频都要严格按照我们的硬性条件来。踩过的坑坚决不能再犯。"
> 开工前通读本页和《踩坑总表》；交付前逐条打勾。任何一条不满足，不得交付。

## 一、音频（最高优先级）
1. **零瑕疵**：每一个词、每一句都要清晰、自然、好听、专业；不能有发闷、发哑、电流声、断续、吞音、尾音被切（如 ink 的 /k/）。
2. **音色**：Kokoro，am_michael 75% + am_fenrir 25%（voice_mb.npy），语速 0.95；后期 F 方案（AF.txt：B 原声 + 轻降噪，去 4800/9600 Hz 电流音）。不得私自改动。
3. **读得连贯，不能卡顿**：词与词之间绝不能出现人为停顿（A9：adds | context）。停顿只能落在标点处，位置用带时长输出的同版模型精确定位（只取时间，声音仍用原模型），并逐处核对。
   **词尾必须完整（A10）**：拉长停顿时只能删真正听不见的部分（比最响处低 45 dB 以上），绝不能删词尾的 s/f/z/t/k 等弱音；实际听到的停顿必须正好等于标准。每次出片前运行 `python3 视频/工具/标点停顿核对.py NN`，全部 OK 才能出片。
   **整句一次合成**：不得在逗号处切开分段合成（会让逗号后开头发闷，A8）。逗号停顿只把模型的自然停顿换成标准时长。
4. **停顿标准（每次生成视频必须严格按此表，程序常量 P_COMMA/P_LIST/P_HOLD/P_LEAD/P_PARA_EXTRA/P_TITLE/P_FIRST 与此表一致）**：

   | 位置 | 时长 |
   |---|---|
   | 普通逗号（, ; :） | 0.4 秒 |
   | 牛津逗号列举内的逗号（A, B, and C） | 0.2 秒 |
   | 行与行之间（无标点） | 不停，整句连读 |
   | 句号（同段内） | 共 1.0 秒：读完 0.7 秒 → 换屏 → 0.3 秒开读 |
   | 段与段 | 共 1.2 秒：读完 0.7 秒 → 换屏 → 0.5 秒开读 |
   | 标题 → 正文 | 读完 0.6 秒 → 换屏 → 0.4 秒开读 |
   | 片尾 | 2 秒 |

5. **只朗读英文原文**：`{{…}}` 注解、`{{=}}` 等标记一律不读。
6. **自动音频检查**：每支视频生成后必须运行 `python3 视频/工具/audio_qc.py NN.mp4` 全部通过（削波、4800/9600 Hz 电流音、片中停顿超长、某句响度骤降）；出片程序找不到逗号处自然停顿时直接停止，不允许退回分段合成。
7. **逐句试听检查**：每次定稿前，疑似发闷、断续、读音不准的地方，必须做成短试听交用户确认；程序检测只作辅助，不能代替人耳。

## 二、翻译
1. 精准、地道、通顺；先写通顺整句，再逐词对齐，绝不为对齐牺牲通顺。
2. **用户亲自给出的译法一律优先，原样采用。**
3. 不添加原文没有的信息（需要补充的放括号，且要用户认可）。
4. 重点词中文词性 = 英文词性（adj→…的，adv→…地）；方向（before/after 等）逐个核对。
5. 比较/倍数结构与被比较对象合成一组；不连续短语两部分都加粗同色。
6. 需要背景知识的地方加括号说明（单独一行，在译文正下方）。

## 三、英文原文与重点词
1. 英文原文一个字不改，**唯一例外：牛津逗号**——三项及以上并列，and/or 前一律加逗号。
2. 用户点名的词立即加为重点词；新加重点词（含同根、同形、短语里的实词）若在别篇加粗过，**不加并提醒用户**；用户坚持则写入 `allow_clash`。
3. 每个英文重点词都有中文标记，速查表补齐"本文义 + 词性 + 词义 + 例子"。

## 四、画面
1. 16:9；每句一屏；英文在上，中文在正下方逐词对照，重点词中英同色，中文重点词两侧留小间隙。
2. **换行必须经用户同意**：不得擅自加、改、删换行；改完与用户上次看过的版本逐句比对换行。已定稿篇目全片逐像素不变。
3. 锁定换行后每屏字号铺满（宽 ≤1860、高 ≤1020、上限 100 号），中文 = 英文 × 0.72；括号注释计入宽度；数字、英文不拆行。
4. 片头：拼字版「朋克英语」标志 + 约 1.5 秒入场动画；**视频不写篇号**；「朋克英语」只出现在片头。
5. 修改阶段出 1080p 草稿；用户确认后才出 4K 定稿。
