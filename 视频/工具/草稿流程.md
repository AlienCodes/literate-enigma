2. **读音待核实**：人名、地名、机构名、缩写、生僻词逐个查权威来源（词典、维基百科音标、官方读法，可用 WebSearch）。**只许用** `python3 $T/发音词典/写入.py 表名 'JSON'` 写（几篇同时做，直接改 json 会互相覆盖）：

   - 读错的：`读音改正` `{"词":{"读音":"…","配音原来读作":"…","依据":"…"}}` 加 `已核实读音` 判定“改正后正确”；改了读音就要重跑草稿声音。
   - 多音词：`多音词核对` 键 `"NN S# 词"`，值含 `语境`、`正确读音`、`判定":"正确"`、`整句音标`（照读音核对输出里“整句：/…/”原样抄）。
   - 只在某个语境读错的（过去式 read、名词/动词不同读音）：写 `发音词典/按语境读音.json`（键是能定词性的词组，值 {"词","读音","依据"}，用 Edit 加一条），再写这一句的多音词核对（A35）。
   - 连字符复合词（Haber-Bosch）读错：复合词整个登记进读音改正；全大写缩写的所有格程序自动补 s（A36）。
   - 全片美式口音；读音核对问题数 0 才能往下。
3. **纯人声疑点（交人看的）**：先看摘要：`python3 -c` 读 `dossier_NN.json` 每条一行（id、句、类型、位置、w 起止、dB、重心 C、周期 P、低频 L、附近的词）；必要时 `python3 $T/逐段看声音.py NN S# 起 止`（**w 里的秒**）或直接读 `work_NN/a.wav` 看 10 ms 响度和重心。判定标准：
   - **是词的一部分（保留，写确认）**：塞音除阻（p t k b d g，常在闭塞静音之后、短于 60 ms）、擦音（f s z v θ ʃ，重心 >4 kHz 的一定是擦音不是呼吸）、元音的气声/嘎裂收尾（连着元音、没有 -55 dB 低谷断开）、词头起始浊音（ð w d 等，周期高或低频重）。
   - **不是词（删）**：吸气声（重心约 1.8–3.8 kHz、低频 < -10 dB、周期 < 0.35，常在停顿后或两个词之间）、孤立的低频噗声（前后有 -55 dB 低谷与词隔开）。删由程序切：`ONLY=S# BREATH_FRAC=0.6 python3 $T/自动切点.py NN --写入`（已用实际声音确认是噗声、不像呼吸的才用 BREATH_FRAC=0）；切点只能在最深低谷/过零点，程序会用出片程序的守门自检。
   - 写“词的一部分”确认：键用 dossier 的 `f"{t0:.2f}–{t1:.2f}s"`，值 `{"配音指纹": work_NN/a.wav 的 md5 前 12 位, "依据": "2026-10-16 … （S# w a–bs，类型）：理由"}`，依据里必须带 `S# w a–bs`（确认按位置迁移.py 靠它在重建后自动迁移）。写在 scripts/NN.json 的 核对确认.非人声（也同步进 genNN 不必要，生成程序会保留脚本里已有的确认）。
   - 拿不准就**不写确认、不硬切**，停下来在最后报告里写明。
4. 每改一次：`bash $T/快速重建核查.sh NN | grep -E "问题数|停止"; python3 $T/疑点清单.py NN >/dev/null; python3 $T/确认按位置迁移.py NN`，直到 纯人声 0、标点停顿 0、句间停顿 0；`python3 $T/词尾辅音核对.py NN | tail -1` 为 0（不为 0 用 `--写入`）。
   - `--写入` 放不下（守门停“词尾除阻的位置不对”，说话人把 /t/ 连到下一个词）：在脚本写 `"停顿处除阻":{"S#":{"第几个标点":[p,q,"t"]}}`（w 的秒：p = 闭塞里、前 5 ms < -40 dB；q = 弱除阻之后、下一个词开口之前的最低处；[p,q) 全 < -30 dB），见 A39。
   - 报“多余的移植”：删掉 词尾除阻 里那一条再重跑（A41）。
5. `python3 $T/交付核查.py NN 出片前 | grep -E "✘|BAD|全部通过"`：

   - 插入点在词里、而两词之间没有低谷（/z/ 直接连 /s/、除阻直接连元音，交界处约 -20 dB）：写 `"停顿插入点":{"S#":{"第几个标点":[秒,"交界"]}}`（w 的秒 = 用逐段看声音分频段量出的两词交界），再写 核对确认.停顿位置（A42）；交界处已经 ≤ -24 dB 或是低谷的，照旧写一个秒数。
