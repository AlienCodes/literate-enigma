# 标定与试算工具（L14 高亮同步）

- `dry_timeline.py`：与出片程序完全相同的配音和时间表，只是不画图、不压视频，写到 `dry_NN/`（几分钟就能试算一篇的高亮时间）。用法：在视频工作目录 `python3 dry_timeline.py scripts/NN.json`，再 `HL_WORK=dry python3 工具/高亮同步核对.py NN`。
- `hl_calib.py`、`hl_calib2.py`：2026-10-08 标定"每一块开始读"的几种算法（音素开头、空格开头、局部对齐、停顿后开口）与独立对齐的差别；结果和 12 处实际声音核实见 `视频/音频核对/高亮时间标定_L14.txt`，原始输出在 `视频/音频核对/高亮标定原始数据/`。
