# 视频制作标准（以第01篇为定稿样板）

所有70篇视频一律按本标准制作。参数已写死在 `工具/` 下的脚本里。

## 一、画面
- 16:9，1920×1080，30fps；背景深绿渐变（上 #0E241E → 下 #143028）。
- **一句话一屏**；一句按意群拆成上/中/下几行（chunk），跟读高亮：正在读的行亮，其余行变暗。
- **逐词对照**：每个英文词/词组正下方放它的中文；能逐词对准就对准，硬对会让中文别扭时就合并成一组。中文从左到右连起来读，必须是一句通顺精准的整句。
- 手动换行：在 align 里插入 `["\n",""]` 强制换行（如 "In fairness," 单独一行、"and Wheeler" 单独一行）。
- **字号**：保持既定换行不变，每一屏把字放到最大铺满屏幕（宽 ≤1860、高 ≤1020），上限 100 号；中文字号 = 英文 × 0.72。
- 中文数字/英文（如 1999）不拆行。
- 正文页**不显示**顶部标题。
- 重点词：英文与中文**同色**，按首次出现顺序循环 8 色调色板；重点短语整体上色（rubbed on、devoid of、calls for…）。
- 括号说明 `note`：单独一行放在该行译文正下方，浅灰绿；"另译"用**黄字**（note 以 `#Y` 开头）。

## 二、标题页
- 全部居中。顶部青绿小标签"考研英语精读 · No.XX"，两侧细线。
- 英文标题超粗体、尽量大（最多 3 行），暖白色。
- 每篇挑最有画面感的词做特效（`title_fx`）：`hl` = 柠檬黄→橙渐变+发光；`ghost` = 从左到右渐隐、碎成光点。
- 中文标题：明黄色圆角长方形色块（小圆角，非胶囊形），深色超粗体，文字在色块内上下左右居中。
- 背景：中央柔光 + 右下角半透明大号篇号水印。

## 三、声音
- 男声美音：Kokoro `am_michael` 与 `am_fenrir` 各 0.5 混合（voice_mf.npy），语速 0.92。
- 去电流声：4800/9600 Hz 陷波 + 高通 60Hz + 低通 10.5kHz（AF.txt）；句尾只去掉极短的低能量杂点，不切真实的 s/z 尾音。

## 四、停顿
| 位置 | 时长 |
|---|---|
| 片头静音 | 0.4 秒 |
| 标题读完 → 正文 | 1.2 秒 |
| 逗号处（行与行之间、行内逗号） | **0.6 秒** |
| 句号：读完静止 → 切下一屏 → 静止 → 开读 | **0.7 + 0.3 = 1.0 秒** |
| 段与段之间 | 在 1.0 秒基础上再加 0.5 秒 |
| 片尾 | 0.8 秒 |

## 五、翻译标准
- 精准、地道、通顺三原则；不得添加原文没有的信息。
- 重点词中文**词性必须与英文一致**：形容词"……的"、副词"……地"、名词译名词。
- 用户亲自审定的译法优先（见 `scripts/01.json`）。

## 六、交付物（每篇）
- `视频/NN.mp4`
- `对照文本/NN-文本.docx`（可编辑，配色与视频一致）、`.html`、`.pdf`
- `脚本/NN.json`（逐词对照数据）

## 七、资源（配音模型与字体）
- `资源/模型/`：Kokoro 模型（拆成 4 段，每段 <100MB）、音色库、混合音色 voice_mf.npy
- `资源/字体/`：Inter.ttf、NotoSansSC.ttf
- 还原：`bash 视频/资源/还原.sh <目录>`（自动合并、校验 SHA256、安装依赖）
