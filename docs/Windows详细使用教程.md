# 声音分身 VoiceTwin —— Windows 详细使用教程

这份教程从零开始，一步一步带你完成：**下载 → 安装 → 放入你的讲课视频 → 训练你的声音 → 用你的声音生成讲课音频**。
每一步都写了"要点哪里、会看到什么、看到什么算成功"。第一次完整走完大约需要 **2~3 个小时**，其中大部分时间是电脑在自动下载和训练，你只需要等。

以后日常使用只需要：**双击桌面图标 → 粘贴讲稿 → 点"生成"**。

> ⚡ 只想最快用起来：先看仓库首页的 [**快速上手**](../快速上手.md)（10 分钟看完）。
>
> 📘 想看带截图、更详细的版本：请打开 `VoiceTwin\docs` 文件夹里的 **《声音分身VoiceTwin使用手册.pdf》**（约 80 页，含界面截图、讲稿写法、剪映配音、盲测方法和 40 多个常见问题），
> 也可以在 [Releases 页面](https://github.com/AlienCodes/literate-enigma/releases/latest) 单独下载。

## 第 0 步：确认电脑配置，准备解压软件

### 0.1 看看你的显卡

1. 同时按下键盘上的 **Ctrl + Shift + Esc**，打开"任务管理器"。
2. 如果窗口很小，点左下角的 **"详细信息"**。
3. 点上方（或左侧）的 **"性能"**。
4. 在左边列表里找到 **"GPU"**，点它。
5. 看右上角的显卡名称，以及下方的 **"专用 GPU 内存"**：
   - 名称里有 **NVIDIA**（例如 NVIDIA GeForce RTX 3060），并且专用 GPU 内存 **≥ 6 GB**：✅ 可以。
   - 8 GB 以上更好，训练更快。
   - 只有 Intel / AMD 显卡、或者没有独立显卡：也能运行，但训练会非常慢（可能要几天）。建议换一台有 NVIDIA 显卡的电脑来训练；训练好后，生成音频对显卡要求低一些。

### 0.2 看看硬盘空间

打开"此电脑"，选一个空间大的盘（下面都以 **D 盘** 为例），确认剩余空间 **≥ 30 GB**。
如果你没有 D 盘，下面所有 `D:\` 都换成你自己的盘符，比如 `E:\`。

### 0.3 更新显卡驱动（建议）

打开 NVIDIA 官网驱动下载页 <https://www.nvidia.cn/drivers/lookup/>，按你的显卡型号下载最新驱动并安装。驱动太旧可能导致训练报错。

### 0.4 安装解压软件 7-Zip

GPT-SoVITS 整合包是 `.7z` 格式，需要 7-Zip 来解压：

1. 打开 <https://www.7-zip.org/>。
2. 点第一行的 **Download**（64-bit Windows x64）。
3. 双击下载好的安装包，点 **Install**，装好后点 **Close**。

## 第 1 步：下载声音分身 VoiceTwin

1. 用浏览器打开：**<https://github.com/AlienCodes/literate-enigma/releases/latest>**
2. 页面往下拉，找到 **"Assets"**（资源）这一栏。如果它是折叠的，点一下展开。
3. 点 **`VoiceTwin-Windows-v0.1.0.zip`**（版本号可能更新），浏览器开始下载。文件不大，几十秒就好。
4. 下载完成后，打开"下载"文件夹（浏览器下载栏里点"在文件夹中显示"）。
5. 在 `VoiceTwin-Windows-v0.1.0.zip` 上 **点右键 → "全部解压缩..."**（Windows 11 可能要先点"显示更多选项"）。
6. 在弹出的窗口里，把路径改成 **`D:\`**，然后点 **"提取"**。
7. 打开 D 盘，你会看到一个 **`VoiceTwin`** 文件夹，也就是 **`D:\VoiceTwin`**。
8. 打开它，确认里面有这些文件：`install_windows.bat`、`install_windows.ps1`、`使用教程（先看我）.html`、`voicetwin` 文件夹等。

> 💡 GitHub 在国内有时打不开或很慢，可以多刷新几次，或换个时间再试。

## 第 2 步：下载 GPT-SoVITS 整合包

GPT-SoVITS 是目前最成熟的开源声音克隆工具，VoiceTwin 用它来训练你的声音。官方提供了 Windows "整合包"，里面已经装好了所有复杂的组件。

### 2.1 下载

1. 打开 GPT-SoVITS 官方文档的下载页：
   **<https://www.yuque.com/baicaigongchang1145haoyuangong/ib3g1e/dkxgpiy9zb96hob4#KTvnO>**
   （海外可用：<https://huggingface.co/lj1995/GPT-SoVITS-windows-package/tree/main>）
2. 在"整合包"部分，下载 **最新版**。认准两点：
   - 文件名里带 **`v2pro`**（或者比 v2pro 更新的版本号）；
   - 日期最新。
   - 如果你的显卡是 **RTX 50 系列**，而页面上有专门的 50 系版本（文件名带 `50` 或 `nvidia50` 字样），就选那个。
3. 文件有好几个 GB，下载需要一些时间，耐心等待。

### 2.2 解压

1. 在下载好的 `.7z` 文件上 **点右键 → 7-Zip → "提取到 "文件名\""**（Windows 11 要先点"显示更多选项"）。
2. 解压完成后得到一个文件夹，例如 `GPT-SoVITS-v2pro-2025xxxx`。
3. 把这个文件夹 **重命名为 `GPT-SoVITS`**，然后 **剪切到 D 盘根目录**，最终路径是 **`D:\GPT-SoVITS`**。

### 2.3 检查

打开 `D:\GPT-SoVITS`，**直接**能看到下面这些东西，就说明放对了：

- `go-webui.bat`
- `api_v2.py`
- `runtime` 文件夹
- `GPT_SoVITS` 文件夹

> ⚠️ 常见错误是多了一层文件夹，比如 `D:\GPT-SoVITS\GPT-SoVITS-v2pro-xxxx\go-webui.bat`。遇到这种情况，把里面那层的所有内容移到外面来。安装程序也会尝试自动找到里面那层。
>
> ⚠️ 路径里 **不要有中文和空格**。`D:\GPT-SoVITS` 可以，`D:\新建文件夹\GPT SoVITS` 不行。

## 第 3 步：运行安装程序

1. 打开 `D:\VoiceTwin`，**双击 `install_windows.bat`**。
2. 如果弹出蓝色窗口 **"Windows 已保护你的电脑"**：点 **"更多信息"**，再点 **"仍要运行"**。
   如果杀毒软件（360、火绒等）弹出拦截提示，选择 **"允许"** 或 **"信任"**。
3. 出现一个黑色窗口，显示：
   ```
   请选择安装方式：
     1) 推荐：安装到 GPT-SoVITS 整合包里 ……
     2) 独立安装 ……
   请输入 1 或 2，然后按回车
   ```
   输入 **`1`**，按 **回车**。
4. 接着让你输入 GPT-SoVITS 整合包的路径。输入 **`D:\GPT-SoVITS`**，按 **回车**。
   > 小技巧：打开 `D:\GPT-SoVITS` 文件夹，点窗口顶部的地址栏，按 Ctrl+C 复制路径，再回到黑色窗口 **点右键** 就能粘贴。
5. 等待 **3~10 分钟**。窗口里会滚动很多英文，这是在下载和安装组件，属于正常现象。**不要关闭窗口。**
6. 最后会出现 **"==> 检查环境"**，下面有一排 ✅ / ⚠️ / ❌：
   - ✅ 正常。
   - ⚠️ 是可选组件，**不用管**。例如"funasr 未安装""demucs 未安装""引擎 Qwen3-TTS""引擎 IndexTTS"都属于这类。
   - ❌ 需要处理。最常见的是 **"引擎 GPT-SoVITS：缺少预训练模型……"**，按下面第 4 步处理即可。
7. 看到 **"安装完成！"** 后，按 **回车** 关闭窗口。
8. 桌面上会多出一个 **"声音分身 VoiceTwin"** 图标，以后双击它就能打开程序。

> 如果双击 `install_windows.bat` 后窗口一闪就没了：在 `install_windows.ps1` 上 **右键 → "使用 PowerShell 运行"**。

## 第 4 步：补齐预训练模型（只在提示缺少时才需要）

较早的整合包没有自带 v2Pro 模型。VoiceTwin 可以自动帮你下载：

1. 打开 `D:\VoiceTwin` 文件夹。
2. 点窗口顶部的 **地址栏**，把里面的文字删掉，输入 **`cmd`**，按 **回车**。会打开一个黑色的"命令提示符"窗口，而且已经位于这个文件夹里。
3. 在黑色窗口里输入下面这行，按 **回车**：
   ```
   voicetwin.bat download-models --source hf-mirror
   ```
4. 等待下载（大约 1~2 GB）。完成后显示 **"✅ 已下载 N 个文件"**。
5. 再输入下面这行，按 **回车**，检查一遍：
   ```
   voicetwin.bat doctor
   ```
   看到 **"✅ 引擎 GPT-SoVITS：就绪"** 就可以了。

> 如果下载一直失败：用记事本打开 `D:\VoiceTwin\config.yaml`，找到 `version: v2ProPlus`，改成 `version: v2`，保存。这样会使用整合包自带的 v2 模型，效果略逊，但不需要下载。

## 第 5 步：整理你的讲课素材

1. 在 D 盘新建一个文件夹：**`D:\讲课素材`**。
2. 把你以前录的讲课**视频或音频**复制进去。支持的格式：
   - 视频：mp4、mov、mkv、avi、flv、webm、wmv、m4v、ts
   - 音频：wav、mp3、m4a、aac、flac、ogg、wma
3. **如果视频有字幕文件**（`.srt`），把它和视频放在一起，并且**文件名相同**，例如：
   ```
   第1课.mp4
   第1课.srt
   ```
   有字幕的话，程序会直接用字幕里的文字，比语音识别更准，效果更好。
4. 挑选素材的原则：
   - ✅ **总时长越多越好**：至少 30 分钟，**1~3 小时最好**。
   - ✅ 你**正常讲课状态**的录音。
   - ✅ 要做英文课的话，一定放入你**讲英文**的录音（至少 5~10 分钟），否则英文会带中文口音。
   - ✅ 如果当初录课有单独保存的原始音频（wav），优先用它，比从视频里提取的质量更好。
   - ❌ **不要放嗓子哑了之后的录音。**
   - ❌ 尽量少放有背景音乐、多人对话、很吵的片段。少量的学生提问没关系，程序会通过声纹自动识别并剔除。

## 第 6 步：打开程序界面

1. 双击桌面上的 **"声音分身 VoiceTwin"**（或者 `D:\VoiceTwin\start_webui.bat`）。
2. 会出现一个黑色窗口，显示"正在启动声音分身……"。**使用期间不要关闭这个黑色窗口**，关掉它程序就停了。
3. 等 10~30 秒，浏览器会自动打开一个网页，地址是 **`http://127.0.0.1:7860`**。
   如果浏览器没有自动打开，就自己打开浏览器，在地址栏输入 `http://127.0.0.1:7860`，按回车。
4. 网页最上面有一个 **"声音名称"** 输入框，下面有几个标签页：
   **① 准备素材 / ② 训练模型 / ③ 生成讲课音频 / ④ 评估相似度 / 环境检查**。

> 这个网页只在你自己的电脑上运行，不需要联网登录，你的声音也不会上传到任何地方。

## 第 7 步：准备素材

1. 在最上面的 **"声音名称"** 框里输入一个名字，例如 **`我的声音`**。以后每次都用这个名字。
2. 确认当前在 **"① 准备素材"** 标签页。
3. 在 **"或者填写电脑上的文件夹路径"** 框里输入 **`D:\讲课素材`**。
   > 也可以用左边的"上传"区域选文件，但视频很大时上传会比较慢，建议直接填文件夹路径。
4. 其它选项：
   - **语音识别引擎**：保持 `faster-whisper`（中英文都支持）。如果你的课全是中文，也可以选 `funasr`（阿里的中文识别模型，中文更准）。
   - **素材语言**：保持 `auto`。
   - **降噪**：保持 `auto`（只在录音明显有噪音时才轻度降噪）。
   - **"视频有背景音乐"**：一般**不勾**。如果你的视频全程有背景音乐，请看[常见问题](#常见问题)里的处理方法。
5. 点橙色的 **"开始准备素材"** 按钮。
6. 下方的 **"运行日志"** 会实时显示进度：
   - `[1/5] 处理 第1课.mp4` —— 正在提取、清理音频，切分句子；
   - `加载识别模型 ……首次使用会自动下载` —— **第一次**会下载语音识别模型（约 3 GB），需要几分钟到十几分钟；
   - `识别 21/800：……` —— 正在把每句话识别成文字；
   - `计算声纹` —— 正在剔除不是你本人的片段。
7. 处理时间参考：1 小时素材，有显卡大约 10~30 分钟。
8. 完成后，日志下方会显示一段摘要，例如：
   ```
   ✅ 素材准备完成：保留 812 / 905 条，共 76.3 分钟
   你的语速：中文 4.62 音节/秒，英文 4.10 音节/秒
   你的停顿习惯：逗号 0.26s / 句号 0.71s / 段落 1.20s
   自动挑选的参考音频：……
   ```
   黄色的 ⚠️ 提示会告诉你素材是否够用，比如"英文素材不足 5 分钟"。

## 第 8 步：校对文字（强烈建议）

语音识别偶尔会听错字。训练素材里的错字，会变成模型的"口误"。花 10~20 分钟校对，效果会明显更好。

1. 在"① 准备素材"页面往下拉，点 **"载入片段列表"**。
2. 下方表格会列出所有片段：
   | 列 | 含义 |
   |---|---|
   | id | 片段编号 |
   | 保留 | ✔ 参与训练，✘ 不参与 |
   | 语言 | zh 中文 / en 英文 |
   | 秒 | 片段时长 |
   | 文字 | 识别出的文字，**可以直接修改** |
   | 丢弃原因 | 程序自动丢弃这一条的原因 |
3. **点击任意一行**，下方的"试听选中的片段"会加载这段录音，点播放键就能听。
4. 发现错字：**双击"文字"那一格**，改成正确的文字，按回车。
5. 某条不是你说的、或者质量很差：把 **"保留"** 那一格改成 **`✘`**（也可以输入 `0`）。
6. 全部改完后，点橙色的 **"保存修改"**。下方会显示"已保存：{'text': 12, 'keep': 3, ...}"，表示改了 12 处文字、3 处保留状态。

> 习惯用 Excel 的话：用 Excel 打开 `D:\VoiceTwin\workspace\我的声音\transcripts.csv`，修改"text"和"keep"两列，保存（保持 CSV 格式）。然后在 `D:\VoiceTwin` 文件夹的地址栏输入 `cmd` 回车，运行 `voicetwin.bat review -v 我的声音`。

## 第 9 步：训练你的声音模型

1. 点上方的 **"② 训练模型"** 标签页。
2. **引擎** 保持 **`gptsovits`**。下面几个数字都保持 **0**，表示全部自动设置。
3. 点橙色的 **"开始训练"**。
4. **"训练日志"** 会依次显示这几个阶段：
   - `1A 文本处理` → `1B 提取 HuBERT 特征与说话人声纹` → `1C 提取语义 token`：准备训练数据；
   - `训练音色模型 SoVITS（共 12 轮）……`，接着不断出现 `gsv_s2_train 进度 25%`、`50%`……：训练音色；
   - `训练语气与节奏模型 GPT（共 15 轮）……`，接着 `gsv_s1_train 进度 20%`……：训练语气和节奏；
   - 每一轮可能要几分钟，进度数字隔一会儿才变一次，这是正常的；
   - `评估模型 s8-g10 ……`：用你没参与训练的真实录音，给每个模型版本打分；
   - 最后显示 **"✅ 训练完成，最佳模型：s12-g15，语速校准：{'zh': 1.02, 'en': 0.98}"**。
5. 训练时间参考：1 小时素材，RTX 3060 约 40~90 分钟，RTX 4090 约 15~30 分钟。
6. 训练期间：
   - **不要关闭黑色窗口，也不要关闭网页。**
   - 把电脑设置成**不自动睡眠**：设置 → 系统 → 电源 → 屏幕和睡眠 → "睡眠"改为"从不"。
   - 电脑会比较卡、风扇会比较响，这是正常的。

> 以后如果增加了素材或重新校对了文字，再点一次"开始训练"即可。

## 第 10 步：生成讲课音频

1. 点上方的 **"③ 生成讲课音频"** 标签页。
2. 在左边的 **"讲稿"** 框里粘贴你的讲稿，或者在下面"或上传讲稿文件"里选择文件（支持 txt、md、srt、docx）。
3. 右边的设置：
   - **引擎**：`gptsovits`。
   - **质量**：
     - `fast`：最快，每句只生成 1 个版本，适合先试听；
     - `balanced`（推荐）：每句生成 3 个版本，自动挑最像的；
     - `best`：每句 5 个版本，还会自动检查漏字、读错，最慢但最好，**正式课程推荐用这个**。
   - **语速倍数**：保持 **1.0**，意思是和你本人的语速一样（程序已经自动校准过）。想整体快一点，可以调到 1.05。
   - **指定参考音频 id**：留空，程序会自动选。
   - **只重新生成第几句**：第一次留空。
4. 点橙色的 **"生成"**。
   - 第一次生成时，需要先启动推理服务，大约多等 1 分钟。
   - 下方日志会显示 `[3/25] 生成 …（相似度 0.87）`。
5. 完成后：
   - **"结果"** 播放器里可以直接试听；
   - **"下载"** 区域有 3 个文件：**音频（.wav）**、**字幕（.srt）**、**报告（.report.json）**；
   - 同样的文件也自动保存在 **`D:\VoiceTwin\workspace\我的声音\outputs\`** 里。
6. 下方表格列出每一句的 **声纹相似度**（越接近 1 越像你）和提示。
7. 某几句不满意时：在 **"只重新生成第几句"** 里填编号，例如 `3,5,8-10`，再点一次 **"生成"**。只会重新生成这几句，其它句子直接用上次的结果，几秒钟就好。

## 第 11 步：把音频放进课程视频

### 用剪映（或其它剪辑软件）

1. 打开剪映，导入你的课程画面（录屏、PPT 视频等）。
2. 把生成的 **`.wav`** 音频拖到音频轨道上。
3. 导入字幕：菜单 **文本 → 本地字幕 → 导入**，选择生成的 **`.srt`** 文件，字幕会自动对齐时间。
4. 导出视频。

### 直接替换视频的音轨（命令行）

在 `D:\VoiceTwin` 文件夹的地址栏输入 `cmd` 回车，然后运行（换成你自己的文件路径）：

```
voicetwin.bat mux --video D:\课程\第3课画面.mp4 --audio D:\VoiceTwin\workspace\我的声音\outputs\第3课.wav -o D:\课程\第3课成品.mp4
```

### 给已有视频按字幕时间轴重新配音

如果你有一个视频和它的 `.srt` 字幕，想按字幕的时间点重新配音：在"③ 生成讲课音频"里**上传这个 `.srt` 文件**作为讲稿。每句话会被放在字幕对应的开始时间上。

## 第 12 步：以后每次怎么用

1. 双击桌面上的 **"声音分身 VoiceTwin"**。
2. 浏览器打开后，在 **"声音名称"** 里选择 **`我的声音`**。

## 讲稿写法速查

```markdown
# 第三课：列表推导式

大家好，今天我们来学习 Python 里面的列表推导式。它可以让代码更简洁。

那么大家想一想，这段代码输出什么？[停顿=2]

Next, let's look at a slightly more complex example.
```

| 写法 | 效果 |
|---|---|
| 空一行 | 段落停顿（按你本人的段落停顿习惯） |
| `[停顿]` | 段落停顿 |
| `[停顿=2]`、`[停顿 1.5秒]`、`[pause=800ms]` | 指定停顿时长 |
| `# 标题` | 标题会被读出来，读完后停顿 |
| ` ``` ` 代码块 ` ``` ` | 默认**不朗读** |
| 中英混写 | 自动识别；整句英文会用你的英文参考音频 |
| 疑问句（？结尾） | 自动使用你问问题时的语气作为参考 |

**纠正读音**：用记事本打开 `D:\VoiceTwin\workspace\我的声音\lexicon.txt`，每行写一条 `原文 => 读法`：

```
SQL => sequel
GPT => G P T
重庆 => 虫庆
行长 => 航长
```

保存后再生成即可。字幕里仍然显示原文。

## 常见问题

**双击 install_windows.bat 后窗口一闪就没了**
在 `install_windows.ps1` 上右键，选 **"使用 PowerShell 运行"**。

**安装时提示"没有找到 ……\runtime\python.exe"**
整合包的路径输错了。打开你的 GPT-SoVITS 文件夹，确认里面**直接**有 `runtime` 文件夹，然后重新运行安装程序，输入正确的路径。

**安装时提示"整合包版本太旧（缺少 api_v2.py）"**
请重新下载最新版的 GPT-SoVITS 整合包。

**下载模型很慢或失败**
程序默认已经使用国内镜像（hf-mirror.com）。如果还是失败：检查网络，换个时间再试；或者在 ① 里把识别引擎换成 `funasr`（它从阿里的 ModelScope 下载，国内速度快）。

**浏览器没有自动打开，或者打开后显示"无法访问此网站"**
确认黑色窗口还开着，而且没有报错；等 30 秒后手动访问 `http://127.0.0.1:7860`。如果提示端口被占用，关闭其它黑色窗口，或者重启电脑后再试。

**训练时报错 "CUDA out of memory"（显存不足）**
用记事本打开 `D:\VoiceTwin\config.yaml`，找到 `batch_size: auto`（在 `gptsovits` → `train` 下面），改成 `batch_size: 2`（还不行就改成 `1`），保存后重新训练。GTX 10 系列等较老的显卡，还需要把 `is_half: true` 改成 `is_half: false`。

**生成时提示"GPT-SoVITS 推理服务启动失败"**
打开 `D:\VoiceTwin\workspace\我的声音\logs\gptsovits_api.log`，看最后几行的报错。常见原因是模型文件不全（运行第 4 步）或显存被其它程序占用（关掉游戏、其它 AI 软件）。

**提示"找不到 GPT-SoVITS 目录"**
你移动过 GPT-SoVITS 的文件夹。重新运行一次 `install_windows.bat`，输入新的路径即可（其它设置会保留）。

**声音不够像**
按效果从大到小排列：
1. 增加素材（30 分钟 → 1~3 小时）；
2. 校对文字（第 8 步）；
3. 检查素材是否干净，把嗓子哑之后的录音删掉；
4. 生成时用 `best` 质量；
5. 在 `workspace\我的声音\references.json` 里挑一条语气最满意的参考音频，把它的 id 填到"指定参考音频 id"；
6. 重新训练。

**某个字总是读错**
写进 `lexicon.txt`，见[讲稿写法速查](#讲稿写法速查)。

**英文有中文口音**
加入你讲英文的录音，重新运行 ① 和 ②。

**视频里全程有背景音乐**
先用 GPT-SoVITS 整合包自带的人声分离工具去掉背景音乐：双击 `D:\GPT-SoVITS\go-webui.bat`，在打开的页面里找到 **"UVR5 人声伴奏分离"**，把视频的音频分离出人声，再把分离出的人声文件放进 `D:\讲课素材`。

**我移动了 VoiceTwin 文件夹**
重新运行一次 `install_windows.bat`（会重新生成启动脚本和桌面图标），`workspace` 里的数据都在，不受影响。

**想看更详细的错误信息**
每一步的日志都在 `D:\VoiceTwin\workspace\我的声音\logs\` 里。也可以在命令行里加 `--verbose` 运行，例如 `voicetwin.bat narrate -v 我的声音 讲稿.txt --verbose`。

**怎么卸载**
1. 在 `D:\VoiceTwin` 地址栏输入 `cmd` 回车，运行 `D:\GPT-SoVITS\runtime\python.exe -m pip uninstall voicetwin`；
2. 删除 `D:\VoiceTwin` 文件夹（注意：`workspace` 里有你训练好的模型和生成的音频，需要的话先备份）；
3. 删除桌面图标。
