# 声音分身 VoiceTwin —— Windows 详细使用教程

> ⚠️ **这份长教程停在 v18.1 以前，不再更新**（里面的表格样子、按钮和现在的界面不一样，也没有「一键全部文字校正」）。请看最新的 [**快速上手**](../快速上手.md)。

这份教程从零开始，一步一步带你完成：**下载 → 安装 → 放入你的讲课视频 → 训练你的声音 → 用你的声音生成讲课音频**。
每一步都写了"要点哪里、会看到什么、看到什么算成功"。第一次完整走完大约需要 **2~3 个小时**，其中大部分时间是电脑在自动下载和训练，你只需要等。

以后日常使用只需要：**双击桌面图标 → 粘贴讲稿 → 点"生成"**。

> 🔄 **从旧版本升级**：下载新的 `VoiceTwin-Windows-v….zip`，解压到 `D:\`（提示同名文件时选"替换"），再双击 `install_windows.bat` 输入 `1` 和整合包路径重新装一次。
> 你的声音、校对和训练好的模型都在 `workspace` 文件夹里，**不会丢**。

> ⚡ 只想最快用起来：先看仓库首页的 [**快速上手**](../快速上手.md)（10 分钟看完）。

## 第 0 步：确认电脑配置，准备解压软件

### 0.1 看看你的显卡

1. 同时按下键盘上的 **Ctrl + Shift + Esc**，打开"任务管理器"。
2. 如果窗口很小，点左下角的 **"详细信息"**。
3. 点上方（或左侧）的 **"性能"**。
4. 在左边列表里找到 **"GPU"**，点它。
5. 看右上角的显卡名称，以及下方的 **"专用 GPU 内存"**：
   - 名称里有 **NVIDIA**（例如 NVIDIA GeForce RTX 3060），并且专用 GPU 内存 **≥ 6 GB**：✅ 可以。
   - 8 GB 以上更好，训练更快。
   - 只有 Intel / AMD 显卡、或者没有独立显卡：也能运行，但训练会非常慢（可能要几天）。建议换一台有 NVIDIA 显卡的电脑来训练；训练好后，生成音频对显卡要求低一些。

### 0.2 看看硬盘空间

打开"此电脑"，选一个空间大的盘（下面都以 **D 盘** 为例），确认剩余空间 **≥ 30 GB**。
如果你没有 D 盘，下面所有 `D:\` 都换成你自己的盘符，比如 `E:\`。

### 0.3 更新显卡驱动（建议）

打开 NVIDIA 官网驱动下载页 <https://www.nvidia.cn/drivers/lookup/>，按你的显卡型号下载最新驱动并安装。驱动太旧可能导致训练报错。

### 0.4 安装解压软件 7-Zip

GPT-SoVITS 整合包是 `.7z` 格式，需要 7-Zip 来解压：

1. 打开 <https://www.7-zip.org/>。
2. 点第一行的 **Download**（64-bit Windows x64）。
3. 双击下载好的安装包，点 **Install**，装好后点 **Close**。

## 第 1 步：下载声音分身 VoiceTwin

1. 用浏览器打开：**<https://github.com/AlienCodes/literate-enigma/releases/latest>**
2. 页面往下拉，找到 **"Assets"**（资源）这一栏。如果它是折叠的，点一下展开。
3. 点 **`VoiceTwin-Windows-v0.1.0.zip`**（版本号可能更新），浏览器开始下载。文件不大，几十秒就好。
4. 下载完成后，打开"下载"文件夹（浏览器下载栏里点"在文件夹中显示"）。
5. 在 `VoiceTwin-Windows-v0.1.0.zip` 上 **点右键 → "全部解压缩..."**（Windows 11 可能要先点"显示更多选项"）。
6. 在弹出的窗口里，把路径改成 **`D:\`**，然后点 **"提取"**。
7. 打开 D 盘，你会看到一个 **`VoiceTwin`** 文件夹，也就是 **`D:\VoiceTwin`**。
8. 打开它，确认里面有这些文件：`install_windows.bat`、`install_windows.ps1`、`使用教程（先看我）.html`、`voicetwin` 文件夹等。

> 💡 GitHub 在国内有时打不开或很慢，可以多刷新几次，或换个时间再试。

## 第 2 步：下载 GPT-SoVITS 整合包

GPT-SoVITS 是目前最成熟的开源声音克隆工具，VoiceTwin 用它来训练你的声音。官方提供了 Windows "整合包"，里面已经装好了所有复杂的组件。

### 2.1 下载

1. 打开 GPT-SoVITS 官方文档的下载页：
   **<https://www.yuque.com/baicaigongchang1145haoyuangong/ib3g1e/dkxgpiy9zb96hob4#KTvnO>**
   （海外可用：<https://huggingface.co/lj1995/GPT-SoVITS-windows-package/tree/main>）
2. 在"整合包"部分，下载 **最新版**。认准两点：
   - 文件名里带 **`v2pro`**（或者比 v2pro 更新的版本号）；
   - 日期最新。
   - 如果你的显卡是 **RTX 50 系列**，而页面上有专门的 50 系版本（文件名带 `50` 或 `nvidia50` 字样），就选那个。
3. 文件有好几个 GB，下载需要一些时间，耐心等待。

### 2.2 解压

1. 在下载好的 `.7z` 文件上 **点右键 → 7-Zip → "提取到 "文件名\""**（Windows 11 要先点"显示更多选项"）。
2. 解压完成后得到一个文件夹，例如 `GPT-SoVITS-v2pro-2025xxxx`。
3. 把这个文件夹 **重命名为 `GPT-SoVITS`**，然后 **剪切到 D 盘根目录**，最终路径是 **`D:\GPT-SoVITS`**。

### 2.3 检查

打开 `D:\GPT-SoVITS`，**直接**能看到下面这些东西，就说明放对了：

- `go-webui.bat`
- `api_v2.py`
- `runtime` 文件夹
- `GPT_SoVITS` 文件夹

> ⚠️ 常见错误是多了一层文件夹，比如 `D:\GPT-SoVITS\GPT-SoVITS-v2pro-xxxx\go-webui.bat`。遇到这种情况，把里面那层的所有内容移到外面来。安装程序也会尝试自动找到里面那层。
>
> ⚠️ 路径里 **不要有中文和空格**。`D:\GPT-SoVITS` 可以，`D:\新建文件夹\GPT SoVITS` 不行。

## 第 3 步：运行安装程序

1. 打开 `D:\VoiceTwin`，**双击 `install_windows.bat`**。
2. 如果弹出蓝色窗口 **"Windows 已保护你的电脑"**：点 **"更多信息"**，再点 **"仍要运行"**。
   如果杀毒软件（360、火绒等）弹出拦截提示，选择 **"允许"** 或 **"信任"**。
3. 出现一个黑色窗口，显示：
   ```
   请选择安装方式：
     1) 推荐：安装到 GPT-SoVITS 整合包里 ……
     2) 独立安装 ……
   请输入 1 或 2，然后按回车
   ```
   输入 **`1`**，按 **回车**。
4. 接着让你输入 GPT-SoVITS 整合包的路径。输入 **`D:\GPT-SoVITS`**，按 **回车**。
   （如果它已经自己找到了，会显示 **"找到了整合包：D:\GPT-SoVITS（直接按回车用它……）"**，直接按 **回车** 就行。）
   > 小技巧：打开 `D:\GPT-SoVITS` 文件夹，点窗口顶部的地址栏，按 Ctrl+C 复制路径，再回到黑色窗口 **点右键** 就能粘贴。
5. 等待 **3~10 分钟**。窗口里会滚动很多英文，这是在下载和安装组件，属于正常现象。**不要关闭窗口。**
6. 最后一步是 **"检查环境"**，会列出一排带编号的 ✅ / ⚠️ / ❌：
   - ✅ 正常。
   - ⚠️ 是可选组件，**不用管**。例如"funasr 未安装""demucs 未安装""引擎 Qwen3-TTS""引擎 IndexTTS"都属于这类。
   - ❌ 需要处理。最常见的是 **"引擎 GPT-SoVITS：缺少预训练模型……"**，按下面第 4 步处理即可。
7. 看到 **"✅ 安装成功！"** 后，它会问 **"现在就打开声音分身吗？"**：直接按 **回车** 就会打开程序（输入 `N` 再按回车 = 先不打开）。
   如果显示的是 **"⚠️ 程序已经装好，但还有问题要先处理"**，看上面标着 ❌ 的行，按提示处理后再双击 `install_windows.bat` 检查一次（数据不会丢）。
8. 桌面上会多出一个 **"声音分身 VoiceTwin"** 图标，以后双击它就能打开程序。

> 如果双击 `install_windows.bat` 后窗口一闪就没了：在 `install_windows.ps1` 上 **右键 → "使用 PowerShell 运行"**。

## 第 4 步：补齐预训练模型（只在提示缺少时才需要）

较早的整合包没有自带 v2Pro 模型。VoiceTwin 可以自动帮你下载：

1. 打开 `D:\VoiceTwin` 文件夹。
2. 点窗口顶部的 **地址栏**，把里面的文字删掉，输入 **`cmd`**，按 **回车**。会打开一个黑色的"命令提示符"窗口，而且已经位于这个文件夹里。
3. 在黑色窗口里输入下面这行，按 **回车**：
   ```
   voicetwin.bat download-models --source hf-mirror
   ```
4. 等待下载（大约 1~2 GB）。完成后显示 **"✅ 已下载 N 个文件"**。
5. 再输入下面这行，按 **回车**，检查一遍：
   ```
   voicetwin.bat doctor
   ```
   看到 **"✅ 引擎 GPT-SoVITS：就绪"** 就可以了。

> 如果下载一直失败：用记事本打开 `D:\VoiceTwin\config.yaml`，找到 `version: v2ProPlus`，改成 `version: v2`，保存。这样会使用整合包自带的 v2 模型，效果略逊，但不需要下载。

## 第 5 步：整理你的讲课素材

1. 在 D 盘新建一个文件夹：**`D:\讲课素材`**。
2. 把你以前录的讲课**视频或音频**复制进去。支持的格式：
   - 视频：mp4、mov、mkv、avi、flv、webm、wmv、m4v、ts
   - 音频：wav、mp3、m4a、aac、flac、ogg、wma
3. **如果视频有字幕文件**（`.srt`），把它和视频放在一起，并且**文件名相同**，例如：
   ```
   第1课.mp4
   第1课.srt
   ```
   有字幕的话，程序会直接用字幕里的文字，比语音识别更准，效果更好。
4. 挑选素材的原则：
   - ✅ **总时长越多越好**：至少 30 分钟，**1~3 小时最好**。
   - ✅ 你**正常讲课状态**的录音。
   - ✅ 要做英文课的话，一定放入你**讲英文**的录音（至少 5~10 分钟），否则英文会带中文口音。
   - ✅ 如果当初录课有单独保存的原始音频（wav），优先用它，比从视频里提取的质量更好。
   - ❌ **不要放嗓子哑了之后的录音。**
   - ❌ 尽量少放有背景音乐、多人对话、很吵的片段。少量的学生提问没关系，程序会通过声纹自动识别并剔除。

## 第 6 步：打开程序界面

1. 双击桌面上的 **"声音分身 VoiceTwin"**（或者 `D:\VoiceTwin\start_webui.bat`）。
2. 会出现一个黑色窗口，显示"正在启动声音分身……"。**使用期间不要关闭这个黑色窗口**，关掉它程序就停了。
   也**不要用鼠标点黑色窗口里面**：如果窗口标题出现"选择"两个字，程序会暂停，按一下回车键就能继续。
3. 等 10~30 秒，浏览器会自动打开一个网页，地址是 **`http://127.0.0.1:7860`**。
   如果浏览器没有自动打开，就自己打开浏览器，在地址栏输入 `http://127.0.0.1:7860`，按回车。
   （不小心又双击了一次图标也没关系：程序不会开第二个，会直接打开已经在运行的那个网页。）
4. 网页最上面是标题 **"声音分身 VoiceTwin v18"**（标题永远是 v18；真正的版本号写在黑色窗口里，例如「声音分身 VoiceTwin v18.5 正在启动」），右边是检测出来的模型型号，下面依次是：
   - **显卡状态条**（一直显示）：
     - 绿色 **"✅ 显卡正常：NVIDIA GeForce RTX ……（显存 … GB，可用 … GB）"** —— 一切正常；
     - 红色 **"❌ 显卡没有正常工作"** —— 照着条里的"怎么办"做（多数是要到 <https://www.nvidia.cn/drivers/lookup/> 安装最新显卡驱动并**重启电脑**），然后点右边的 **"🔄 重新检查显卡"**；
     - 黄色 —— 显卡能用但有需要注意的地方（例如显存小、可用显存不多），条里会写原因。
   - **"声音名称"** 输入框；
   - **"🎙️ 我的声音库（共 N 个）"**：点开能看到你所有的声音，每行有编号、素材多少分钟、训练好没有、最佳模型、最后修改时间，**点一行就选中这个声音**；
   - 几个标签页：**① 准备素材 / ② 训练模型 / ③ 生成讲课音频 / ④ 试试像不像（可选） / ⑤ 鉴别 / 🩺 环境检查**。

> 这个网页只在你自己的电脑上运行，不需要联网登录，你的声音也不会上传到任何地方。

### 看懂进度条（每一步都有）

准备素材、找错字、训练、挑选模型、生成、鉴别、下载模型……每个要等的步骤，按钮下面都会出现一个**进度条**：

| 进度条 | 意思 | 你要做什么 |
|---|---|---|
| 🟩 绿色、条纹在动 | 正在正常工作。上面写着百分比、"第几步（共几步）"、已经用了多久、**大约还要多久、预计几点完成** | 等着就行，可以去做别的事 |
| 🟨 黄色 | 已经好几分钟没有新进度：这一步可能比较慢（例如第一次下载模型），也可能卡住了 | 先等一等；很久都不动再点"⏹ 停止" |
| 🟥 红色 | 出问题停下了。会写出**停在哪一步、原因、怎么办** | 照着"怎么办"做；要找人帮忙时，点开下面"详细过程"，复制给他 |
| ⬜ 灰色 | 你点了停止，已经停下 | 已经做好的部分不会丢，需要时再点开始 |
| ✅ 实心绿色 100% | **全部完成**，写着总用时和完成时间 | 进行下一步 |

> 关掉网页、刷新网页都不会打断正在做的事（只要黑色窗口开着）。重新打开网页后，页面上方会提示现在正在做什么；到那一页**再点一次同一个按钮**，就能接着看进度（不会重新开始）。
> **"⏹ 停止"** 要在 5 秒内点两次才会停（防止误点）。

## 第 7 步：准备素材

1. 在最上面的 **"声音名称"** 框里输入一个名字，例如 **`我的声音`**。以后每次都用这个名字。
2. 确认当前在 **"① 准备素材"** 标签页。
3. 在 **"或者填写电脑上的文件夹路径"** 框里输入 **`D:\讲课素材`**。
   > 也可以用左边的"上传"区域选文件，但视频很大时上传会比较慢，建议直接填文件夹路径。
4. 其它选项一般不用动：
   - **"视频有背景音乐"**：一般**不勾**。如果你的视频全程有背景音乐，请看[常见问题](#常见问题)里的处理方法。
   - **"高级设置"** 里有识别引擎（课全是中文可以选"纯中文课更准"）、素材语言、降噪，保持默认即可。
5. 点橙色的 **"开始准备素材"** 按钮。
6. 下面出现绿色进度条，依次显示：提取声音、降噪、切成小段 → 识别文字（**第一次**会先下载语音识别模型，约 3 GB，需要几分钟到十几分钟）→ 剔除不是你本人的片段 → 分析你的说话习惯。
7. 处理时间参考：1 小时素材，有显卡大约 10~30 分钟。进度条上会写预计几点完成。
8. 完成后进度条变成 **"✅ 全部完成！"**，下面显示一段摘要，例如：
   ```
   ✅ 素材准备好了：可用 76.3 分钟（英文 8.1 分钟，中文 68.2 分钟），一共 812 条
   你的语速：中文每秒 4.6 个字；英文每秒 4.1 个音节
   你的停顿习惯：逗号处约 0.3 秒，句号处约 0.7 秒，段落之间约 1.2 秒
   其中 20 条留作「考试题」：训练后用来自动挑出最像你的模型
   ```
   ⚠️ 提示会告诉你素材是否够用，比如"英文素材不足 5 分钟"。

## 第 8 步：校对文字（强烈建议）

语音识别偶尔会听错字。训练素材里的错字，会变成模型的"口误"。程序可以帮你自动找出可能错的字，你只要看一看、点一点。

1. 素材准备完成后，"① 准备素材"页面下方会自动列出所有片段。表格上方写着：
   **"📊 一共 812 条片段：保留 790 条（74.9 分钟），不保留 22 条"**，每一行最前面都有编号。
2. 点 **"🔍 自动查找可能的错字"**。程序会用第二个识别模型把每一段再听一遍，两次结果不一样、或者识别时没把握的字，就是"可能有错"。等进度条走完，会显示"✅ 检查完了：一共查了 812 条，有 N 条可能有错"。
3. 勾选 **"只看可能有错的"**，表格里只剩这些行：
   | 列 | 含义 |
   |---|---|
   | # | 编号 |
   | id | 片段编号 |
   | 语言 | 中文 / 英文（双击可以切换） |
   | 秒 | 片段时长 |
   | 文字（双击修改） | 识别出的文字。**双击它会打开一个会自动换行的大框**，整句话都看得见，改好按回车（或点别的地方）；你改过、新打上去的字是**绿色** |
   | 可能有错（红）· 改过（蓝） | **红色** = 可能识别错、还没改的字；**蓝色** = 已经改过的字；蓝色删除线 = 删掉的字 |
   | 修改建议 | 只有"可能有错"那一列有内容的行才有：**蓝色小按钮** = 还没用这条建议，点一下就按建议改好，按钮**变红 = 生效了**；再点一下红色按钮可以撤销 |
   | 选项 | 最右边：**⋯ 选项**按钮，左边的小灯 🔴 = 改了还没保存、🟢 = 已经保存。菜单里有：保存这一行、删除这一行（会再问一次；删除以后变成"撤销删除"）、修改文字、听一听、撤销这一行的修改、这句没错（不再标红） |
4. **点击一行**：下方的"试听选中的片段"会播放这段录音，旁边还会显示两次识别的对比。
5. 建议是对的：点那一行的**蓝色小按钮**。建议不对、但原文确实错了：**双击"文字"那一格**自己改，按回车。
   **同一个错字在很多句子里**（例如把 as 都识别成了"艾子"），用表格上面的**查找 / 替换**（和 Word 一样）：
   - 在 **"🔍 查找"** 框里输入错字（例如"借词"），点 **"🔍 查找"** 或者按回车：表格里只列出有这个字的句子，行号不变；找到的字是**黄色**，现在这一处是**橙色**，上面写着"找到 5 处（在 3 句里）· 现在是第 1 处"
   - **"⬆ 上一处 / ⬇ 下一处"**：一处一处看（表格会滚到橙色的那一处）
   - 在 **"替换成"** 里输入正确的字（例如"介词"）。**"替换这一处"** 只换橙色的那一个，换完自动跳到下一处；**"全部替换"** 一次全换掉（会先问一次，写着一共几处）
   - 换上的字是**绿色**、这一行亮 🔴（没保存），和自己改字一样，点"保存修改"才生效；换错了点 **"↩️ 撤销刚才的替换"**（只撤销最近一次；替换以后你又改过的句子不会被冲掉）
   - 英文默认**只找整个单词**（找 as 不会找到 has 里面的 as）；要找单词里面的，把这个勾去掉。删除（紫色）的句子不查也不换
   - 查找时找到过的句子一直列在表格里（换完、删除了也不会突然不见）；点 **"✖ 关闭查找"** 表格显示全部句子
6. 某条不是你说的、或者质量很差：**⋯ 选项 → 删除这一行**。删除的行整行变**紫色**（紫色 = 不再算训练素材；删错了在 ⋯ 选项 里点「撤销删除」）。程序判断不能用的行是灰色。
   表格上方写着用来训练的句子数：删几条就减几条（例如 1000 − 2（你删除的）= 998 条），撤销删除就加回来。
7. 全部改完后，点橙色的 **"保存修改"**（全部保存），或者在某一行的 **⋯ 选项** 里点 **"保存这一行"**。保存过的行小灯变成 🟢。
   没保存的修改也不会丢：刷新网页、关掉浏览器以后还在（红灯），保存了才用来训练。
8. 最后点 **"✅ 确认训练素材"**：用来训练的句子行号变成**橙色**，删除的、不能用的不显示行号，一眼就能看出哪些句子会用来训练。
   表格里写着"还没有识别出文字"：上次准备素材的"识别文字"没做完，再点一次"开始准备素材"就会接着识别。

> 习惯用 Excel 的话：用 Excel 打开 `D:\VoiceTwin\workspace\我的声音\transcripts.csv`，修改"text"和"keep"两列，保存（保持 CSV 格式）并**关掉 Excel**。
> 然后在 `D:\VoiceTwin` 文件夹的地址栏输入 `cmd` 回车，运行 `voicetwin.bat review -v 我的声音`，再回到网页点"🔄 刷新表格"。
> 注意：网页里的"保存修改"会重新写一遍 `transcripts.csv`，所以用 Excel 改过之后，一定要先运行上面这条命令。

## 第 9 步：训练你的声音模型

1. 点上方的 **"② 训练模型"** 标签页。
2. 页面上会写出 **"🧠 这次自动选择的训练方案"**，例如"显存 12 GB → 每批 6 条；素材 75 分钟 → 音色 SoVITS 8 轮、语气 GPT 15 轮；……训练完自动挑最像你的那个"。
   **什么都不用改**：程序会按你的显卡和素材多少，自动选出你这台电脑能做到的最好的设置。
3. 点橙色的 **"开始训练"**。
4. 进度条依次显示：准备训练数据 → 训练音色（SoVITS）→ 训练语气和节奏（GPT）→ 用"考试题"给每个保存下来的版本打分、挑出最像你的 → 校准语速。每一步都写着百分比和预计完成时间。
5. 最后显示 **"✅ 训练完成"**，写着挑出的版本"像你本人百分之多少"，并且已经把语速调得和你本人一样。
6. 训练时间参考：1 小时素材，RTX 3060 约 40~90 分钟，RTX 4090 约 15~30 分钟。
7. 训练期间：
   - **不要关闭黑色窗口**（网页可以关，重新打开会接着显示进度）。
   - 程序会尽量让电脑在训练时不睡眠；保险起见也可以设置：设置 → 系统 → 电源 → 屏幕和睡眠 → "睡眠"改为"从不"。
   - 电脑会比较卡、风扇会比较响，这是正常的。
   - 如果显存不够，程序会自动减小"每批数量"再试一次。

> 以后如果增加了素材或重新校对了文字，再点一次"开始训练"即可（旧的训练结果会自动归档，不会混在一起）。

## 第 10 步：生成讲课音频

1. 点上方的 **"③ 生成讲课音频"** 标签页。
2. 在左边的 **"讲稿"** 框里粘贴你的讲稿，或者在下面"或上传讲稿文件"里选择文件（支持 txt、md、srt、docx）。
3. 右边的设置：
   - **质量**（程序会按你的显卡自动选好，显卡正常、显存 8GB 以上时默认是"完美"）：
     | 档位 | 做法 | 适合 |
     |---|---|---|
     | 快速 | 每句只做 1 遍 | 先听个大概 |
     | 均衡 | 每句做 3 遍，挑最像你的 | 日常草稿 |
     | 最好 | 每句做 5 遍，并检查漏字错字 | 正式课程 |
     | 极致 | 更多遍、更严格，很慢 | 显存 8GB 以上 |
     | **完美** | 每句最多试 **20 次**、严格检查漏字错字，并做**两个版本**（去杂音 / 不去杂音）让你选 | **最终发布**（最慢） |
   - **语速** 拉杆：中间 **0 = 和你原声一样**；**往左拉越来越快，往右拉越来越慢**（拉杆下面会写"当前：比你原声快 10%"之类）。
     只改快慢，**不改音色和音高**。建议在 −15～+15 之间，太极端会不自然。点 **"▶ 试听语速"** 可以先听一句。
   - **只重新生成第几句**：第一次留空。
   - **高级设置** 里的引擎、指定参考音频，一般不用动。
4. 点橙色的 **"生成"**。第一次生成时，需要先启动合成引擎，大约多等 1 分钟。进度条会显示正在做第几句、预计几点完成。
5. 完成后：
   - **"结果"** 播放器里可以直接试听；
   - **"下载（音频 / 字幕）"** 区域有：**音频（.wav 或 .mp3）**、**字幕（.srt）**、**报告**；
   - 同样的文件也自动保存在 **`D:\VoiceTwin\workspace\我的声音\outputs\`** 里，点 **"📂 打开保存文件夹"** 可以直接打开。
6. 下方表格列出每一句的 **"像你本人（%）"**：100% 表示和你自己另一段真实录音一样像。每句话的多个候选里，低于 85% 的会被淘汰；如果某一句最好的也不到 85%，会标出来并建议重新生成。
7. **完美档的两个版本**：会多出一块 **"🎧 这次做了两个版本，听一听，选你更喜欢的"**：
   - **版本 A：未去杂音**、**版本 B：去杂音**，各自写着"像你本人百分之多少"；
   - 程序自动比较哪个更像你的原声，标 **⭐ 推荐**；
   - 两个都听一听，在 **"最终使用哪个版本"** 里选一个，下载区里的文件会跟着换成你选的版本。两个版本都会保存。
8. 不管哪个档位，生成的音频都**只有你的声音**：没有背景音、没有底噪，句子之间的停顿是**完全静音**（停顿的长短按你本人的习惯）。
9. 某几句不满意时：在 **"只重新生成第几句"** 里填编号，例如 `3,5,8-10`，再点一次 **"生成"**。只会重新生成这几句，其它句子直接用上次的结果，很快。

## 第 11 步：把音频放进课程视频

### 用剪映（或其它剪辑软件）

1. 打开剪映，导入你的课程画面（录屏、PPT 视频等）。
2. 把生成的 **`.wav`** 音频拖到音频轨道上。
3. 导入字幕：菜单 **文本 → 本地字幕 → 导入**，选择生成的 **`.srt`** 文件，字幕会自动对齐时间。
4. 导出视频。

### 直接替换视频的音轨（命令行）

在 `D:\VoiceTwin` 文件夹的地址栏输入 `cmd` 回车，然后运行（换成你自己的文件路径）：

```
voicetwin.bat mux --video D:\课程\第3课画面.mp4 --audio D:\VoiceTwin\workspace\我的声音\outputs\第3课.wav -o D:\课程\第3课成品.mp4
```

### 给已有视频按字幕时间轴重新配音

如果你有一个视频和它的 `.srt` 字幕，想按字幕的时间点重新配音：在"③ 生成讲课音频"里**上传这个 `.srt` 文件**作为讲稿。每句话会被放在字幕对应的开始时间上。

## 讲稿写法速查

```markdown
# 第三课：列表推导式

大家好，今天我们来学习 Python 里面的列表推导式。它可以让代码更简洁。

那么大家想一想，这段代码输出什么？[停顿=2]

Next, let's look at a slightly more complex example.
```

| 写法 | 效果 |
|---|---|
| 空一行 | 段落停顿（按你本人的段落停顿习惯） |
| `[停顿]` | 段落停顿 |
| `[停顿=2]`、`[停顿 1.5秒]`、`[pause=800ms]` | 指定停顿时长 |
| `# 标题` | 标题会被读出来，读完后停顿 |
| ` ``` ` 代码块 ` ``` ` | 默认**不朗读** |
| 中英混写 | 自动识别；整句英文会用你的英文参考音频 |
| 疑问句（？结尾） | 自动使用你问问题时的语气作为参考 |

**纠正读音**：用记事本打开 `D:\VoiceTwin\workspace\我的声音\lexicon.txt`，每行写一条 `原文 => 读法`：

```
SQL => sequel
GPT => G P T
重庆 => 虫庆
行长 => 航长
```

保存后再生成即可。字幕里仍然显示原文。

## 怎么检验"像不像"：鉴别和盲测

打开 **"⑤ 鉴别"** 标签页：

- **机器鉴别**：点 **"开始鉴别"**。不选文件时，程序自动用素材里留出的你的真实录音，和最近一次生成的结果来比；也可以自己上传原始录音和要鉴别的音频（都可以多选）。
  结果表格里每个文件都有"综合 %"和排名，"是否 ≥85%"一列告诉你够不够像。
- **观众盲听测试**：选好"用几句话"，点 **"生成盲听测试"**。程序从你的真实录音里挑几句，再用你的模型读同样的句子，打乱顺序编上号。
  让同事、学生逐段选"真人"还是"生成"，点"提交答案"就会自动批改，告诉你大家分得出来的比例。
  离线测试（例如把音频发给别人、收回答题卡）可以在 **"📝 批改收上来的答题卡"** 里粘贴答案批改。

如果大家分不出来，就可以放心用了；如果能听出来，看下面"声音不够像"那一条。

> 说实话：相似度是声纹模型自动打分，越高越像，但不是绝对精确，也没有任何技术能保证 100% 一模一样。最终以耳朵为准。

## 常见问题

**双击 install_windows.bat 后窗口一闪就没了**
在 `install_windows.ps1` 上右键，选 **"使用 PowerShell 运行"**。

**安装时提示"没有找到 ……\runtime\python.exe"**
整合包的路径输错了。打开你的 GPT-SoVITS 文件夹，确认里面**直接**有 `runtime` 文件夹，然后重新运行安装程序，输入正确的路径。

**安装时提示"整合包版本太旧（缺少 api_v2.py）"**
请重新下载最新版的 GPT-SoVITS 整合包。

**下载模型很慢或失败**
程序默认已经使用国内镜像（hf-mirror.com）。如果还是失败：检查网络，换个时间再试；或者在 ① 里把识别引擎换成 `funasr`（它从阿里的 ModelScope 下载，国内速度快）。

**浏览器没有自动打开，或者打开后显示"无法访问此网站"**
确认黑色窗口还开着，而且没有报错；等 30 秒后手动访问 `http://127.0.0.1:7860`。如果提示端口被占用，关闭其它黑色窗口，或者重启电脑后再试。

**训练时报错 "CUDA out of memory"（显存不足）**
程序会先自动减小"每批数量"再试一次。还是不行：在"② 训练模型 → 高级设置"里把 **"每批数量 batch"** 改成 `2`（还不行就改成 `1`），再点开始训练。GTX 10 系列等较老的显卡，还需要用记事本打开 `D:\VoiceTwin\config.yaml`，把 `is_half: true` 改成 `is_half: false`。

**页面最上面一直是红色"❌ 显卡没有正常工作"**
1. 到 <https://www.nvidia.cn/drivers/lookup/> 按显卡型号下载最新驱动，安装后**重启电脑**；
2. RTX 50 系列显卡要用文件名带 `nvidia50` 的整合包；
3. 再打开程序，点"🔄 重新检查显卡"。还是红色的话，把红条里的文字和"🩺 环境检查"页面截图发给帮你的人。

**进度条变成红色**
红条里会写"停在第几步、原因、怎么办"，照着做就行。需要别人帮忙时，点开下面的"详细过程（出问题时可以复制给帮你的人）"，点右上角的复制按钮，把内容发给他。

**生成时提示"GPT-SoVITS 推理服务启动失败"**
打开 `D:\VoiceTwin\workspace\我的声音\logs\gptsovits_api.log`，看最后几行的报错。常见原因是模型文件不全（运行第 4 步）或显存被其它程序占用（关掉游戏、其它 AI 软件）。

**提示"找不到 GPT-SoVITS 目录"**
你移动过 GPT-SoVITS 的文件夹。重新运行一次 `install_windows.bat`，输入新的路径即可（其它设置会保留）。

**声音不够像**
按效果从大到小排列：
1. 增加素材（30 分钟 → 1~3 小时）；
2. 校对文字（第 8 步，用"🔍 自动查找可能的错字"）；
3. 检查素材是否干净，把嗓子哑之后的录音删掉；
4. 生成时用"完美"质量（显卡正常时默认就是），并在两个版本里选更像的那个；
5. 在 `workspace\我的声音\references.json` 里挑一条语气最满意的参考音频，把它的 id 填到"指定参考音频 id"；
6. 重新训练。

**某个字总是读错**
写进 `lexicon.txt`，见[讲稿写法速查](#讲稿写法速查)。

**英文有中文口音**
加入你讲英文的录音，重新运行 ① 和 ②。

**视频里全程有背景音乐**
先用 GPT-SoVITS 整合包自带的人声分离工具去掉背景音乐：双击 `D:\GPT-SoVITS\go-webui.bat`，在打开的页面里找到 **"UVR5 人声伴奏分离"**，把视频的音频分离出人声，再把分离出的人声文件放进 `D:\讲课素材`。

**我移动了 VoiceTwin 文件夹**
重新运行一次 `install_windows.bat`（会重新生成启动脚本和桌面图标），`workspace` 里的数据都在，不受影响。

**想看更详细的错误信息**
每一步的日志都在 `D:\VoiceTwin\workspace\我的声音\logs\` 里。也可以在命令行里加 `--verbose` 运行，例如 `voicetwin.bat narrate -v 我的声音 讲稿.txt --verbose`。

**怎么卸载**
1. 在 `D:\VoiceTwin` 地址栏输入 `cmd` 回车，运行 `D:\GPT-SoVITS\runtime\python.exe -m pip uninstall voicetwin`；
2. 删除 `D:\VoiceTwin` 文件夹（注意：`workspace` 里有你训练好的模型和生成的音频，需要的话先备份）；
3. 删除桌面图标。
