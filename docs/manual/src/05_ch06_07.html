第 6 章第一步：准备素材

这一步在 ① 准备素材 页面完成。程序会自动：从视频里提取声音 → 清理 → 切成一句一句 → 识别成文字 → 过滤掉质量差的和不是你本人的片段 → 分析你的说话风格 → 挑选参考音频。你只需要填两个地方、点一个按钮，然后看进度条等它做完。

6.1 填写声音名称

  1. 点页面最上面的 声音名称（新建请直接输入名字） 输入框。
  2. 输入一个名字，例如 我的声音，按 Enter。名称下面会出现一行提示，例如"「我的声音」是新声音，还没有素材。👉 下一步：……"。
  • 名字可以用中文，但不能包含 \ / : * ? " < > | 这些符号。
  • 以后每次使用都要选同一个名字，这样才能用到你训练好的模型。也可以在 🎙️ 我的声音库 里点一下来选（5.2 节）。
  • 一台电脑可以有多个声音（例如"讲课声音""激情版"），它们的素材和模型互相独立。

6.2 选择素材

有两种方式，任选其一：

方式一（推荐）：填写文件夹路径

在 或者填写电脑上的文件夹路径（推荐） 里输入 D:\讲课素材。

优点：不需要上传，视频再大、再多都很快，也不占 C 盘。程序会自动找到文件夹及子文件夹里的所有视频和音频。

方式二：上传文件

点左边的 上传视频/音频/字幕（可多选） 区域，选择文件（按住 Ctrl 可多选），或者直接把文件拖进去。

适合文件较少、较小的情况。大视频上传会比较慢。

小技巧：打开 D:\讲课素材 文件夹 → 点地址栏 → Ctrl+C 复制路径 → 回到网页，点输入框 → Ctrl+V 粘贴。

6.4 开始处理，看进度条

  1. 点橙色的 开始准备素材 按钮。按钮会变成"⏳ 正在准备素材……"，旁边出现 ⏹ 停止。
  2. 按钮下面出现绿色进度条（样子见图 5-4），写着做到百分之几、第几步、已经用了多久、预计几点完成。准备素材一共 7 步：
    第几步在做什么
    1整理要处理的文件
    2提取声音、降噪、切成小段（有同名字幕时按字幕切）
    3识别每段话的文字（第一次会先下载语音识别模型，约 3GB，要几分钟到十几分钟）
    4分析语速和停顿
    5检查是不是你本人的声音（用声纹剔除学生提问等）
    6挑选参考音频、保存结果
    7分析你的说话风格
    如果电脑上装了第二个识别引擎，最后还会自动多做一步"查找可能的错字"（共 8 步，见 7.2 节）。
  3. 全部完成后，进度条变成实心绿色 "✅ 全部完成！"，下面出现 "✅ 素材准备好了" 的摘要和 去「② 训练模型」 → 按钮；再往下，所有片段的校对表会自动列出来（第 7 章）。
第一次下载识别模型时，进度条可能会变成黄色（好几分钟没有新进度），这是正常的，耐心等就行。原来的详细日志还在，收在进度条下面的 详细过程（出问题时可以复制给帮你的人） 里，平时不用看；进度条变红时照 5.3 节处理。

第 7 章校对文字（强烈建议）

7.1 为什么要校对

训练时，模型会把"这段声音"和"这段文字"一一对应起来学习。如果识别出的文字有错（例如把"推导式"识别成"推倒是"），模型就会学到错误的发音对应关系， 生成时可能出现读错字、吞字、语气奇怪的情况。现在程序可以自动找出可能识别错的字，你只要看一看、听一听、点一点，花 5~20 分钟，效果会明显更好，是性价比最高的一步。

如果你的素材都有准确的字幕文件（4.5 节），文字本身就是准确的，可以只快速浏览一遍。

7.2 在网页里校对：自动查找可能的错字

  1. 素材准备完成后，在 ① 准备素材 页面往下拉，找到 "✍️ 校对文字（可选，但能明显提升效果）"。片段表格已经自动列好了，表格上方写着一共多少条、保留多少条（多少分钟）、不保留多少条。
  2. 点 🔍 自动查找可能的错字，等进度条走到 100%。程序会用第二个识别引擎把每一段再听一遍（faster-whisper 和 FunASR 互相核对），两次听到的不一样、或者识别时没把握的字，再加上一些规则（例如一串看不懂的大写英文、同一个词重复好几遍），都会被标为"可能有错"。查完会显示 "✅ 检查完了：一共查了 228 条，其中 2 条可能有错（已在表格里标红）"。
  3. 勾选 只看可能有错的，表格里就只剩这些行。各列的意思：
    列含义
    #序号（第几条），从 1 开始。
    id片段编号（"文件名_编号"），不要修改。
    保留（是/否）"是"参加训练；"否"不参加。
    语言中文 / 英文（一般不用改）。
    秒片段时长。
    文字识别出的文字，可以直接修改。
    可能有错（红色）可能识别错的字用红色标出来，有建议时也写在这里。这一列只用来看，改字请改"文字"列。
    丢弃原因被自动丢弃的原因（保留的片段这一栏是空的）。
  4. 点击任意一行：表格下面的 试听选中的片段 会自动播放这一段录音；标红的片段还会显示一个红边框的对比框，写着可能有错的原因，以及"识别 A（现在的文字）"和"识别 B"（第二个引擎听到的）两次结果，不一样的字会标出来。
  5. 建议是对的：点 ✅ 采用建议（有建议时才会出现），文字马上改好。建议不对、但原文确实错了：双击这一行的"文字"格子，改成正确的文字，按 Enter 确认。
  6. 某一段不是你说的、质量很差、或者说错了话：把"保留"格子改成 否。想恢复被自动丢弃的片段：把它的"保留"改成 是。
  7. 全部改完后，点橙色的 保存修改。下方会显示类似"✅ 已保存：改了 12 处文字、3 处「保留」、0 处语言"。
修改完一定要点 保存修改，否则关掉页面后修改会丢失。还没保存时，表格上方会提醒"表格里还有 N 条修改没有保存"。🔄 重新载入 会按已经保存的内容重新显示表格，没保存的修改会被丢掉，所以先保存再点它。片段很多时，可以分几次校对，每次改完都保存。

标红只是提醒"可能有错"，不一定真错；也可能有个别错字没被发现。重要的片段最好自己听一听。

没有装第二个识别引擎时，程序会改用识别时的"把握程度"来找；连这个也没有时只按规则检查，结果里会写"没有可用的第二个识别引擎，能发现的错字比较少"，这时更要自己多听一听。

校对时重点看什么

  • 错别字和同音字：专业术语最容易识别错，例如"推导式 / 推倒是"、"Python / 派森"。
  • 漏字、多字：录音里说了但文字里没有，或者相反。
  • 标点：句末有没有句号、问号。标点会影响模型学习停顿和语气，问句请用问号。
  • 口头语：录音里说了"嗯""那个"，文字里也要写上（按实际说的写），或者把这一段删掉。
  • 中英文：英文单词按原样写英文，不要写成中文谐音。

7.3 用 Excel 校对（适合片段很多时）

  1. 打开 D:\VoiceTwin\workspace\我的声音\transcripts.csv（用 Excel 或 WPS 表格打开，中文不会乱码）。
  2. 修改 text 列的文字；不想要的行把 keep 改成 0（要恢复就改成 1）。最后一列 audio 是音频文件的位置，可以复制路径去播放。Excel 里看不到红色标记，想用"自动查找错字"请在网页里校对。
  3. 保存时选择保持 CSV 格式（Excel 提示"可能会丢失某些功能"时选"是 / 保持当前格式"），然后关掉 Excel / WPS。
  4. 在 D:\VoiceTwin 打开命令提示符（3.7 节），输入 voicetwin.bat review -v 我的声音 按 Enter，程序会读回你的修改。
  5. 回到网页，点 🔄 重新载入，表格里就是你在 Excel 里改好的内容了。
Excel 开着这个文件时，网页里点"保存修改"会提示"transcripts.csv 正被 Excel/WPS 打开，请先关掉它"。Excel 和网页二选一：在 Excel 里改完、还没运行上面第 4 步之前，不要在网页里点"保存修改"，否则网页表格里的旧内容会盖掉你在 Excel 里的修改。

7.4 什么样的片段应该删掉

  • 不是你本人的声音（程序没识别出来的漏网之鱼）。
  • 咳嗽、笑场、清嗓子、明显口误后重说的片段。
  • 有明显杂音（敲门、手机铃声、翻书声很大）的片段。
  • 声音状态明显不对（很累、很哑）的片段。
  • 文字实在听不清、无法确定的片段。

删掉少量片段不会影响效果，宁缺毋滥。

7.5 校对之后

点 保存修改（或运行 voicetwin.bat review）后，程序会自动重新统计语速、重新过滤、重新挑选参考音频，并更新你的说话风格档案。然后就可以进入第 8 章开始训练了。 如果你是在训练之后才校对的，校对完需要重新训练一次，修改才会生效。
