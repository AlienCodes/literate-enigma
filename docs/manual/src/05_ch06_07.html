第 6 章第一步：准备素材

这一步在 ① 准备素材 页面完成。程序会自动：从视频里提取声音 → 清理 → 切成一句一句 → 识别成文字 → 过滤掉质量差的和不是你本人的片段 → 分析你的说话风格 → 挑选参考音频。你只需要填两个地方、点一个按钮。

6.1 填写声音名称

  1. 点页面最上面的 声音名称（新建请直接输入名字） 输入框。
  2. 输入一个名字，例如 我的声音，按 Enter。
  • 名字可以用中文，但不能包含 \ / : * ? " < > | 这些符号。
  • 以后每次使用都要选同一个名字，这样才能用到你训练好的模型。
  • 一台电脑可以有多个声音（例如"讲课声音""激情版"），它们的素材和模型互相独立。

6.2 选择素材

有两种方式，任选其一：

方式一（推荐）：填写文件夹路径

在 或者填写电脑上的文件夹路径 里输入 D:\讲课素材。

优点：不需要上传，视频再大、再多都很快。程序会自动找到文件夹及子文件夹里的所有视频和音频。

方式二：上传文件

点左边的 上传视频/音频/字幕（可多选） 区域，选择文件（按住 Ctrl 可多选），或者直接把文件拖进去。

适合文件较少、较小的情况。大视频上传会比较慢。

小技巧：打开 D:\讲课素材 文件夹 → 点地址栏 → Ctrl+C 复制路径 → 回到网页，点输入框 → Ctrl+V 粘贴。

6.3 其它选项说明

一般保持默认即可。各选项的含义：

选项默认值说明与建议
语音识别引擎faster-whisperfaster-whisper：中文、英文都识别得好，推荐。
funasr：阿里的中文识别模型，纯中文课程识别更准，但英文较弱（需要整合包里带有 funasr，一般都有）。
none：不做识别，只用字幕文件里的文字（所有视频都有字幕时可选）。
素材语言autoauto：每一句自动判断是中文还是英文（推荐）。素材全是中文可以选 zh，全是英文可以选 en。
降噪autoauto：程序估算录音的噪音大小，只有噪音明显时才轻度降噪（推荐）。
on：总是降噪。off：从不降噪。
降噪太狠会损伤音色，所以默认很保守。
视频有背景音乐不勾选勾选后会用 Demucs 去除背景音乐，需要额外安装 demucs 组件，处理也较慢。一般不勾，推荐用 4.6 节的方法。

6.4 开始处理并看懂日志

  2. 下方的 运行日志 会实时滚动显示进度。第一次运行时，程序会先下载语音识别模型（约 3GB），需要几分钟到十几分钟，请耐心等待。

第 7 章校对文字（强烈建议）

7.1 为什么要校对

训练时，模型会把"这段声音"和"这段文字"一一对应起来学习。如果识别出的文字有错（例如把"推导式"识别成"推倒是"），模型就会学到错误的发音对应关系， 生成时可能出现读错字、吞字、语气奇怪的情况。花 10~20 分钟校对，效果会明显更好，是性价比最高的一步。

如果你的素材都有准确的字幕文件（4.5 节），文字本身就是准确的，可以只快速浏览一遍。

7.2 在网页里校对

  1. 在 ① 准备素材 页面往下拉，找到 "校对文字" 部分，点 载入片段列表。
  2. 表格里会列出所有片段，每行一个：
    列含义
    #序号（第几条）。表格上方会写着一共多少条、保留多少条（多少分钟）、不保留多少条。
    id片段编号（"文件名_编号"），不要修改。
    保留✔ 参加训练；✘ 不参加。
    语言zh 中文 / en 英文（一般不用改）。
    秒片段时长。
    文字识别出的文字，可以直接修改。
    丢弃原因被自动丢弃的原因（保留的片段这一栏是空的）。
  3. 点击任意一行，下方的 试听选中的片段 会加载这一段录音，点 ▶ 播放，一边听一边核对文字。
  4. 发现错字：双击这一行的"文字"格子，修改成正确的文字，按 Enter 确认。
  5. 某一段不是你说的、质量很差、或者说错了话：把"保留"格子改成 ✘（也可以输入 0）。
  6. 想恢复被自动丢弃的片段：把它的"保留"改成 ✔（或 1）。
  7. 全部改完后，点橙色的 保存修改。下方会显示类似"已保存：{'text': 12, 'keep': 3, 'lang': 0}"，意思是改了 12 处文字、3 处保留状态。
修改完一定要点 保存修改，否则关掉页面后修改会丢失。片段很多时，可以分几次校对，每次改完都保存。

校对时重点看什么

  • 错别字和同音字：专业术语最容易识别错，例如"推导式 / 推倒是"、"Python / 派森"。
  • 漏字、多字：录音里说了但文字里没有，或者相反。
  • 标点：句末有没有句号、问号。标点会影响模型学习停顿和语气，问句请用问号。
  • 口头语：录音里说了"嗯""那个"，文字里也要写上（按实际说的写），或者把这一段删掉。
  • 中英文：英文单词按原样写英文，不要写成中文谐音。

7.3 用 Excel 校对（适合片段很多时）

  1. 打开 D:\VoiceTwin\workspace\我的声音\transcripts.csv（用 Excel 或 WPS 表格打开，中文不会乱码）。
  2. 修改 text 列的文字；不想要的行把 keep 改成 0。最后一列 audio 是音频文件的位置，可以复制路径去播放。
  3. 保存时选择保持 CSV 格式（Excel 提示"可能会丢失某些功能"时选"是 / 保持当前格式"）。
  4. 在 D:\VoiceTwin 打开命令提示符（3.7 节），输入 voicetwin.bat review -v 我的声音 按 Enter，程序会读回你的修改。
用 Excel 修改期间不要同时在网页里点"保存修改"，以免互相覆盖。二选一即可。

7.4 什么样的片段应该删掉

  • 不是你本人的声音（程序没识别出来的漏网之鱼）。
  • 咳嗽、笑场、清嗓子、明显口误后重说的片段。
  • 有明显杂音（敲门、手机铃声、翻书声很大）的片段。
  • 声音状态明显不对（很累、很哑）的片段。
  • 文字实在听不清、无法确定的片段。

删掉少量片段不会影响效果，宁缺毋滥。

7.5 校对之后

点 保存修改 后，程序会自动重新统计语速、重新过滤、重新挑选参考音频，并更新你的说话风格档案。然后就可以进入第 8 章开始训练了。 如果你是在训练之后才校对的，校对完需要重新训练一次，修改才会生效。
