第 3 章下载与安装

这一章完成后，你的电脑上会有两个文件夹：D:\VoiceTwin（声音分身）和 D:\GPT-SoVITS（整合包）， 桌面上会出现一个"声音分身 VoiceTwin"图标。整个过程大约 30~60 分钟，主要时间花在下载上。

3.1 下载声音分身 VoiceTwin

  1. 用浏览器（推荐 Edge 或 Chrome）打开：
    https://github.com/AlienCodes/literate-enigma/releases/latest
  2. 页面上方是版本说明。往下拉，找到 Assets（资源）这一栏；如果它是折叠的，点一下把它展开。
  3. 点 VoiceTwin-Windows-v0.1.2.zip（版本号可能更高）开始下载。
    不要下载下面的 Source code (zip) 和 Source code (tar.gz)，那是给开发者的源代码。
  4. 下载完成后，打开"下载"文件夹（浏览器下载列表里点"在文件夹中显示"）。
  5. 在 VoiceTwin-Windows-v0.1.2.zip 上点鼠标右键 → 选择 全部解压缩… （Windows 11 需要先点 显示更多选项）。
  6. 在弹出的窗口里，把"文件将被提取到这个文件夹"下面的路径改成 D:\，然后点 提取。
  7. 打开 D 盘，你会看到一个 VoiceTwin 文件夹，也就是 D:\VoiceTwin。打开它，确认里面有这些文件： 
    D:\VoiceTwin
├── install_windows.bat        ← 安装程序（下一步要双击它）
├── install_windows.ps1
├── 使用教程（先看我）.html      ← 简明网页版教程
├── README.md
├── pyproject.toml
├── docs\                      ← 本手册 PDF 也在这里
└── voicetwin\                 ← 程序本体，不要改动
GitHub 在国内有时打开很慢或打不开，可以多刷新几次、换个时间，或者换一个网络（例如手机热点）再试。

3.2 下载 GPT-SoVITS 整合包

GPT-SoVITS 是声音分身用来训练和生成你的声音的核心工具。它的官方团队为 Windows 提供了"整合包"，已经装好了 Python、PyTorch、显卡加速等所有复杂组件。

  1. 打开 GPT-SoVITS 官方文档的整合包下载页（国内用户）：
    https://www.yuque.com/baicaigongchang1145haoyuangong/ib3g1e/dkxgpiy9zb96hob4#KTvnO
    海外用户可以用：https://huggingface.co/lj1995/GPT-SoVITS-windows-package/tree/main
  2. 在"整合包"部分找到下载链接，下载最新版。怎么判断是不是新版：
    • 文件名里带 v2pro（或者比 v2pro 更新的版本号）；
    • 文件名里的日期越新越好（例如 2025 年 6 月以后）；
    • 如果你的显卡是 RTX 50 系列（5060/5070/5080/5090），并且页面上有专门标注 50 系的版本（文件名带 50 或 nvidia50 字样），请选那个。
  3. 整合包有好几个 GB，下载需要一段时间。下载时可以先去做第 4 章的素材整理。

3.3 解压整合包并放到正确位置

  1. 在下载好的 .7z 文件上点右键 → 7-Zip → 提取到 "文件名\"（Windows 11 要先点"显示更多选项"）。解压需要几分钟。
  2. 解压完成后，会得到一个文件夹，名字类似 GPT-SoVITS-v2pro-20250604。
  3. 在这个文件夹上点右键 → 重命名，改成 GPT-SoVITS。
  4. 把它剪切（Ctrl+X）到 D 盘根目录后粘贴（Ctrl+V），最终路径是 D:\GPT-SoVITS。
  5. 打开 D:\GPT-SoVITS，检查是否直接能看到下面这些： 
    D:\GPT-SoVITS
├── go-webui.bat          ← 有它说明位置对了
├── api_v2.py             ← 声音分身需要用到
├── runtime\              ← 整合包自带的 Python 环境
├── GPT_SoVITS\
├── tools\
└── ……
常见错误 1：多套了一层文件夹 如果你看到的是 D:\GPT-SoVITS\GPT-SoVITS-v2pro-2025xxxx\go-webui.bat，说明多了一层。 请打开里面那一层，全选（Ctrl+A）所有内容，剪切到外面的 D:\GPT-SoVITS 里。（安装程序也会尝试自动找到里面那层。）
常见错误 2：路径里有中文或空格 D:\GPT-SoVITS ✅　　D:\新建文件夹\GPT SoVITS ❌　　C:\Users\张老师\Desktop\GPT-SoVITS ❌
中文和空格会导致部分组件报错，请一定放在类似 D:\GPT-SoVITS 这样简单的路径里。
想确认整合包本身是好的，可以双击 D:\GPT-SoVITS\go-webui.bat，如果能打开 GPT-SoVITS 自己的网页界面，说明整合包正常。确认后关掉那个黑色窗口即可（声音分身不需要你手动打开它）。

3.4 运行安装程序

  1. 打开 D:\VoiceTwin，双击 install_windows.bat。
  2. 如果弹出蓝色窗口 "Windows 已保护你的电脑"：点 更多信息，再点 仍要运行。
    如果 360、火绒等杀毒软件弹出拦截提示，选择 允许 或 信任此程序。
    出现这个提示是因为安装程序是从网上下载的、没有购买微软的签名证书，并不是病毒。安装程序的全部内容都是公开的，可以用记事本打开 install_windows.ps1 查看。
  3. 会出现一个黑色窗口，显示安装菜单。输入 1，按 Enter：
Windows PowerShell —— 安装程序（示意）
=============================================
   VoiceTwin 声音分身 安装程序
=============================================
安装位置：D:\VoiceTwin

请选择安装方式：
  1) 推荐：安装到 GPT-SoVITS 整合包里（最省事，语音识别和训练都用显卡，不用重复下载 PyTorch）
  2) 独立安装：创建单独的 Python 虚拟环境（需要本机已安装 Python 3.10 或 3.11，适合有经验的用户）
请输入 1 或 2，然后按回车: 1
  1. 接着它会让你输入整合包的位置。输入 D:\GPT-SoVITS，按 Enter：
Windows PowerShell —— 安装程序（示意）
请输入 GPT-SoVITS 整合包所在的文件夹路径（打开那个文件夹，里面能看到 go-webui.bat 和 runtime 文件夹）。
小技巧：在文件夹窗口顶部的地址栏点一下，复制路径，再回到这里右键粘贴。
GPT-SoVITS 整合包路径（例如 D:\GPT-SoVITS）: D:\GPT-SoVITS
不想手打路径？打开 D:\GPT-SoVITS 文件夹 → 点窗口顶部的地址栏（路径会变成蓝色选中状态）→ 按 Ctrl+C 复制 → 回到黑色窗口，点鼠标右键就能粘贴。
  1. 等待 3~10 分钟。窗口里会滚动很多英文（这是在下载和安装组件），属于正常现象。请不要关闭窗口。 过程中会依次出现下面这些步骤标题：

3.5 看懂安装结果（环境检查）

"检查环境"会逐项列出程序需要的组件。每一行前面有一个符号：

符号含义你需要做什么
✅正常不用管。
⚠️可选组件没装，或者是提醒一般不用管。例如"funasr 未安装""demucs 未安装""引擎 Qwen3-TTS""引擎 IndexTTS"都是可选的。
❌必需的东西有问题需要处理，见下表。
常见的 ❌ 提示处理方法
引擎 GPT-SoVITS：缺少预训练模型：……v2Pro……整合包版本较早，没有自带 v2Pro 模型。按 3.6 节自动下载。
引擎 GPT-SoVITS：找不到 GPT-SoVITS 目录整合包路径输错了，或者之后移动过文件夹。重新运行 install_windows.bat，输入正确路径。
NVIDIA 显卡：没有找到 nvidia-smi显卡驱动没装好，或者电脑没有 NVIDIA 显卡。按 2.4 节更新驱动。
ffmpeg：找不到 ffmpeg很少见。重新运行安装程序；仍然不行请看第 15.1 节。

3.6 补齐预训练模型（只在提示缺少时才需要）

较早的整合包没有自带 v2Pro 模型（大约 1~2GB）。声音分身可以自动帮你下载：

  1. 按 3.7 节的方法，在 D:\VoiceTwin 文件夹里打开"命令提示符"。
  2. 输入下面这行，按 Enter：
    voicetwin.bat download-models --source hf-mirror
  3. 等待下载完成，看到 "✅ 已下载 N 个文件"。
  4. 再输入 voicetwin.bat doctor 按 Enter，确认出现 "✅ 引擎 GPT-SoVITS：就绪"。
命令提示符（示意）
D:\VoiceTwin>voicetwin.bat download-models --source hf-mirror
21:05:12 | 下载 v2Pro/s2Gv2ProPlus.pth（https://hf-mirror.com）……
21:05:40 | 下载 v2Pro/s2Dv2ProPlus.pth（https://hf-mirror.com）……
21:06:02 | 下载 sv/pretrained_eres2netv2w24s4ep4.ckpt（https://hf-mirror.com）……
✅ 已下载 4 个文件

D:\VoiceTwin>voicetwin.bat doctor
……
✅ 引擎 GPT-SoVITS：就绪（Python：D:\GPT-SoVITS\runtime\python.exe）
下载总是失败？ 用记事本打开 D:\VoiceTwin\config.yaml，找到 version: v2ProPlus 这一行，改成 version: v2，保存。 这样会使用整合包自带的 v2 模型，不需要下载，效果略逊一些。

3.7 如何打开"命令提示符"

大部分操作都在网页界面里完成，但有少数步骤（例如上一节）需要在黑色的"命令提示符"窗口里输入命令。打开方法：

  1. 打开 D:\VoiceTwin 文件夹。
  2. 点一下窗口顶部的地址栏（显示"此电脑 › 本地磁盘 (D:) › VoiceTwin"的那一栏），里面的文字会变成可编辑的路径。
  3. 把地址栏里的文字删掉，输入 cmd，按 Enter。
  4. 会弹出一个黑色窗口，第一行显示 D:\VoiceTwin>，说明已经位于正确的文件夹，可以输入命令了。
在命令提示符里：输入命令后按 Enter 执行；命令运行时不要关窗口；想复制窗口里的文字，用鼠标选中后按 Enter（或右键）；想粘贴，点鼠标右键。

3.8 安装完成后的文件夹说明

D:\VoiceTwin
├── start_webui.bat          ← 启动程序（桌面图标指向它）
├── voicetwin.bat            ← 在命令提示符里使用的命令入口
├── config.yaml              ← 设置文件（第 13.3 节），可用记事本修改
├── install_windows.bat      ← 安装程序（重新安装、换整合包路径时再运行）
└── workspace\               ← 第一次准备素材后自动出现，你的所有数据都在这里
    └── 我的声音\
        ├── outputs\          ← 生成的音频、字幕、报告
        ├── transcripts.csv   ← 校对表
        ├── lexicon.txt       ← 读音纠正词典
        └── ……（附录 B 有完整说明）
请不要随意删除 workspace 文件夹里面保存着你切好的素材、校对结果和生成的音频。想换电脑时，把整个 D:\VoiceTwin 和 D:\GPT-SoVITS 一起复制过去即可。
