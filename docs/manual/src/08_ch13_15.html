第 13 章进阶技巧：让声音更像你

按前面的步骤操作，已经能得到不错的效果。这一章介绍几种进一步提升效果的方法，以及设置文件、可选引擎、备份和换电脑等进阶操作。

13.1 提升相似度的方法（按效果从大到小）

#方法具体怎么做
1增加优质素材从 30 分钟增加到 1~3 小时，效果提升最明显（4.2 节）。放入新素材后：① 准备素材（只处理新文件）→ ② 重新训练。
2校对文字识别错的字会变成模型的"口误"。花 10~20 分钟校对（第 7 章），然后重新训练。
3剔除不好的素材把嗓子哑之后、感冒时、非常疲惫时的录音从素材里拿掉；在校对表里把有杂音、有别人说话的片段设为不保留。
4用 best 档生成每句生成 5 个版本挑最像的，并自动检查漏字、读错（9.2 节）。
5挑一个满意的参考音频参考音频决定了生成时的"状态"和"语气"。挑一条你最满意的，固定使用（13.2 节）。
6改写讲稿口语化、短句、标点准确（10.8 节）。
7补充英文素材要做英文课时特别重要（4.3 节）。

13.2 指定参考音频：固定你想要的语气

生成每一句话时，模型都需要一段你的真实录音作为参考音频，模仿它的音色、状态和语气。准备素材时，程序已经自动挑出了约 8~10 条最有代表性的参考音频（中文陈述句、疑问句、感叹句，英文句子各有），生成时会根据句子的语言和类型自动选择。

如果你觉得生成的语气整体偏平淡、偏急促，或者某一条参考音频的状态特别好，可以手动指定一条：

  1. 打开文件夹 D:\VoiceTwin\workspace\我的声音\references，里面是所有参考音频，例如： 
    references\
├── 第1课_b6dd09_0021.wav     ← 这里有一个常见的错误，很多同学都会犯。
├── 第1课_b6dd09_0047.wav     ← 但是要注意，不要把太复杂的逻辑都塞进一行。
├── 第2课_b09a84_0063.wav     ← 那么什么时候应该用普通的循环呢？（疑问句）
├── 第3课_ac0ef9_0061.wav     ← 今天的内容就到这里，大家辛苦了！（感叹句）
└── ……
  2. 双击逐个试听，找一条你最满意的（声音状态好、语气自然、没有杂音）。
  3. 它的文件名去掉 .wav 就是参考音频 id，例如 第1课_b6dd09_0047。在文件上点右键 → 重命名，按 Ctrl+C 复制文件名（复制后按 Esc 取消重命名）。
  4. 在 ③ 生成讲课音频 的 指定参考音频 id 里粘贴这个 id，然后生成。
参考音频的文字在哪看？用记事本打开 D:\VoiceTwin\workspace\我的声音\references.json，每一条参考音频都有 id（编号）、text（说的内容）、lang（zh 中文 / en 英文）、kind（statement 陈述 / question 疑问 / exclaim 感叹）、duration（秒数）。
指定参考音频后，所有句子（包括疑问句、英文句子）都会用这一条参考。所以：中文讲稿请指定中文参考，英文讲稿请指定英文参考；如果讲稿里疑问句很多、希望疑问语气更明显，就留空让程序自动选。
想用一条自己新录的参考？参考音频必须来自素材。可以专门录一段 3~10 秒、状态很好的话（例如"同学们好，今天我们来学习一个新的知识点。"），放进素材文件夹，重新 ① 准备素材；它有很大概率会被选为参考音频。

13.3 设置文件 config.yaml 详解

网页上没有的设置，都在 D:\VoiceTwin\config.yaml 里。大多数人不需要修改它。

如何修改

  1. 先备份：复制一份 config.yaml，改名为 config备份.yaml。
  2. 在 config.yaml 上点右键 → 打开方式 → 记事本。
  3. 按 Ctrl+F 搜索要改的项目名称，例如 output_format，修改冒号后面的值。
  4. 按 Ctrl+S 保存，关闭黑色窗口，重新双击桌面图标启动，设置才会生效。
修改时的三条规则 ① 冒号后面必须有一个空格：output_format: mp3 ✅，output_format:mp3 ❌。 ② 每行前面的空格缩进不能改（缩进表示层级），也不能用 Tab 键。 ③ # 后面是说明文字，不影响设置。

改坏了怎么办？把备份的文件改回 config.yaml；或者在命令提示符里运行 voicetwin.bat init-config --force 恢复默认设置（旧文件会自动备份为 config.yaml.bak；恢复默认后需要重新运行一次 install_windows.bat 写入整合包路径）。

13.4 可选引擎：Qwen3-TTS 与 IndexTTS

除了默认的 GPT-SoVITS，声音分身还支持两个开源引擎。它们主要做零样本克隆（不训练，只用参考音频模仿），适合对比试听或临时使用：

引擎特点是否需要训练显存要求
GPT-SoVITS（默认）用你的素材微调，最像你；安装最简单需要6GB 以上
Qwen3-TTS阿里开源，零样本自然度高，也支持微调可选零样本 8GB+；微调 12GB+
IndexTTS 2.5B 站开源，零样本克隆，情绪和时长控制强不需要8GB+
这两个引擎需要单独安装（要用到 conda、git 等工具），步骤比较专业，没有编程基础的用户建议只用默认的 GPT-SoVITS。安装方法见项目主页 README 的"可选引擎"一节。安装好后，在 ③ 生成讲课音频 的 引擎 里选择即可；环境检查里对应的行会从 ⚠️ 变成 ✅。

13.5 管理多个声音

一个"声音名称"就是一套独立的素材和模型。你可以建多个声音，互不影响，例如：

  • "我的声音"：日常讲课（中英文素材放在一起，推荐）。
  • "我的声音-精神饱满"：只放状态最好的几节课，用来做重要的公开课。
  • 帮同事做一个（需要对方本人授权，见附录 D）。

新建方法：在最上面的 声音名称 里输入新名字，然后从 ① 准备素材 开始。切换方法：点 声音名称 右边的小三角选择。

声音名称不能包含 \ / : * ? " < > | 这些字符。每个声音训练出的模型都会占用几百 MB 硬盘空间。

13.6 备份、换电脑和释放硬盘空间

需要备份什么

文件夹内容
D:\VoiceTwin\workspace所有声音的素材片段、校对结果、读音词典、参考音频、生成的音频。最重要。
D:\GPT-SoVITS\SoVITS_weights_v2ProPlus
D:\GPT-SoVITS\GPT_weights_v2ProPlus		训练好的模型文件（文件名以 vt_ 开头）。
D:\VoiceTwin\config.yaml你的设置。

换电脑

  1. 把 D:\VoiceTwin 和 D:\GPT-SoVITS 两个文件夹整个复制到新电脑（用移动硬盘）。推荐放在和原来一样的位置（都在 D 盘根目录）；放到别的位置也可以，下一步安装时输入新的整合包路径即可，训练好的模型会被自动找到。
  2. 在新电脑上双击 D:\VoiceTwin\install_windows.bat 重新安装一次（会重新生成桌面图标，已有的设置和数据会保留）。
  3. 双击桌面图标，选择"我的声音"，直接去 ③ 生成讲课音频 就能用了，不需要重新训练。

释放硬盘空间

  • 句子缓存：每一句生成的结果都会缓存（9.5 节），时间长了会占用较多空间。在命令提示符运行 voicetwin.bat clear-cache -v 我的声音 清空。清空后不影响模型，只是下次生成同样的句子时要重新生成。
  • 旧的生成结果：workspace\我的声音\outputs 里不需要的音频可以直接删除。
  • 训练中间文件：D:\GPT-SoVITS\logs\vt_…… 是训练时产生的中间文件，训练完成后可以删除（下次重新训练会自动重新生成，只是多花一点时间）。
  • 多余的模型版本：训练会保存多个版本的模型（文件名里有 e4、e8 或 e5、e10、e15 等）。不建议手动删除，删错了会导致生成失败；确实需要空间时，可以只保留 ② 训练模型 页面显示的最佳模型对应的文件。

13.7 在局域网或手机上使用（注意隐私）

默认情况下网页界面只能在本机打开。如果想在同一个局域网里的另一台电脑或平板上使用，可以在命令提示符里运行：

voicetwin.bat webui --host 0.0.0.0 --port 7860

然后在另一台设备的浏览器里访问 http://这台电脑的IP地址:7860（IP 地址可以在命令提示符里输入 ipconfig 查看"IPv4 地址"）。Windows 防火墙可能会弹窗询问，选择"允许"（仅专用网络）。

不要随意使用 --sharevoicetwin.bat webui --share 会生成一个任何人都能访问的公网链接，别人拿到链接就能用你的声音生成任意内容。除非你完全清楚风险，否则不要使用。

第 14 章命令行用法（选读）

网页界面能完成所有日常操作。命令行适合想批量处理（例如一次生成十几节课）或者想自动化的用户。不熟悉电脑的老师可以跳过这一章。

14.1 基本用法

  1. 按 3.7 节的方法，在 D:\VoiceTwin 打开命令提示符。
  2. 所有命令的格式都是：voicetwin.bat 命令 参数……，输入后按 Enter。
  3. 查看所有命令：voicetwin.bat -h；查看某个命令的详细参数：voicetwin.bat narrate -h。
路径的写法文件路径建议写完整路径（例如 D:\讲稿\第1课.md），路径里有空格时前后加英文双引号。-v 后面是声音名称，和网页里的"声音名称"一致。

14.4 实例：一次生成一整门课

假设你把 12 节课的讲稿放在 D:\讲稿 里（第01课.md ~ 第12课.md），想全部用 best 档生成，可以在 D:\VoiceTwin 里新建一个文本文件，改名为 批量生成.bat，用记事本写入：

@echo off
chcp 65001 >nul
cd /d "%~dp0"
for %%f in ("D:\讲稿\*.md") do (
    echo 正在生成 %%~nf ……
    call voicetwin.bat narrate -v 我的声音 "%%f" -q best -o "D:\成品\%%~nf.wav"
)
echo 全部完成！
pause

保存时在记事本的"另存为"对话框里把编码选为 UTF-8。先建好 D:\成品 文件夹，然后双击 批量生成.bat，电脑会一节一节地生成，完成后每节课的音频和字幕都在 D:\成品 里。可以晚上开始，第二天早上来看结果。

每节课生成完会在窗口里列出有"提示"的句子（例如 ⚠️ 第 7 句：语速过快/可能漏读（可用 --redo 7 重新生成）），按提示用 --redo 重做那几句即可。

14.5 用 Excel 校对后同步

7.3 节介绍了用 Excel 校对 transcripts.csv。改完保存后，除了在网页里点按钮，也可以在命令行运行：

voicetwin.bat review -v 我的声音
voicetwin.bat train -v 我的声音

第 15 章常见问题与故障排除

遇到问题先别急。绝大多数问题都能在这一章找到答案。每个问题都按"现象 → 原因 → 解决办法"来写。找不到答案时，看 15.8 节如何收集信息求助。

15.1 安装阶段

双击 install_windows.bat 后，黑色窗口一闪就没了
原因：系统阻止了 PowerShell 脚本运行，或者安装包没有完整解压。
解决：① 确认你是在解压后的 D:\VoiceTwin 文件夹里双击，而不是在压缩包里直接双击；② 在 install_windows.ps1 上点右键 → 使用 PowerShell 运行；③ 如果仍然不行，按 Win 键，输入 powershell，打开"Windows PowerShell"，输入下面这行后回车：
powershell -ExecutionPolicy Bypass -File D:\VoiceTwin\install_windows.ps1
提示"没有找到 ……\runtime\python.exe"
原因：输入的 GPT-SoVITS 整合包路径不对。
解决：打开你的整合包文件夹，确认里面直接能看到 runtime 文件夹和 go-webui.bat。如果解压后多套了一层文件夹（例如 D:\GPT-SoVITS\GPT-SoVITS-v2pro-2026xxxx\runtime），要输入里面那一层的路径。然后重新运行安装程序。
提示"这个 GPT-SoVITS 整合包版本太旧（缺少 api_v2.py）"
解决：按 3.2 节重新下载最新版整合包。
提示"安装失败：pip install ……请检查网络后重新运行安装程序"
原因：下载组件时网络中断。安装程序会先用国内镜像，失败后再试官方源。
解决：检查网络（关掉可能干扰的代理 / 加速器，或者反过来打开它），重新双击 install_windows.bat。重复运行是安全的，已经装好的部分不会重复下载。
提示"安装路径里有中文或空格"
这是提醒不是错误。个别组件对中文路径支持不好，建议按手册把程序放在 D:\VoiceTwin，整合包放在 D:\GPT-SoVITS。
环境检查里 ffmpeg 显示 ❌
解决：重新运行安装程序。仍然不行的话，确认整合包目录里有 ffmpeg.exe（整合包一般自带）；也可以在命令提示符里运行 D:\GPT-SoVITS\runtime\python.exe -m pip install imageio-ffmpeg 后再检查。
杀毒软件报毒 / 拦截
安装过程会下载 Python 组件、生成 .bat 脚本，个别杀毒软件可能误报。请从本项目的 GitHub Release 页面下载（3.1 节），然后在杀毒软件里把 D:\VoiceTwin 和 D:\GPT-SoVITS 加入信任区。

15.2 启动与网页界面

双击桌面图标后，浏览器没有自动打开
解决：看黑色窗口里有没有出现 Running on local URL: http://127.0.0.1:7860。出现了就手动打开浏览器，输入 127.0.0.1:7860 回车。推荐使用 Edge 或 Chrome 浏览器。
浏览器显示"无法访问此网站"
原因：程序还没启动完成，或者黑色窗口被关掉了、出错了。
解决：确认黑色窗口还开着；等 30 秒后刷新页面。黑色窗口里有红色报错的话，按 15.8 节处理。
黑色窗口提示端口被占用（Cannot find empty port / address already in use）
原因：之前打开的声音分身没关，或者其它程序占用了 7860 端口。
解决：关掉所有声音分身的黑色窗口，再重新双击图标；或者重启电脑。也可以换一个端口启动：在命令提示符运行 voicetwin.bat webui --port 7861，然后访问 127.0.0.1:7861。
黑色窗口里的中文显示成乱码
一般不影响使用，网页界面里的文字是正常的。启动脚本已经设置了 UTF-8 编码；个别老版本 Windows 仍可能显示乱码，可以忽略。
网页上点了按钮没反应 / 一直转圈
准备素材、训练、第一次生成都需要较长时间，请看下方日志有没有在更新。日志完全不动超过 10 分钟，看黑色窗口有没有报错。刷新网页会丢失当前页面的显示，但正在后台运行的任务会继续，完成后结果照常保存在 workspace 里。
下拉框里找不到"我的声音"
点 🔄 刷新。仍然没有的话，说明素材准备还没成功完成过一次，或者 config.yaml 里的 workspace 被改过。

15.3 准备素材阶段

提示"没有找到任何视频或音频文件"
原因：路径写错，或者文件格式不在支持列表里（4.4 节）。
解决：在文件夹地址栏复制路径再粘贴；确认文件扩展名（在资源管理器"查看"里勾选"文件扩展名"）。
下载识别模型很慢，或者失败
程序默认使用国内镜像（hf-mirror.com）。如果还是失败：① 换个时间再试；② 素材以中文为主的话，在 识别引擎 里改用 funasr（从阿里 ModelScope 下载，国内速度快）；③ 显存或网速有限时，可以在 config.yaml 里把识别模型改成 large-v3-turbo（更小更快）。
保留下来的素材比预期少很多
看处理结果里的"丢弃原因"（6.5 节）：
• "声音不像本人"很多：可能素材里确实有较多别人说话；也可能你的录音环境差别很大（不同教室、不同麦克风），可以在校对时把误删的改回保留；
• "识别置信度低""语速异常"很多：通常是录音质量差、背景音乐或回声大；
• "太短 / 太长"很多：说话停顿很少的话，可以在 config.yaml 里把 max_duration 调到 15。
提示"可用素材只有 X 分钟"或"英文素材不足 5 分钟"
这是提醒：素材少也能训练，但效果会差一些。按 4.2、4.3 节补充素材。
提示"去背景音乐需要安装 demucs"
你勾选了"视频有背景音乐"，但没有安装 demucs 组件。建议取消勾选，改用 4.6 节的 UVR5 方法先分离人声。
提示"没有挑到合适的参考音频"
原因：没有找到 3.5~9.5 秒、完整一句话的片段。通常是素材太少，或者识别出的文字都没有句末标点。
解决：增加素材；或者在校对时给句子补上句号、问号，保存后再生成。

15.4 训练阶段

报错 "CUDA out of memory"（显存不足）
解决：① 关闭其它占用显卡的程序（游戏、剪辑软件、其它 AI 工具、浏览器里的视频）；② 在 ② 训练模型 页面把 batch 改成 2（还不行改成 1）再训练；③ 或者在 config.yaml 里把 batch_size: auto 改成 batch_size: 2。
GTX 10 系列等老显卡训练报错，或者生成的声音全是杂音
老显卡不支持半精度加速。在 config.yaml 里把 is_half: true 改成 is_half: false，重新启动程序后再训练。
提示"没有检测到可用的 NVIDIA 显卡，训练会非常慢"
原因：电脑没有 NVIDIA 显卡，或者驱动没装好。
解决：按 2.4 节更新驱动后重启电脑，再运行环境检查。没有 N 卡的电脑训练可能需要几天，建议借用一台有 N 卡的电脑训练，训练好后把两个文件夹复制回来使用（13.6 节）。
提示"GPT-SoVITS 环境有问题：缺少预训练模型……"
按 3.6 节运行 voicetwin.bat download-models --source hf-mirror 补齐模型。
提示"gsv_s2_train 失败（退出码 X）"或"1A 文本处理没有产出"
训练的某一步出错了。错误信息下方会附上最后 30 行日志，常见原因：显存不足（见上）、硬盘空间不足（清理出 20GB 以上）、素材路径里有特殊字符。完整日志在 D:\VoiceTwin\workspace\我的声音\logs 里（附录 C）。
训练到一半电脑睡眠 / 断电 / 不小心关掉了窗口
重新打开程序，再点一次 开始训练 即可，从头开始训练。为避免这种情况，请按 8.1 节关闭自动睡眠。
训练特别慢，进度很久不动
SoVITS 每一轮可能需要几分钟到十几分钟（素材越多越久），进度按"轮"更新，所以会有一段时间不动。打开任务管理器 → 性能 → GPU，如果 GPU 使用率很高，说明正在正常训练，耐心等待即可。

15.5 生成阶段

提示"GPT-SoVITS 推理服务启动失败"或"启动超时"
解决：打开 workspace\我的声音\logs\gptsovits_api.log，看最后几行。常见原因：① 端口 9880 被占用（关闭其它 GPT-SoVITS 窗口，或者在 config.yaml 里把 port 改成 9881）；② 显存被其它程序占满；③ 模型文件不全（运行环境检查）。处理后关闭黑色窗口重新启动程序。
提示"还没有训练好的 GPT-SoVITS 模型，暂时使用官方底模做零样本克隆"
说明你还没有完成训练（或者训练失败），这时生成的声音只是"有点像"。请先完成第 8 章的训练。
提示"讲稿里没有可以朗读的内容"
讲稿为空，或者全部是代码块、图片、表情符号。检查讲稿内容；如果上传了文件，确认文件本身有文字（例如 Word 文档里的文字不是图片）。
提示"读取 Word 讲稿需要：pip install python-docx"
把 Word 讲稿另存为 .txt 再上传即可；或者重新运行一次最新版的安装程序（v0.1.1 起会自动安装 Word 支持）。
上传讲稿文件后，生成的还是文本框里的旧内容 / 反过来
上传了文件时以文件为准，文本框的内容会被忽略。想用文本框，先点上传区域右上角的 ✕ 移除文件。
生成的音频里某些句子有杂音、电流声、吞字、重复
记下句子编号，用"只重新生成第几句"重做（9.5 节）；用 best 档会自动检查和重试。某一句反复出问题，改写这句话（拆短、换说法）。
某个字 / 词总是读错
写进读音纠正词典（10.4 节）。
生成很慢
第一次生成需要启动推理服务，多等 1 分钟是正常的。之后速度取决于档位：best 档每句生成 5 个版本还要识别检查，最慢。试听讲稿用 fast 档，正式生成再用 best 档。

15.6 效果问题

声音不够像
按 13.1 节的方法从上到下逐条尝试。其中增加素材、校对文字、剔除嗓子哑时的录音效果最明显。
语速比我平时快 / 慢
程序已经自动校准了语速。如果仍然觉得不对，用 语速倍数 调整（0.95 慢一点，1.05 快一点）。也可以在 ② 训练模型 页面点 重新挑选最佳模型，重新校准一次。
句子之间的停顿太长 / 太短
停顿是按你素材里的习惯统计的。想整体调整，可以在 config.yaml 里把 pauses 改成 fixed，再修改 fixed_pauses 里的秒数（13.3 节）；个别位置用停顿标记（10.3 节）。
英文有中文口音
加入你讲英文的录音（至少 5~10 分钟），重新 ① 准备素材、② 训练。
语气太平淡，没有讲课的感觉
① 讲稿更口语化，多用问句、感叹句（10.8 节）；② 挑一条语气生动的参考音频指定使用（13.2 节）；③ 素材里多放一些你状态好、有激情的讲课录音。
声音听起来有点闷 / 有点"电音"
通常和素材质量有关：素材被压缩得很厉害、降噪太强。可以在 config.yaml 里把 denoise 改成 off，或者换用更清晰的原始录音，重新准备素材并训练。

15.7 其它问题

我移动了 VoiceTwin 或 GPT-SoVITS 文件夹，现在打不开了
重新运行一次 install_windows.bat，输入新的整合包路径。其它设置和 workspace 里的数据都会保留。
如何升级到新版本
从 Release 页面下载新版本的压缩包，解压后覆盖到 D:\VoiceTwin（选择"替换目标中的文件"），然后重新双击 install_windows.bat。你的 workspace、config.yaml 不会被覆盖（压缩包里不包含它们）。
如何卸载
① 在命令提示符运行 D:\GPT-SoVITS\runtime\python.exe -m pip uninstall voicetwin；② 删除 D:\VoiceTwin 文件夹（workspace 里有你的素材和生成的音频，需要的话先备份）；③ 删除桌面图标。GPT-SoVITS 整合包不需要的话也可以整个删除。
没有网络能用吗
安装、第一次准备素材（下载识别模型）、第一次使用 best 档需要联网下载。全部下载完成后，准备素材、训练、生成都可以离线进行。

15.8 如何收集信息并求助

如果以上方法都解决不了，请收集下面这些信息再求助（例如在项目的 GitHub 页面提交 Issue），能大大加快解决速度：

  1. 环境检查结果：在网页 环境检查 页面点检查，截图；或者在命令提示符运行 voicetwin.bat doctor，复制全部输出。
  2. 出错时的完整信息：网页日志或黑色窗口里的红色报错，截图或复制文字。
  3. 详细错误信息：用命令行重做出错的那一步，并在最后加上 --verbose，例如：
    voicetwin.bat narrate -v 我的声音 D:\讲稿\第1课.md --verbose
  4. 日志文件：D:\VoiceTwin\workspace\我的声音\logs 里对应的日志（附录 C 说明了每个日志的用途）。
  5. 你的电脑配置：显卡型号、显存、Windows 版本，以及声音分身的版本号（在 Release 页面或压缩包文件名里）。
提交日志或截图前，请检查里面有没有你不想公开的信息（例如讲课内容、个人姓名、文件路径里的真实姓名）。不要上传你的素材音频或训练好的模型文件，别人拿到它们就能模仿你的声音。
