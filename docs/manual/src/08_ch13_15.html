第 13 章进阶技巧：让声音更像你

按前面的步骤操作，已经能得到不错的效果。这一章介绍几种进一步提升效果的方法，以及设置文件、可选引擎、多个声音、备份和换电脑等进阶操作。

13.1 提升相似度的方法（按效果从大到小）

#方法具体怎么做
1增加优质素材从 30 分钟增加到 1~3 小时，效果提升最明显（4.2 节）。放入新素材后：① 准备素材（只处理新文件）→ ② 重新训练。
2校对文字识别错的字会变成模型的"口误"。点 🔍 自动查找可能的错字，把标红的字看一遍、改一改（第 7 章），然后重新训练。
3剔除不好的素材把嗓子哑之后、感冒时、非常疲惫时的录音从素材里拿掉；在校对表里把有杂音、有别人说话的片段的"保留"改成"否"。
4用「完美」档生成每句最多试 20 次、严格检查漏字错字，自动挑最像你的，还做两个版本让你选（第 9 章）。显卡正常（显存 8GB 以上）时默认就是它。结果表里标着"低于 85%"的句子，用"只重新生成第几句"重做（9.5 节）。
5挑一个满意的参考音频参考音频决定了生成时的"状态"和"语气"。挑一条你最满意的，固定使用（13.2 节）。
6改写讲稿口语化、短句、标点准确（10.8 节）。
7补充英文素材要做英文课时特别重要（4.3 节）。
训练参数不用自己调② 训练模型 会按你的显卡显存和素材多少，自动选出这台电脑能做到的最好方案（每批数量、训练轮数、多久存一次模型），训练完再自动挑出最像你的那个版本（第 8 章）。手动把轮数改大不一定更像，练太多反而可能变差。

13.2 指定参考音频：固定你想要的语气

生成每一句话时，模型都需要一段你的真实录音作为参考音频，模仿它的音色、状态和语气。准备素材时，程序已经自动挑出了约 8 条最有代表性的参考音频（中文陈述句、疑问句、感叹句，英文句子各有），生成时会根据句子的语言和类型自动选择。

如果你觉得生成的语气整体偏平淡、偏急促，或者某一条参考音频的状态特别好，可以手动指定一条：

  1. 打开文件夹 D:\VoiceTwin\workspace\我的声音\references，里面是所有参考音频，例如： 
    references\
├── 第1课_b6dd09_0021.wav     ← 这里有一个常见的错误，很多同学都会犯。
├── 第1课_b6dd09_0047.wav     ← 但是要注意，不要把太复杂的逻辑都塞进一行。
├── 第2课_b09a84_0063.wav     ← 那么什么时候应该用普通的循环呢？（疑问句）
├── 第3课_ac0ef9_0061.wav     ← 今天的内容就到这里，大家辛苦了！（感叹句）
└── ……
  2. 双击逐个试听，找一条你最满意的（声音状态好、语气自然、没有杂音）。
  3. 它的文件名去掉 .wav 就是参考音频的编号（id），例如 第1课_b6dd09_0047。在文件上点右键 → 重命名，按 Ctrl+C 复制文件名（复制后按 Esc 取消重命名）。
  4. 在 ③ 生成讲课音频 里点开 高级设置（一般不用改），把编号粘贴到 指定参考音频编号（留空 = 自动挑选） 里，然后生成。
参考音频的文字在哪看？用记事本打开 D:\VoiceTwin\workspace\我的声音\references.json，每一条参考音频都有 id（编号）、text（说的内容）、lang（zh 中文 / en 英文）、kind（statement 陈述 / question 疑问 / exclaim 感叹）、duration（秒数）。
指定参考音频后，所有句子（包括疑问句、英文句子）都会用这一条参考。所以：中文讲稿请指定中文参考，英文讲稿请指定英文参考；如果讲稿里疑问句很多、希望疑问语气更明显，就留空让程序自动选。
想用一条自己新录的参考？参考音频必须来自素材。可以专门录一段 3~10 秒、状态很好的话（例如"同学们好，今天我们来学习一个新的知识点。"），放进素材文件夹，重新 ① 准备素材；它有很大概率会被选为参考音频。

13.3 设置文件 config.yaml 详解

网页上没有的设置，都在 D:\VoiceTwin\config.yaml 里。大多数人不需要修改它。

如何修改

  1. 先备份：复制一份 config.yaml，改名为 config备份.yaml。
  2. 在 config.yaml 上点右键 → 打开方式 → 记事本。
  3. 按 Ctrl+F 搜索要改的项目名称，例如 output_format，修改冒号后面的值。
  4. 按 Ctrl+S 保存，关闭黑色窗口，重新双击桌面图标启动，设置才会生效。
修改时的三条规则 ① 冒号后面必须有一个空格：output_format: mp3 ✅，output_format:mp3 ❌。 ② 每行前面的空格缩进不能改（缩进表示层级），也不能用 Tab 键。 ③ # 后面是说明文字，不影响设置。

改坏了怎么办？把备份的文件改回 config.yaml；或者在命令提示符里运行 voicetwin.bat init-config --force --gptsovits-root D:\GPT-SoVITS，恢复成默认设置并写好整合包的位置（旧文件会自动备份为 config.yaml.bak）。

从旧版本升级的老师请注意升级时安装程序会保留你原来的 config.yaml，所以里面可能没有下表里的新设置项（例如 similarity 部分），也可能还写着旧的 quality: balanced。文件里没写的项会自动使用默认值，不影响使用。想换成新版本的完整设置文件，运行上面那条 init-config --force 命令即可。

13.4 可选引擎：Qwen3-TTS 与 IndexTTS

除了默认的 GPT-SoVITS，声音分身还支持两个开源引擎。它们主要做零样本克隆（不训练，只用参考音频模仿），适合对比试听或临时使用：

引擎特点是否需要训练显存要求
GPT-SoVITS（默认）用你的素材微调，最像你；安装最简单需要6GB 以上
Qwen3-TTS阿里开源，零样本自然度高，也支持微调可选零样本 8GB+；微调 12GB+
IndexTTS 2.5B 站开源，零样本克隆，情绪和时长控制强不需要8GB+
这两个引擎需要单独安装（要用到 conda、git 等工具），步骤比较专业，没有编程基础的用户建议只用默认的 GPT-SoVITS。安装方法见项目主页 README 的"可选引擎"一节。安装好后，在 ③ 生成讲课音频 的 高级设置（一般不用改） → 引擎 里选择即可；环境检查里对应的行会从 ⚠️ 变成 ✅。

13.5 管理多个声音：我的声音库

一个"声音名称"就是一套独立的素材和模型。你可以建多个声音，互不影响，例如：

  • "我的声音"：日常讲课（中英文素材放在一起，推荐）。
  • "我的声音-精神饱满"：只放状态最好的几节课，用来做重要的公开课。
  • 帮同事做一个（需要对方本人授权，见附录 D）。

新建：在最上面的 声音名称 里输入新名字，然后从 ① 准备素材 开始。

查看和切换：点开声音名称下面的 🎙️ 我的声音库（共 N 个），每个声音一行，列出 # / 名称 / 素材（分钟 / 条）/ 状态 / 最佳模型 / 最后修改时间，一眼就能看出哪个声音训练好了。点哪一行就选中哪个声音（上面的"声音名称"会跟着变），表格下面还会出现 ▶ 试听这个声音 播放器，可以听一听（5.2 节）。也可以点 声音名称 右边的小三角直接选。新建的声音没出现时，点 🔄 刷新声音列表。

声音名称不能包含 \ / : * ? " < > | 这些字符。每个声音训练出的模型都会占用不少硬盘空间（通常 1 GB 以上）。程序同一时间只做一件耗时的事：一个声音正在训练时，不能同时给另一个声音准备素材或生成音频。

13.6 备份、换电脑和释放硬盘空间

需要备份什么

文件夹内容
D:\VoiceTwin\workspace所有声音的素材片段、校对结果、读音词典、参考音频、生成的音频。最重要。
D:\GPT-SoVITS\SoVITS_weights_v2ProPlus
D:\GPT-SoVITS\GPT_weights_v2ProPlus		训练好的模型文件（文件名以 vt_ 开头）。
D:\VoiceTwin\config.yaml你的设置。

换电脑

  1. 把 D:\VoiceTwin 和 D:\GPT-SoVITS 两个文件夹整个复制到新电脑（用移动硬盘）。推荐放在和原来一样的位置（都在 D 盘根目录）；放到别的位置也可以，下一步安装时输入新的整合包路径即可，训练好的模型会被自动找到。
  2. 在新电脑上双击 D:\VoiceTwin\install_windows.bat 重新安装一次（会重新生成桌面图标，已有的设置和数据会保留）。
  3. 双击桌面图标，先看最上面的显卡状态条是不是绿色，再选择"我的声音"（或者在 🎙️ 我的声音库 里点一下它），直接去 ③ 生成讲课音频 就能用了，不需要重新训练。

释放硬盘空间

  • 句子缓存：每一句生成的结果都会缓存（9.5 节），时间长了会占用较多空间。在命令提示符运行 voicetwin.bat clear-cache -v 我的声音 清空。清空后不影响模型，只是下次生成同样的句子时要重新生成。
  • 旧的生成结果：workspace\我的声音\outputs 里不需要的音频可以直接删除，包括「完美」档没选用的那个版本（文件名后面带 _未去杂音 或 _去杂音）、试听语速的音频和盲听测试的文件夹。
  • 训练中间文件：D:\GPT-SoVITS\logs\vt_…… 是训练时产生的中间文件，训练完成后可以删除（下次重新训练会自动重新生成，只是多花一点时间）。里面的 old_runs 是以前几次训练的备份（程序只保留最近 2 次，每次大约 1 GB）。
  • 多余的模型版本：训练会每隔几轮存一个模型（文件名里有 e2、e4、e8 或 e3、e6、e15 等），训练完自动挑出最像你的那个。不建议手动删除，删错了会导致生成失败；确实需要空间时，可以只保留 ② 训练模型 页面显示的最佳模型对应的文件。

13.7 在局域网或手机上使用（注意隐私）

默认情况下网页界面只能在本机打开。想在同一个局域网里的另一台电脑或平板上使用：先关掉桌面图标打开的那个黑色窗口（否则只会提示"声音分身已经在运行了"），再在命令提示符里运行 voicetwin.bat webui --host 0.0.0.0 --port 7860， 然后在另一台设备的浏览器里访问 http://这台电脑的IP地址:7860（IP 地址用 ipconfig 查看"IPv4 地址"；端口以黑色窗口里显示的为准）。Windows 防火墙弹窗时选"允许"（仅专用网络）。

不要随意使用 --sharevoicetwin.bat webui --share 会生成一个任何人都能访问的公网链接，别人拿到链接就能用你的声音生成任意内容。除非你完全清楚风险，否则不要使用。

第 14 章命令行用法（选读）

网页界面能完成所有日常操作。命令行适合想批量处理（例如一次生成十几节课）或者想自动化的用户。不熟悉电脑的老师可以跳过这一章。

14.1 基本用法

  1. 按 3.7 节的方法，在 D:\VoiceTwin 打开命令提示符。
  2. 所有命令的格式都是：voicetwin.bat 命令 参数……，输入后按 Enter。
  3. 查看所有命令：voicetwin.bat -h；查看某个命令的详细参数：voicetwin.bat narrate -h。
路径的写法文件路径建议写完整路径（例如 D:\讲稿\第1课.md），路径里有空格时前后加英文双引号。-v 后面是声音名称，和网页里的"声音名称"一致。

耗时的命令（准备素材、训练、生成、下载模型）会在窗口里一行一行地打印进度，例如"⏳ 45% ｜第 3/7 步 识别每段话的文字｜……｜已用 3 分 20 秒｜这一步大约还要 5 分钟"，完成时打印"✅ 完成，用时 ……"；运行期间电脑不会自动睡眠。命令运行时不要用鼠标点窗口里面，万一窗口标题出现"选择"，按一下 Enter 就能继续。

say直接生成一句话（不输出字幕）voicetwin.bat say -v 我的声音 "同学们好，欢迎来到今天的课程。"
evaluate评估一段音频有多像你（= 网页 ④）voicetwin.bat evaluate -v 我的声音 D:\测试.wav --text "音频里说的话"
auto全自动：准备 → 训练 → 挑选 → 生成一段试听voicetwin.bat auto -v 我的声音 -i D:\讲课素材
mux把音频放进视频（替换原声）见 11.3 节
download-models下载缺少的 GPT-SoVITS 预训练模型（= 网页 🩺 环境检查 的"⬇️ 下载缺少的模型"）voicetwin.bat download-models --source hf-mirror
clear-cache清空句子缓存voicetwin.bat clear-cache -v 我的声音
init-config生成 / 更新设置文件voicetwin.bat init-config --gptsovits-root D:\GPT-SoVITS
webui启动网页界面（= 双击桌面图标；端口被占用时自动换一个）voicetwin.bat webui --port 7861
⑤ 鉴别 里的机器鉴别和观众盲听测试只能在网页里做，没有对应的命令。

14.4 实例：一次生成一整门课

假设你把 12 节课的讲稿放在 D:\讲稿 里（第01课.md ~ 第12课.md），想全部用「完美」档生成，可以在 D:\VoiceTwin 里新建一个文本文件，改名为 批量生成.bat，用记事本写入：

@echo off
chcp 65001 >nul
cd /d "%~dp0"
for %%f in ("D:\讲稿\*.md") do (
    echo 正在生成 %%~nf ……
    call voicetwin.bat narrate -v 我的声音 "%%f" -q perfect -o "D:\成品\%%~nf.wav"
)
echo 全部完成！
pause

保存时在记事本的"另存为"对话框里把编码选为 UTF-8。先建好 D:\成品 文件夹，然后双击 批量生成.bat，电脑会一节一节地生成。「完美」档最慢，可以晚上开始，第二天早上来看结果；想快一点就把 -q perfect 改成 -q best。完成后每节课都在 D:\成品 里：第01课.wav 是推荐的版本，另外还有 第01课_未去杂音.wav、第01课_去杂音.wav 两个版本可以对比，以及字幕 第01课.srt 和报告。

每节课生成完，窗口里会列出有提示的句子（例如 ⚠️ 第 7 句：低于 85%，建议重新生成或改写这一句），最后一行写着 想只重做这几句：加上 --redo 7，按提示用 --redo 重做那几句即可。

14.5 用 Excel 校对后同步

7.3 节介绍了用 Excel 校对 transcripts.csv。改完保存并关掉 Excel 后，在命令行运行下面两行：第一行读回你的修改，第二行重新训练。

voicetwin.bat review -v 我的声音
voicetwin.bat train -v 我的声音

运行完第一行后，网页里的校对表要点 🔄 重新载入 才会显示新内容。在重新载入之前不要在网页里点"保存修改"，否则网页表格里的旧内容会盖掉 Excel 里的修改。

第 15 章常见问题与故障排除

遇到问题先别急。出错时，进度条会变成红色，并用大白话写出"原因"和"怎么办"，大多数情况照着做就能解决。这一章按"现象 → 原因 → 解决办法"列出常见问题。找不到答案时，看 15.8 节如何收集信息求助。

15.1 安装阶段

双击 install_windows.bat 后，黑色窗口一闪就没了
原因：系统阻止了 PowerShell 脚本运行，或者安装包没有完整解压。
解决：① 确认你是在解压后的 D:\VoiceTwin 文件夹里双击，而不是在压缩包里直接双击；② 在 install_windows.ps1 上点右键 → 使用 PowerShell 运行；③ 如果仍然不行，按 Win 键，输入 powershell，打开"Windows PowerShell"，输入下面这行后回车：
powershell -ExecutionPolicy Bypass -File D:\VoiceTwin\install_windows.ps1
提示"没有找到 ……\runtime\python.exe"
原因：输入的 GPT-SoVITS 整合包路径不对。
解决：打开你的整合包文件夹，确认里面直接能看到 runtime 文件夹和 go-webui.bat。如果解压后多套了一层文件夹（例如 D:\GPT-SoVITS\GPT-SoVITS-v2pro-2026xxxx\runtime），要输入里面那一层的路径。然后重新运行安装程序。
提示"这个 GPT-SoVITS 整合包版本太旧（缺少 api_v2.py）"
解决：按 3.2 节重新下载最新版整合包。
提示"安装失败：pip install ……请检查网络后重新运行安装程序"
原因：下载组件时网络中断。安装程序会先用国内镜像，失败后再试官方源。
解决：检查网络（关掉可能干扰的代理 / 加速器，或者反过来打开它），重新双击 install_windows.bat。重复运行是安全的，已经装好的部分不会重复下载。
提示"安装路径里有中文或空格"
这是提醒不是错误。个别组件对中文路径支持不好，建议按手册把程序放在 D:\VoiceTwin，整合包放在 D:\GPT-SoVITS。
环境检查里 ffmpeg 显示 ❌
解决：重新运行安装程序。仍然不行的话，确认整合包目录里有 ffmpeg.exe（整合包一般自带）；也可以在命令提示符里运行 D:\GPT-SoVITS\runtime\python.exe -m pip install imageio-ffmpeg 后再检查。
杀毒软件报毒 / 拦截
安装过程会下载 Python 组件、生成 .bat 脚本，个别杀毒软件可能误报。请从本项目的 GitHub Release 页面下载（3.1 节），然后在杀毒软件里把 D:\VoiceTwin 和 D:\GPT-SoVITS 加入信任区。

15.2 启动、网页界面和进度条

双击桌面图标后，浏览器没有自动打开
解决：看黑色窗口里"网页地址："后面写的地址（一般是 http://127.0.0.1:7860），手动打开浏览器，把它输入地址栏后回车。推荐使用 Edge 或 Chrome 浏览器。
浏览器显示"无法访问此网站"
原因：程序还没启动完成，或者黑色窗口被关掉了、出错了；也可能是代理软件挡住了本机地址。
解决：① 确认黑色窗口还开着，等 30 秒后刷新页面；② 黑色窗口里有红色报错的话，按 15.8 节处理；③ 开着 VPN、加速器等代理软件时，先关掉它，或者在代理软件里把 127.0.0.1 和 localhost 设为"直连 / 不走代理"。
又双击了一次桌面图标，多出来一个黑色窗口
没关系。程序不会再开第二个，新窗口会提示"声音分身已经在运行了（在另一个黑色窗口里），已经帮你打开网页。这个窗口可以关掉。"关掉新出现的那个窗口就行，原来的黑色窗口不要关。
黑色窗口里写着"7860 端口被别的软件占用了，这次改用 7861 端口"
这是正常的提示，不用处理：程序自动换了一个空闲的端口，浏览器会打开新地址。浏览器没打开的话，以黑色窗口里"网页地址："后面写的为准（例如 127.0.0.1:7861）。
如果提示的是"端口被占用（可能已经开着一个声音分身）"：先看看浏览器里是不是已经打开了声音分身的网页；没有的话，关掉所有声音分身的黑色窗口，再双击桌面图标；还不行就重启电脑。
用鼠标点了一下黑色窗口，程序好像卡住不动了
新版本启动时已经关掉了黑色窗口的"快速编辑"功能，一般点了也不会卡住。万一窗口标题出现"选择"两个字（程序被暂停了），按一下 Enter 就能继续。平时把黑色窗口最小化，不要用鼠标点它里面。
黑色窗口里的中文显示成乱码
一般不影响使用，网页界面里的文字是正常的。启动脚本已经设置了 UTF-8 编码；个别老版本 Windows 仍可能显示乱码，可以忽略。
页面最上面是红色的"❌ 显卡没有正常工作"
原因：显卡驱动没装好或太旧，或者电脑没有 NVIDIA 显卡。不处理的话，训练会非常慢（可能要十几个小时）。
解决：① 照着红条里的"怎么办"做：到 https://www.nvidia.cn/drivers/lookup/ 按显卡型号下载最新驱动，安装后重启电脑（2.4 节）；② RTX 50 系列显卡要用文件名带 nvidia50 的整合包；③ 重新打开程序，点 🔄 重新检查显卡。还是红色的话，把红条里的文字和 🩺 环境检查 页面截图发给帮你的人（15.8 节）。
黄色的"⚠️"不是故障：显卡能用，只是显存比较小，或者可用显存不多（可能被游戏、剪映、在线视频占用），条里写着原因和建议。
进度条变成红色，停下了
红框里写着停在第几步，下面有原因和怎么办（例如"原因：讲稿是空的；怎么办：在「讲稿」框里粘贴文字，或者上传 txt / Word 文件。"），照着做，再点一次原来的开始按钮就行（5.3 节）。本章后面也按"原因"里的文字列出了常见情况。
自己解决不了时：点开下面的 详细过程（出问题时可以复制给帮你的人），点文字框右上角的复制按钮，把内容和红框的截图一起发给帮你的人。
进度条变成黄色，很久不动
黄色表示已经 3 分钟以上没有新进度，这时"全部还要多久"会显示"暂时算不出来"。多数情况是这一步本来就慢：第一次下载识别模型（约 3 GB）、处理很长的视频、训练中比较长的一轮。
解决：① 先耐心等，不要关黑色窗口；② 打开任务管理器 → 性能 → GPU，显卡使用率很高说明正在干活；③ 超过半小时还不动，点 ⏹ 停止（5 秒内点两次），再重新点开始。已经做好的部分不会丢。
点了按钮，提示"现在正在「……」……同一时间只能做一件事"
这不是出错。准备素材、训练、生成这些事都很占显卡，程序同一时间只做一件，例如素材还在准备时又点了"开始训练"。提示里写着正在做什么、已经做了多久、百分之几，以及进度在哪一页能看到。等它完成后再点；不想等，就到那一页点 ⏹ 停止（5 秒内点两次）。
不小心关掉或刷新了网页，正在做的事还在吗
在。只要黑色窗口开着，任务就在后台继续。重新打开网页后，进度条会接着显示；如果已经做完了，页面上直接显示最新的结果。
声音名称的下拉框里找不到"我的声音"
点 🔄 刷新声音列表，或者点开 🎙️ 我的声音库 看看。仍然没有的话，说明素材准备还没成功完成过一次，或者 config.yaml 里的 workspace 被改过。

15.3 准备素材阶段

提示"文件夹里没找到视频或录音"
原因：路径写错，或者文件格式不在支持列表里（4.4 节）。
解决：在文件夹窗口顶部的地址栏复制路径再粘贴；确认文件扩展名（在资源管理器"查看"里勾选"文件扩展名"），支持 mp4、mov、mkv、mp3、wav、m4a 等常见格式。
下载识别模型很慢，或者失败
程序默认使用国内镜像（hf-mirror.com）。如果还是失败：① 换个时间再试；② 素材以中文为主的话，在 ① 准备素材 的 高级设置（一般不用改） 里，把 识别文字用哪个引擎 改成"纯中文课更准"（funasr，从阿里 ModelScope 下载，国内速度快）；③ 显存或网速有限时，可以在 config.yaml 里把识别模型改成 large-v3-turbo（更小更快）。
保留下来的素材比预期少很多
看片段表格里的"丢弃原因"一列（6.5 节）：
• "声音不像本人（可能是别人说话）"很多：可能素材里确实有较多别人说话；也可能你的录音环境差别很大（不同教室、不同麦克风），可以在校对时把误删的"保留"改回"是"；
• "识别置信度低""语速异常（文字可能不对）"很多：通常是录音质量差、背景音乐或回声大；
• "太短""太长"很多：说话停顿很少的话，可以在 config.yaml 里把 max_duration 调到 15。
提示"可用素材只有 X 分钟"或"英文素材不足 5 分钟"
这是提醒：素材少也能训练，但效果会差一些。按 4.2、4.3 节补充素材。
提示"去背景音乐需要安装 demucs"
你勾选了"视频有背景音乐（去除背景音乐，会慢一些）"，但没有安装 demucs 组件。建议取消勾选，改用 4.6 节的 UVR5 方法先分离人声。
"🔍 自动查找可能的错字"找到的很少，或者说没有装第二个识别引擎
查错字最好的办法是用第二个识别引擎（例如 FunASR）把每段再听一遍、逐字对比。没有第二个引擎时，程序会改用"识别时没把握的字"和规则来查，能发现的错字少一些，但照样能用。标红只是提醒"可能有错"，不一定真错，也可能有个别错字没被发现；时间允许的话，自己把文字通读一遍最可靠（第 7 章）。
提示"没有挑到合适的参考音频"
原因：没有找到 3.5~9.5 秒、完整一句话的片段。通常是素材太少，或者识别出的文字都没有句末标点。
解决：增加素材；或者在校对时给句子补上句号、问号，保存后再生成。

15.4 训练阶段

训练时提示"显卡内存（显存）不够"（CUDA out of memory）
程序会先自动把每批数量减半再试一次（进度条上会写"……时显存不够：自动把每批数量从 6 减到 3，再试一次"），一般不用管。如果最后还是变成红色：① 关闭其它占用显卡的程序（游戏、剪映、其它 AI 工具、浏览器里的视频）；② 在 ② 训练模型 点开 高级设置（一般不用改，数字保持 0 = 自动），把 每批数量 batch（0 = 自动；显存不够报错时改成 2） 改成 2（还不行改成 1），再点 开始训练；③ 或者在 config.yaml 里把 batch_size: auto 改成 batch_size: 2。
GTX 10 系列等老显卡训练报错，或者生成的声音全是杂音
老显卡不支持半精度加速。在 config.yaml 里把 is_half: true 改成 is_half: false，重新启动程序后再训练。
训练特别慢，进度很久才动一下
音色（SoVITS）每一轮可能要几分钟到十几分钟，素材越多越久。进度条的"现在："会写着"训练音色：第 3/8 轮（45%）"这样的进度和大约几点完成，只要是绿色就在正常工作；变成黄色也先别急（15.2 节）。如果页面最上面的显卡状态条是红色，训练用不上显卡，会非常慢，先按 15.2 节处理显卡；没有 N 卡的电脑可以借一台有 N 卡的电脑训练，训练好后把两个文件夹复制回来使用（13.6 节）。
提示"缺少 GPT-SoVITS 的模型文件"或"缺少预训练模型"
到 🩺 环境检查 页面点 ⬇️ 下载缺少的模型，等进度条走到 100% 再训练（3.6 节）。
训练停在某一步变红，技术细节里有"gsv_s2_train 失败（退出码 X）"或"1A 文本处理没有产出"
训练的某一步出错了。先看红框里的"原因"和"怎么办"。常见原因：显存不足（见上）、硬盘空间不足（至少空出 30 GB）、素材路径里有特殊字符。完整日志在 D:\VoiceTwin\workspace\我的声音\logs 里（附录 C）；求助时把"详细过程"里的内容一起发过去。
训练到一半电脑睡眠 / 断电 / 不小心关掉了黑色窗口
重新打开程序，再点一次 开始训练 即可；素材没有改动时，一般会从上次存下的进度接着练。训练、生成这些长任务进行时，程序会自动阻止电脑睡眠（合上笔记本盖子仍然会睡眠）；保险起见也可以按 8.1 节关闭自动睡眠。

15.5 生成阶段

提示"GPT-SoVITS 推理服务启动失败"或"启动超时"
解决：打开 workspace\我的声音\logs\gptsovits_api.log，看最后几行。常见原因：① 端口 9880 被占用（关闭其它 GPT-SoVITS 窗口，或者在 config.yaml 里把 port 改成 9881）；② 显存被其它程序占满；③ 模型文件不全（运行环境检查）。处理后关闭黑色窗口重新启动程序。
提示"还没有训练好的 GPT-SoVITS 模型，暂时使用官方底模做零样本克隆"
说明你还没有完成训练（或者训练失败），这时生成的声音只是"有点像"。请先完成第 8 章的训练。
提示"讲稿是空的"
讲稿框里没有文字，或者全部是代码块、图片、表情符号。在"讲稿"框里粘贴文字，或者上传 txt / Word 文件；如果上传了文件，确认文件本身有文字（例如 Word 文档里的文字不是图片）。
上传 Word 讲稿时提示"读不了这个文件"或"不支持这种文件"
讲稿支持 .txt、.docx、.md 和 .srt。旧的 .doc、WPS 的 .wps、PDF 都不行：在 Word 或 WPS 里点"文件 → 另存为"，类型选 .docx 或 .txt，再上传。.docx 也读不了的话，重新运行一次 install_windows.bat（会装上读取 Word 的组件），或者直接把文字复制粘贴到"讲稿"框里。
上传了讲稿文件，生成的内容不对
上传 txt / Word / md 文件后，文件里的文字会直接放进"讲稿"框，生成时用的就是框里的文字，可以先改再生成。上传的是 .srt 字幕文件时，会按字幕的时间轴生成，这时以字幕文件为准；想改用框里的文字，点文件右上角的 × 删除它。
生成的音频里某些句子有杂音、电流声、吞字、重复
看结果表里这句的编号，在"只重新生成第几句"里填编号再点 生成，只重做这几句（9.5 节）。「最好」「极致」「完美」档会自动检查漏字、读错并重试。某一句反复出问题，就改写这句话（拆短、换说法）。
结果表里某一句标着"低于 85%，建议重新生成或改写这一句"
说明这一句试了好几次，最像的那个也没达到 85%。先用"只重新生成第几句"重做一两次；还不行就改写这句（换个说法、拆成两句、检查标点），或者换一条参考音频（13.2 节）。很多句都这样时，问题多半在素材和校对上，按 13.1 节改进。
某个字 / 词总是读错
写进读音纠正词典（10.4 节）。
选了「完美」，却只生成了一个版本，没有"版本 B：去杂音"
说明电脑上没有装 noisereduce 组件（环境检查里它显示 ⚠️）。重新双击 install_windows.bat 安装一次就会装上，你的设置和声音都会保留。
生成时提示"显卡内存（显存）不够"
关掉游戏、剪映、在线视频等占用显卡的程序再试；还不行就把"质量"选低一档（例如从「完美」改成「极致」或「最好」）。
生成很慢
第一次生成需要先启动合成引擎，多等 1 分钟是正常的。之后速度取决于档位：「完美」每句最多试 20 次，还要做两个版本，最慢；「极致」次之。进度条上会写大约几点完成。检查讲稿、试听读音时用「快速」或「均衡」，正式发布再用「完美」。

15.6 效果问题

声音不够像
按 13.1 节的方法从上到下逐条尝试，其中增加素材、校对文字、剔除嗓子哑时的录音效果最明显。改进前后可以用 ⑤ 鉴别 打分对比，或者做一次盲听测试，让同事、学生来听（第 12 章）。
"像你本人（%）"看起来很低，或者和我听到的感觉对不上
这个百分比是拿你自己的真实录音做标尺校准过的：100% = 和你本人另一段真实录音一样像。低于 85% 的候选会被淘汰，一句话都达不到 85% 时会标出来。它是声纹模型自动打分，不是绝对精确，最终以耳朵为准。
• 页面上出现"⚠️ 这次没有可靠的声纹模型（只有简易的 MFCC），百分比只能粗略参考，也不会按 85% 自动淘汰"时，说明整合包自带的声纹模型没能用上：到 🩺 环境检查 看看有没有 ❌，按提示处理（例如点 ⬇️ 下载缺少的模型）；
• 分数普遍偏低：多半是素材少或不干净、文字没校对，按 13.1 节改进后重新训练；
• 想更客观地比较：到 ⑤ 鉴别 把你的原始录音和生成的音频放在一起打分，或者做盲听测试（第 12 章）。
「完美」档的两个版本听起来一模一样
这很正常。两个版本的文字、停顿和字幕完全一样，版本 B 只是去掉了说话时轻微的杂音；素材本来就干净时，两者几乎听不出区别。程序会比较哪个更像你的原声并标 ⭐ 推荐，分数接近时会写"两个版本几乎一样像，听哪个顺耳就用哪个"。在 最终使用哪个版本 里选一个就好，两个版本都保存在 outputs 文件夹里。
我要求生成的音频里完全没有背景音、没有底噪
已经做到了，不需要任何设置：不管哪个档位，生成的音频里只有你的声音。句子之间、开头和结尾都是绝对的数字静音，没有背景音、没有底噪；每句话首尾的杂音会被切掉并淡入淡出，不会有"咔哒"声。停顿的长短按你本人的习惯。
如果说话的过程中（句子里面）还能听到一点沙沙声，那是模型从素材里学来的：「完美」档选"版本 B：去杂音"试试；根本办法是换用更干净的素材重新训练。另外，mp3 是压缩格式，静音处可能有极小的杂讯，要绝对静音请保存为 WAV。
语速比我平时快 / 慢
程序已经自动校准了语速，拉杆在 0 就是和你原声一样。还觉得不对，就用 语速 拉杆调：往左更快、往右更慢（例如 −5 = 快 5%），点 ▶ 试听语速 先听一句。它只改快慢，不改音色和音高，建议在 −15～+15 之间。所有课都不对时，也可以在 ② 训练模型 页面点 重新挑选最佳模型，重新校准一次。
句子之间的停顿太长 / 太短
停顿的长短是按你素材里的习惯统计的。想整体调整，可以在 config.yaml 里把 pauses 改成 fixed，再修改 fixed_pauses 里的秒数（13.3 节）；个别位置用停顿标记（10.3 节）。
英文有中文口音
加入你讲英文的录音（至少 5~10 分钟），重新 ① 准备素材、② 训练。
语气太平淡，没有讲课的感觉
① 讲稿更口语化，多用问句、感叹句（10.8 节）；② 挑一条语气生动的参考音频指定使用（13.2 节）；③ 素材里多放一些你状态好、有激情的讲课录音。
声音听起来有点闷 / 有点"电音"
通常和素材质量有关：素材被压缩得很厉害、降噪太强。「完美」档可以先比较"版本 A：未去杂音"和"版本 B：去杂音"，选更自然的那个。根本办法是在 config.yaml 里把 denoise 改成 off，或者换用更清晰的原始录音，重新准备素材并训练。

15.7 其它问题

我移动了 VoiceTwin 或 GPT-SoVITS 文件夹，现在打不开了
重新运行一次 install_windows.bat，输入新的整合包路径。其它设置和 workspace 里的数据都会保留。
如何升级到新版本
见 3.9 节：下载新的压缩包，解压到 D:\ 并选择"替换目标中的文件"，再双击 install_windows.bat，输入 1。你的 workspace（素材、校对结果、生成的音频）、训练好的模型和 config.yaml 都会保留。升级好后，网页最上面的标题会显示新的版本号。
如何卸载
① 在命令提示符运行 D:\GPT-SoVITS\runtime\python.exe -m pip uninstall voicetwin；② 删除 D:\VoiceTwin 文件夹（workspace 里有你的素材和生成的音频，需要的话先备份）；③ 删除桌面图标。GPT-SoVITS 整合包不需要的话也可以整个删除。
没有网络能用吗
安装、下载缺少的预训练模型、第一次准备素材（下载识别模型），以及第一次查找错字或使用「最好」「极致」「完美」档（可能要下载检查读音用的识别模型）时需要联网。全部下载完成后，准备素材、训练、生成、鉴别都可以离线进行。

15.8 如何收集信息并求助

如果以上方法都解决不了，请收集下面这些信息再求助（例如在项目的 GitHub 页面提交 Issue），能大大加快解决速度：

  1. 环境检查结果：在网页 🩺 环境检查 页面截图（表格每行有编号，下面写着"共 N 项"）；或者在命令提示符运行 voicetwin.bat doctor，复制全部输出。
  2. 出错时的信息：红色进度条（原因 / 怎么办）的截图；再点开下面的 详细过程（出问题时可以复制给帮你的人），点右上角的复制按钮，把全部内容粘贴过去。
  3. 详细错误信息：用命令行重做出错的那一步，并在最后加上 --verbose，例如：
    voicetwin.bat narrate -v 我的声音 D:\讲稿\第1课.md --verbose
  4. 日志文件：D:\VoiceTwin\workspace\我的声音\logs 里对应的日志（附录 C 说明了每个日志的用途）。
  5. 你的电脑配置：显卡型号和显存（页面最上面的显卡状态条里就有）、Windows 版本，以及声音分身的版本号（网页标题里，例如"声音分身 VoiceTwin v0.1.6"）。
提交日志或截图前，请检查里面有没有你不想公开的信息（例如讲课内容、个人姓名、文件路径里的真实姓名）。不要上传你的素材音频或训练好的模型文件，别人拿到它们就能模仿你的声音。
