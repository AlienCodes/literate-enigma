第 1 章认识声音分身

1.1 它能帮你做什么

声音分身 VoiceTwin 是一个在你自己电脑上运行的"声音克隆"程序。它会仔细"听"你以前录好的讲课视频和录音，学会你的声音； 之后你只要把讲稿交给它，它就能用你的音色、你的语气、你的说话节奏把讲稿读出来，同时生成对应的字幕文件。

🎙️ 嗓子不舒服也能继续出课

感冒、嗓子哑、需要休息的时候，用讲稿直接生成讲课音频，课程更新不中断。

✏️ 改一句不用重录整段

录好的课程里讲错了一句话？只生成那一句替换进去，不用把整段重录一遍。

🌏 中文、英文、中英混说

支持普通话讲解、英文讲解，以及中文里夹英文术语（如 "Python 的 list comprehension"）。

📝 自动生成字幕

每次生成都会同时输出 .srt 字幕文件，直接导入剪映等剪辑软件，时间轴自动对齐。

1.2 它是怎么做到"像你"的

听起来"像不像一个人"，主要取决于三件事：音色（声音本身的质感）、语气（抑扬顿挫、提问和感叹时的语调）、 节奏（说话快慢、在哪里停顿、停多久）。声音分身把目前最好的开源技术组合起来，分别处理这三件事：

环节程序做了什么对应"像"的哪一方面
素材清理从视频里提取声音；去掉空调、电流等低频嗡嗡声；只有录音明显有噪音时才轻度降噪（降噪过猛会把你的音色一起"削掉"）；统一音量。音色干净、不失真
智能切分在你说话自然停顿的地方，把长录音切成 2~12 秒的一句一句；视频有字幕时直接按字幕切，更准确。训练数据完整准确
语音识别自动把每一句话识别成文字（中文、英文逐句自动判断），并加上标点；还能再听一遍，把可能识别错的字标成红色，方便你校对。文字与声音严格对应
质量过滤剔除识别不可靠、文字对不上、有爆音的片段；用"声纹"比对，自动剔除不是你本人的声音（例如学生提问）。模型只学你的声音
风格分析统计你的中文和英文语速、逗号 / 句号 / 段落处分别停顿多久、音高和起伏、原始录音的音量，生成你的"说话风格档案"。节奏、语气
专属训练按你的显卡显存和素材多少自动定好训练参数（显存不够时自动减小再试），用你的全部素材训练 GPT-SoVITS v2ProPlus 模型（目前开源社区里"用自己的声音训练"最成熟的方案之一，特点是更贴近整个训练素材的说话风格）。音色 + 语气 + 口音
自动挑模型训练会保存多个版本。程序留出一小部分没参加训练的你的真实录音当"考题"，让每个版本读同样的句子，和你的原声比较，选出最像你的版本。选出最像的模型
语速校准同一句话，比较"模型读用了多久"和"你本人读用了多久"，自动算出语速校正系数。快慢和你一致
多候选择优每一句话按质量档位生成多个版本（均衡 3 个、最好 5 个、极致 8 个，「完美」档每句最多试 20 次），按"像你本人（%）+ 语速 / 音高偏差 + 识别错字率"打分，只保留最好的一个；发现漏字、读错会自动重做。每一句都尽量最像
相似度百分比用你自己的真实录音做标尺：100% = 和你本人另一段真实录音一样像。每个候选、每一句、每个版本都标出"像你本人"百分之多少，低于 85% 的候选直接淘汰。看得见有多像
语气匹配疑问句用你提问时的录音做参考，感叹句用你感叹时的录音，陈述句用陈述的录音。语气
拼接句子之间、段落之间停多久，按你本人的停顿习惯；停顿处是完全静音（没有背景音、没有底噪）；最终音量调到和你原来的录音一致。节奏；音量和旧课程一致

1.3 实事求是：效果能达到什么程度

实话实说 目前世界上还没有任何技术能保证"任何人、任何一句都 100% 听不出来"。声音分身能做到的是：在素材充足、干净、文字校对过的情况下， 生成的声音和你本人非常接近，大多数听众很难分辨。

最终效果主要取决于你提供的素材。按影响从大到小：

  1. 素材时长：10 分钟能用，30 分钟以上明显更好，1~3 小时最好。
  2. 素材质量：只有你本人、正常讲课状态、背景安静的录音最好。
  3. 文字准确：识别出的文字校对过（程序会把可能错的字标红，第 7 章），模型就不会学到"口误"。
  4. 生成时的质量档位：显卡正常、显存 8GB 以上时，默认就是最高的「完美」档。档位越高越慢、越稳定，但它只是让出错更少、挑得更准，不会超过模型训练出来的水平。

另外几件事也要先说清楚：

  • "像你本人"百分比是自动打分：它用你自己没参加训练的真实录音做标尺，100% 表示和你本人另一段真实录音一样像。它能帮你快速比较、找出不够像的句子，但不是绝对精确，最终以耳朵为准。
  • 低于 85% 的会被淘汰：每句话的几个候选里，低于 85% 的直接不要；如果一句话最好的候选也不到 85%，会标出"低于 85%，建议重新生成或改写这一句"。 如果电脑上只能用简易的打分方法，百分比只能粗略参考，这时程序不会淘汰任何候选，页面上会用 ⚠️ 提示你。
  • 停顿是完全静音：生成的音频里只有你的声音，句子之间的停顿是完全静音，没有背景音和底噪。停多长按你本人的习惯，但不会去模仿旧录音里的环境声音。
  • 「完美」档会做两个版本：版本 A 未去杂音、版本 B 去杂音。两个版本的文字、停顿和字幕完全一样，B 只是多去掉一点轻微的杂音。程序会推荐更像你原声的那个（标 ⭐ 推荐），最后用哪个由你听了再决定。

第 12 章会教你用 ④ 试试像不像（可选） 给音频打分、用 ⑤ 鉴别 给多个音频排名，以及用"盲听测试"让别人来判断。

1.4 整体流程一览

整个使用过程分为"安装一次"和"日常使用"两部分。下面方框里的 ①②③ 就是网页上同名的标签页：

安装下载本程序和 GPT-SoVITS 整合包，运行安装程序只需一次 · 约 30~60 分钟
→
① 准备素材放入你的讲课视频，程序自动切分、识别、过滤约 10~40 分钟
→
② 训练模型按你的显卡自动设置，训练完自动挑出最像的约 30~90 分钟
→
③ 生成讲课音频粘贴讲稿，点"生成"，得到音频 + 字幕日常使用 · 讲稿越长、档位越高越慢

安装、①、② 只需要做一次（以后增加了新素材，可以再做一次 ①② 让声音更像）。之后每次出课，只需要做 ③。 想确认像不像，还可以用 ⑤ 鉴别（可选）让电脑打分排名，或者做一次观众盲听测试。

一路上你会经常看到两样东西 显卡状态条：网页最上面一直显示。绿色"✅ 显卡正常"表示训练和生成都能用上显卡；红色"❌ 显卡没有正常工作"时，照着条里的"怎么办"做（多数是装显卡驱动并重启电脑，见 2.4 节）。
进度条：准备素材、训练、生成等每个要等的步骤都有进度条，写着做到百分之几、第几步、已经用了多久、预计几点完成。 绿色 = 正常工作；黄色 = 好几分钟没有新进度；红色 = 出问题停下了，会写"原因"和"怎么办"；走到 100% = 全部完成。关掉或刷新网页不会打断正在做的事。

1.5 几个常用名词

名词意思

质量档位生成时每句话试几次、检查得多严格：快速 / 均衡 / 最好 / 极致 / 完美，越往后越慢、越稳定。程序会按你的显卡自动选好。
像你本人（%）程序用"声纹模型"衡量生成的声音像不像你，并用你自己的真实录音校准：100% = 和你本人另一段真实录音一样像。低于 85% 的候选会被淘汰。这是自动打分，最终以耳朵为准。
字幕（srt）带时间轴的文字文件，剪辑软件可以直接导入，显示在视频下方。

2.2 查看显卡型号和显存

  1. 同时按下键盘上的 Ctrl + Shift + Esc，打开"任务管理器"。
  2. 如果窗口很小、只有几个程序名，点左下角的 详细信息。
  3. 点窗口上方（Windows 11 在左侧）的 性能。
  4. 在左侧列表里找到 GPU 0 或 GPU 1，逐个点开看。
  5. 看右上角的显卡名称，以及下方的 专用 GPU 内存：
    • 名称里有 NVIDIA（例如 NVIDIA GeForce RTX 3060），并且专用 GPU 内存 ≥ 6.0 GB：✅ 符合要求。
    • 名称是 Intel 或 AMD：这是非 NVIDIA 显卡，训练会很慢，请看上面的黄色提示。
装好以后，看显卡更简单 装好声音分身、打开程序后，网页最上面一直有一条显卡状态条（图 2-1）：
  • 绿色 "✅ 显卡正常"：后面写着显卡型号、显存大小和现在还可用的显存，一切正常。
  • 黄色 "⚠️ 显卡能用，但……"：能用，但要留意（例如显存比较小，或者可用显存不多），条里会写原因和怎么办。
  • 红色 "❌ 显卡没有正常工作"：训练用不上显卡，会非常慢。照着条里的"怎么办"做（多数是按 2.4 节装最新驱动并重启电脑），再点右边的 🔄 重新检查显卡。

2.3 查看硬盘剩余空间

  1. 双击桌面上的"此电脑"（或按 Win + E 打开文件资源管理器，点左侧的"此电脑"）。
  2. 在"设备和驱动器"里看每个盘下面的"可用空间"，选一个可用空间大于 30GB 的盘。
  3. 本手册统一以 D 盘为例。如果你的电脑没有 D 盘，或 D 盘空间不够，下面所有 D:\ 都换成你选的盘，例如 E:\。
尽量不要放在 C 盘（系统盘）：C 盘空间一般比较紧张，而且系统文件夹的权限限制可能导致安装失败。

2.4 更新显卡驱动（建议）

显卡驱动太旧，训练时可能会报错。建议更新到最新版本：

  1. 用浏览器打开 NVIDIA 驱动下载页：https://www.nvidia.cn/drivers/lookup/
  2. 按你的显卡型号选择（例如：GeForce → GeForce RTX 30 Series → GeForce RTX 3060 → Windows 11），点"查找"。
  3. 下载最新的"Game Ready"或"Studio"驱动，双击安装，一路选"同意并继续" → "精简安装"。
  4. 安装完成后重启电脑。
如果电脑上装了 "NVIDIA App" 或 "GeForce Experience"，也可以直接在里面点"驱动程序" → "检查更新"。
RTX 50 系列显卡（5060 / 5070 / 5080 / 5090）除了装最新驱动，还要用文件名带 nvidia50 的 GPT-SoVITS 整合包（3.2 节），否则训练用不上显卡。

以后如果声音分身网页最上面变成红色"❌ 显卡没有正常工作"，处理方法也一样：按上面的步骤装好最新驱动，重启电脑，再打开程序点 🔄 重新检查显卡。

2.5 安装解压软件 7-Zip

GPT-SoVITS 整合包是 .7z 格式的压缩包，需要用 7-Zip 解压（免费软件）：

  1. 打开 https://www.7-zip.org/
  2. 在页面最上面的下载表格里，点第一行（64-bit Windows x64）对应的 Download。
  3. 双击下载好的安装程序（文件名类似 7z2409-x64.exe），点 Install，完成后点 Close。
Windows 11 自带解压 7z 的功能，但遇到大文件时 7-Zip 更稳定、更快，建议还是安装。
