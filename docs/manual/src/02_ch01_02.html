第 1 章认识声音分身

1.1 它能帮你做什么

声音分身 VoiceTwin 是一个在你自己电脑上运行的"声音克隆"程序。它会仔细"听"你以前录好的讲课视频和录音，学会你的声音； 之后你只要把讲稿交给它，它就能用你的音色、你的语气、你的说话节奏把讲稿读出来，同时生成对应的字幕文件。

🎙️ 嗓子不舒服也能继续出课

感冒、嗓子哑、需要休息的时候，用讲稿直接生成讲课音频，课程更新不中断。

✏️ 改一句不用重录整段

录好的课程里讲错了一句话？只生成那一句替换进去，音色和前后完全一致。

🌏 中文、英文、中英混说

支持普通话讲解、英文讲解，以及中文里夹英文术语（如 "Python 的 list comprehension"）。

📝 自动生成字幕

每次生成都会同时输出 .srt 字幕文件，直接导入剪映等剪辑软件，时间轴自动对齐。

1.2 它是怎么做到"像你"的

听起来"像不像一个人"，主要取决于三件事：音色（声音本身的质感）、语气（抑扬顿挫、提问和感叹时的语调）、 节奏（说话快慢、在哪里停顿、停多久）。声音分身把目前最好的开源技术组合起来，分别处理这三件事：

环节程序做了什么对应"像"的哪一方面
素材清理从视频里提取声音；去掉空调、电流等低频嗡嗡声；只有录音明显有噪音时才轻度降噪（降噪过猛会把你的音色一起"削掉"）；统一音量。音色干净、不失真
智能切分在你说话自然停顿的地方，把长录音切成 3~12 秒的一句一句；视频有字幕时直接按字幕切，更准确。训练数据完整准确
语音识别自动把每一句话识别成文字（中文、英文逐句自动判断），并加上标点。文字与声音严格对应
质量过滤剔除识别不可靠、文字对不上、有爆音的片段；用"声纹"比对，自动剔除不是你本人的声音（例如学生提问）。模型只学你的声音
风格分析统计你的中文和英文语速、逗号 / 句号 / 段落处分别停顿多久、音高和起伏、原始录音的音量，生成你的"说话风格档案"。节奏、语气
专属训练用你的全部素材训练 GPT-SoVITS v2ProPlus 模型（目前开源社区里"用自己的声音训练"最成熟的方案之一，特点是更贴近整个训练素材的说话风格）。音色 + 语气 + 口音
自动挑模型训练会保存多个版本。程序留出一小部分没参加训练的你的真实录音当"考题"，让每个版本读同样的句子，和你的原声比较，选出总分最高的版本。选出最像的模型
语速校准同一句话，比较"模型读用了多久"和"你本人读用了多久"，自动算出语速校正系数。快慢和你一致
多候选择优每一句话生成 3~5 个版本，按"声纹相似度 + 语速 / 音高偏差 +（可选）识别错字率"打分，只保留最好的一个；发现漏字、读错会自动重试。每一句都尽量最像
语气匹配疑问句用你提问时的录音做参考，感叹句用你感叹时的录音，陈述句用陈述的录音。语气
自然拼接句子之间、段落之间按你本人的停顿习惯留空（带自然的长短变化），最终音量调到和你原来的录音一致。节奏；能无缝剪进旧课程

1.3 实事求是：效果能达到什么程度

实话实说 目前世界上还没有任何技术能保证"任何人、任何一句都 100% 听不出来"。声音分身能做到的是：在素材充足、干净、文字校对过的情况下， 生成的声音和你本人非常接近，大多数听众很难分辨。

最终效果主要取决于你提供的素材。按影响从大到小：

  1. 素材时长：10 分钟能用，30 分钟以上明显更好，1~3 小时最好。
  2. 素材质量：只有你本人、正常讲课状态、背景安静的录音最好。
  3. 文字准确：识别出的文字校对过，模型就不会学到"口误"。
  4. 生成时的质量档位：正式课程用 best 档，每句 5 个候选自动择优。

第 12 章会教你用"评估"功能打分，以及用"盲测"的方法客观地检验效果。

1.4 整体流程一览

整个使用过程分为"安装一次"和"日常使用"两部分：

① 安装下载本程序和 GPT-SoVITS 整合包，运行安装程序只需一次 · 约 30~60 分钟
→
② 准备素材放入你的讲课视频，程序自动切分、识别、过滤约 10~40 分钟
→
③ 训练用你的素材训练专属模型，自动挑出最像的约 30~90 分钟
→
④ 生成粘贴讲稿，点"生成"，得到音频 + 字幕日常使用 · 几十秒到几分钟

①②③ 只需要做一次（以后增加了新素材，可以再做一次 ②③ 让声音更像）。之后每次出课，只需要做 ④。

1.5 几个常用名词

名词意思
素材你以前录的讲课视频或音频，程序从里面学习你的声音。
片段程序把长录音切成的一小段一小段（每段 3~12 秒，大多是一句话）。
声音名称你给这个声音起的名字，例如"我的声音"。一个声音对应一套素材和模型，以后每次使用都选这个名字。
参考音频程序从你的素材里自动挑出的、最有代表性的几句话。生成时模型会参考它们的语气。
训练让模型反复"听"你的素材、学习你的声音的过程，需要显卡，耗时较长。
模型训练的结果，可以理解为"你的声音的数字副本"，保存在 GPT-SoVITS 文件夹里。
生成（合成）用训练好的模型把文字读出来。
GPT-SoVITS一个开源的声音克隆项目，声音分身用它来训练和生成声音。
整合包GPT-SoVITS 官方为 Windows 用户打包好的版本，里面已经装好了所有复杂组件，解压就能用。
显存显卡自带的内存。训练需要显存，6GB 以上可以训练，越大越快。
声纹相似度程序用"声纹模型"衡量两段声音像不像同一个人，数字越接近 1 越像（0.86 以上可以认为非常像）。
字幕（srt）带时间轴的文字文件，剪辑软件可以直接导入，显示在视频下方。

2.2 查看显卡型号和显存

  1. 同时按下键盘上的 Ctrl + Shift + Esc，打开"任务管理器"。
  2. 如果窗口很小、只有几个程序名，点左下角的 详细信息。
  3. 点窗口上方（Windows 11 在左侧）的 性能。
  4. 在左侧列表里找到 GPU 0 或 GPU 1，逐个点开看。
  5. 看右上角的显卡名称，以及下方的 专用 GPU 内存：
    • 名称里有 NVIDIA（例如 NVIDIA GeForce RTX 3060），并且专用 GPU 内存 ≥ 6.0 GB：✅ 符合要求。
    • 名称是 Intel 或 AMD：这是非 NVIDIA 显卡，训练会很慢，请看上面的黄色提示。

2.3 查看硬盘剩余空间

  1. 双击桌面上的"此电脑"（或按 Win + E 打开文件资源管理器，点左侧的"此电脑"）。
  2. 在"设备和驱动器"里看每个盘下面的"可用空间"，选一个可用空间大于 30GB 的盘。
  3. 本手册统一以 D 盘为例。如果你的电脑没有 D 盘，或 D 盘空间不够，下面所有 D:\ 都换成你选的盘，例如 E:\。
尽量不要放在 C 盘（系统盘）：C 盘空间一般比较紧张，而且系统文件夹的权限限制可能导致安装失败。

2.4 更新显卡驱动（建议）

显卡驱动太旧，训练时可能会报错。建议更新到最新版本：

  1. 用浏览器打开 NVIDIA 驱动下载页：https://www.nvidia.cn/drivers/lookup/
  2. 按你的显卡型号选择（例如：GeForce → GeForce RTX 30 Series → GeForce RTX 3060 → Windows 11），点"查找"。
  3. 下载最新的"Game Ready"或"Studio"驱动，双击安装，一路选"同意并继续" → "精简安装"。
  4. 安装完成后重启电脑。
如果电脑上装了 "NVIDIA App" 或 "GeForce Experience"，也可以直接在里面点"驱动程序" → "检查更新"。

2.5 安装解压软件 7-Zip

GPT-SoVITS 整合包是 .7z 格式的压缩包，需要用 7-Zip 解压（免费软件）：

  1. 打开 https://www.7-zip.org/
  2. 在页面最上面的下载表格里，点第一行（64-bit Windows x64）对应的 Download。
  3. 双击下载好的安装程序（文件名类似 7z2409-x64.exe），点 Install，完成后点 Close。
Windows 11 自带解压 7z 的功能，但遇到大文件时 7-Zip 更稳定、更快，建议还是安装。
