# 每篇写作流程（2026-10-01 定：质量第一，兼顾效率）

调度：一律由总编辑（我）直接派人，能并行的同时派（三位写手同时写，三位评审同时审）。不用自动流水线，因为它一次只跑 2 人，太慢。

从流水线保留的规矩：
1. 每个环节的指令里都附「历届评审问题清单」：时间写到月、无引语、少人名、句长不超过 32 词、指代清楚、对冲诚实、数字与措辞一致、搭配自然、不为加粗扭曲句子、结尾句式不与前文重复、中文保留全部对冲、(english) 小写、速查表按段序排列。
2. 评审至少两轮。首审后由总编辑一次性合并三人的修改；复审时评审先读自己上一轮报告，逐条核对是否已改。三人都达到 95 分、且没有硬伤，才能定稿。
3. 评审的修改意见一律写成「原文 → 新文」，并附中文和速查表的同步改法，以及改后的词数。
4. 合并稿词数控制在 252–262，给评审修改留出余量；重点词 54 个以上，留出余量。

从直接派人方式保留的优势：
- 每一步交稿后我都亲自检查。发现问题（如风级用词、中文漏了对冲、参考文件路径不对）当场纠正，不等最后一起处理。
- 小改动我直接改，并用 draft_check 验证，不再为此另派一轮人。

## 第四位评审：总编辑本人（用户 2026-10-01 定）
- 每一轮评审，我和三位评审同时审稿。我按评分表独立打分，写入 rewrite/NN/review-总编辑-rN.md，同样要求 ≥95 分且无硬伤。
- 我重点审三件事：全篇是否达到顶尖水平（开头抓不抓人、反转立不立得住、结尾有没有余味）；三位评审之间有没有互相冲突的意见；有没有三个人都没发现的问题。
- 定稿条件改为：四位评审全部 ≥95，且都没有硬伤。

## 双总编辑会签（用户 2026-10-01 定）
质量由我（总编辑本人）和英文总编辑评审**共同把关**，不由任何一方单独说了算：
1. **互审意见**：每轮评审结束后，我把自己的评审意见交给英文总编辑，英文总编辑也审我的意见，逐条表态（同意、反对或修改）。我同样逐条回应对方的意见。
2. **分歧共同裁决**：两人意见冲突的地方，由两人各自给出理由，按"更准确、更地道、更合史实"的标准商定。商定不了的，取更保守、更不易出错的写法，并在汇报中告诉用户。
3. **定稿会签**：除四位评审全部 ≥95、零硬伤外，还要我和英文总编辑都写明"同意定稿"，才能上传。
4. **不额外拖慢**：互审放在复评同一轮里完成，不单独加一轮。

## 评分记录必须随稿上传（用户 2026-10-01 定）
- 每篇定稿上传时，同时上传 `新版定稿/评分记录/NN-评分记录.md`，内容包括：最终分数表、各轮分数总表、逐轮逐人扣分明细（按评分表 10 项）、主要问题及解决办法、会签结果、定稿说明。
- README 总表每行链接到该篇的评分记录。

## 合稿纪律（第20篇教训）
合稿或改稿时，**不得为凑重点词替换事实性词语**（如把"驾驶经验"换成"里程"）。凑词只能换修饰性、非事实性的词，并在交评审前对照史实表复核一遍。
