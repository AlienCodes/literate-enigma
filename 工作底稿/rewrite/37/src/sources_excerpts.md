# 第37篇来源摘录（检索摘要，不得直接引用）
S1 Wikipedia/Griffith Institute：1922年11月4日，卡特的埃及工人发现凿入岩床的台阶顶部（帝王谷）。11月26日，卡特与卡纳冯、伊芙琳夫人、助手卡伦德在场，在门道左上角开了一个小孔。
S2 Griffith Institute/Wikipedia：卡纳冯1923年3月被蚊子叮咬，叮咬处感染（刮胡子时割破，history.co.uk 称在脸颊），丹毒、血液中毒，后转肺炎；1923年4月5日死于开罗。
S3 History Today / Manchester 大学：《泰晤士报》独家报道协议令大批记者无事可报，各报转而找"专家"评论，包括柯南·道尔等通俗作家。1923年3月，畅销小说家玛丽·科雷利致函报纸，警告闯入封闭陵墓者必遭严惩；几天后卡纳冯病逝，科雷利被奉为"预言者"，传说由此诞生。
S4 history.co.uk / hoaxes.org：报道称卡纳冯死时开罗全城灯灭、他在英国家中的狗嚎叫而死；开罗当时几乎天天停电。墓中从未发现诅咒铭文，所谓"死神之翼"刻文纯属捏造；此后几年考古队成员陆续去世，使故事延续。
S5 BMJ 2002年12月21日，Mark R. Nelson《木乃伊的诅咒：历史队列研究》：卡特记录的44名当时在埃及的西方人，25人"暴露"；暴露者平均死亡年龄70岁，未暴露者75岁，差异无统计学意义；结论：无证据支持诅咒存在。
S6 historyonthenet/biography.com：卡特1939年3月2日死于淋巴瘤，终年64岁。1923年2月16日打开墓室封门。
