## 0 摘要
- 1922年11月4日帝王谷发现台阶 → 11月26日卡特在卡纳冯面前凿开小孔，看到满室珍宝，轰动世界 → 卡纳冯与《泰晤士报》签独家协议，其他记者无料可写，转向耸动故事 → 1923年3月畅销小说家科雷利公开警告：闯入封闭陵墓者必遭严惩 → 1923年3月卡纳冯被蚊子叮咬、刮胡子割破、感染（血液中毒），转肺炎，4月5日死于开罗；"诅咒"传说爆发：报称开罗全城灯灭、他在英国的狗同时死去——但开罗当时几乎天天停电；墓中从未发现诅咒铭文 → 2002年12月《英国医学杂志》研究：44名当时在埃及的西方人，25人"暴露"，平均死亡年龄70岁，未暴露者75岁，差异无统计学意义 → 打开墓室的卡特本人1939年3月才去世，终年64岁。
- **论点**：传说靠竞争的报纸、一位小说家和一次巧合的死亡长成；数据显示进墓者并未早死。

## 4 禁区
1. 不渲染恐怖；"灯灭""狗死"必须是报道/传说语气（reportedly / it was claimed），且紧跟停电常见的事实。
2. 对冲每句至多一个。不说"科学证明诅咒不存在"，写"found no evidence"。
3. 不为凑重点词改事实或用不准搭配。
4. 无引语、无问号叹号、无 &、句首无阿拉伯数字；书报名不加星号。
