# 第38篇来源摘录（检索摘要，不得直接引用）
S1 NPR/Wikipedia：1930年2月18日，克莱德·汤博在亚利桑那州弗拉格斯塔夫附近洛厄尔天文台比对玻璃底片时发现冥王星；1930年3月13日公布；名字由11岁英国女孩维尼夏·伯尼提议（冥界之神），1930年5月1日正式采用。
S2 Wikipedia/Caltech：厄里斯（Eris）2005年1月由迈克·布朗团队在帕洛马天文台照片中发现，同年稍后确认；起初看来比冥王星大，NASA 一度称之为"第十大行星"；后测其质量比冥王星大27%，但体积略小。此事及更多同类天体可能被发现，促使国际天文学联合会首次给"行星"下定义。
S3 IAU：第26届大会2006年8月14–25日在布拉格举行；8月24日通过决议：行星须绕日运行、近似球形、并已清空其轨道附近区域；冥王星、厄里斯、谷神星归为矮行星，太阳系行星减为8颗。
S4 CBC/space.com：仅424名留到最后一天的天文学家参加投票（学会约1万名会员）；新视野号负责人艾伦·斯特恩带头发起数百名专业天文学家联署反对。
S5 美国方言学会：2007年1月宣布 plutoed（"被冥王星了"，即被降级、贬值）为2006年度词汇。新墨西哥州（2007年）与伊利诺伊州（2009年）通过决议称冥王星为行星；伊利诺伊州定3月13日为"冥王星日"。
S6 Wikipedia/NASA：新视野号2006年1月19日发射（降级前约7个月），飞行9年半；2015年7月14日首次飞掠冥王星；照片显示巨大心形平原，团队以汤博之名命名为 Tombaugh Regio。飞船载有汤博（1997年去世）的少量骨灰。冥王星直径约2,377公里，比月球（3,474公里）小。
