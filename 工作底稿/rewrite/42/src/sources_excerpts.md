# 第42篇来源摘录（检索摘要，不得直接引用）
S1 Britannica/NASA：1990年4月24日，哈勃空间望远镜由"发现号"航天飞机发射升空。
S2 Physics Today/space.com：1990年6月（NASA 于6月27日宣布），升空几个月后，科学家发现主镜存在球面像差，望远镜传回的图像模糊；一台造价15亿美元的望远镜看不清，必须纠正。
S3 Wikipedia/Physics Today：主镜外缘被磨平了约2.2微米，使光线无法正确聚焦；误差极小，约为人类头发丝宽度的五十分之一。根源是检测主镜形状的"反射式零位校正器"中一块场镜位置偏了约1.3毫米。地面测试时，珀金-埃尔默公司另一台独立的"折射式零位校正器"给出了不同结果，但工程师和 NASA 项目经理没有追查这一差异，认为折射式的不如反射式准确，相信了后者。
S4 ESA/NASA：主镜无法在太空中修复，于是在望远镜上加装冰箱大小的 COSTAR（矫正光学空间望远镜轴向替换装置），像给人戴眼镜一样矫正视力：一组装在机械臂上的小镜子在光线到达科学仪器之前截住并矫正像差。同时换上一台新的主相机（WFPC2）。
S5 Wikipedia/NASA（STS-61）：首次哈勃维修任务，"奋进号"航天飞机1993年12月2日从肯尼迪航天中心发射，任务约11天；7名宇航员，两人一组完成5次太空行走，共35小时28分钟；安装新主相机和 COSTAR，并换装新的太阳能电池板，恢复了望远镜的视力。
S6 ESA Hubble（COSTAR 与第四次维修任务页面）：COSTAR 在2009年第四次维修任务中被拆下；哈勃初次部署之后安装的所有仪器都自带矫正光学，因此不再需要 COSTAR。主镜无法在太空修复（S4），哈勃从未返回地面，主镜本身始终带着这一误差。
