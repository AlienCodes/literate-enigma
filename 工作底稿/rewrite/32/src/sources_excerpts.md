## Myths / nuances
- Pitchfork was not caught by the screening itself: he evaded it via Kelly's substitute sample; a tip-off from an overheard pub conversation led to arrest; DNA then confirmed the match (S3, S4).
- First DNA *exoneration* (Buckland) preceded first conviction.
- Not the first-ever DNA use in court/crime: some cite Robert Melias (Nov 1987, rape) as first conviction via DNA overall; Pitchfork = first for murder. Use "first murder conviction".
- "Genetic fingerprint"/"DNA fingerprint" was Jeffreys's own term; modern term "DNA profiling".
