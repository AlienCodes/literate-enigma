## 2 质量要求
- 开篇即具体场景（1984 年，32 岁的马歇尔在弗里曼特尔医院，把一杯培养了细菌的肉汤一饮而尽）。
- 叙事推进：喝下去 → 回到起点：主流认为溃疡由压力、辛辣食物、胃酸引起，细菌活不过胃酸 → 沃伦在胃活检中看到螺旋状细菌 → 培养一再失败，1982 年复活节假期培养皿多放了几天，长出菌落 → 1983 年论文被评为当年投稿最差的 10% → 猪实验失败 → 自己喝 → 几天后呕吐、口臭、疲惫，约十天后胃镜显示胃炎（不是溃疡！），细菌被培养出来 → 妻子催他吃抗生素，治好 → 2005 年诺贝尔奖 → 有力、字面属实的结尾（不说教）。
- 生动、精确；医学措辞严谨：他得的是胃炎（溃疡前兆），不是溃疡；不要写"拿不到人体试验许可"（来源未证实）。

## 3 史实表（只用这些；来源 src/sources_excerpts.md S1–S5）

|---|---|
| T1 | 皇家珀斯医院病理学家罗宾·沃伦在胃炎患者的胃活检样本中看到弯曲的螺旋状细菌；年轻医生巴里·马歇尔加入研究。S1 |
| T2 | 培养一再失败；1982 年复活节假期，培养皿在培养箱里放了约五天（平时两天就丢弃），终于长出菌落，后命名为幽门螺杆菌。S1 |
| T3 | 主流观点认为溃疡由压力、辛辣食物和过多胃酸引起，细菌被认为无法在胃酸中存活；1983 年他们向澳大利亚胃肠病学会投稿，被评为当年投稿中最差的 10%。S2 |
| T4 | 1984 年，在感染小猪失败后，32 岁的马歇尔（弗里曼特尔医院）喝下用两个培养皿的细菌刮进牛肉汤调成的液体。几天内他开始呕吐、口臭、疲惫；约十天后胃镜显示胃炎（胃黏膜发炎，溃疡的前兆），并从他胃中培养出该菌。他得的是胃炎，不是溃疡。S3 |
| T5 | 在妻子催促下他服用抗生素，清除了感染；此后溃疡可用抗生素治疗。S4 |
| T6 | 2005 年，马歇尔与沃伦因发现幽门螺杆菌及其在胃炎和消化性溃疡中的作用，获诺贝尔生理学或医学奖。S5 |
