# 第39篇来源摘录（检索摘要，不得直接引用）
S1 AP / National Geographic / Boston Globe（2016年4月13–14日）：新西兰国家水族馆（内皮尔）的章鱼 Inky 等天黑、员工下班后，从水箱顶部网罩的一道小缝挤出，滑下约2米到地面，径直爬过房间到一个排水口；身体约橄榄球大小，伸展后挤进洞口，沿约50米长的管道回到太平洋。只留下一道黏液痕迹，员工据此还原逃跑路线。事发约三个月前（约2016年初），直到2016年4月市议会传播经理听说后才公开，随即成为全球新闻。
S2 Wikipedia（Inky）：Inky 是一只普通新西兰章鱼，2014年被渔民在内皮尔港以北约半公里的龙虾笼中发现，此后住在水族馆，2016年逃走。
S3 ScienceAlert/OIST 等：章鱼约有5亿个神经元，其中约三分之二在腕足里，每条腕约4,000万个；腕足能在一定程度上独立"尝"、感知和反应。
S4 Cephalopod Page / EarthSky：章鱼没有骨骼和外壳，唯一的硬质部分是喙，能钻过和喙差不多大的孔，许多章鱼只需约一英寸（2.5厘米）。
S5 西雅图水族馆：一只巨型太平洋章鱼打开螺旋盖罐子，第一次用15分钟，之后平均约2分钟。
S6 Anderson 等，2010年，《应用动物福利科学杂志》：8只巨型太平洋章鱼在两周内分别接触两名陌生人，一人喂食，一人用带刺毛的棍子触碰；两周后，章鱼对两人的体色斑纹与动作明显不同——能认出不同的人。
S7 剑桥意识宣言，2012年7月7日：包括所有哺乳动物、鸟类及章鱼在内的许多动物具备产生意识的神经基础。
S8 LSE 报告（2021年11月）：综述300多项研究，建议英国动物福利法将所有头足类（章鱼、鱿鱼、乌贼）和十足类甲壳动物视为有感知的动物；《动物福利（感知）法2022》2022年4月28日获御准，涵盖章鱼与龙虾等无脊椎动物。
