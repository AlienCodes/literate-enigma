# 第44篇来源摘录（检索摘要，不得直接引用）
S1 EBSCO/CBS：1985年4月23日，可口可乐公司宣布改变已有99年历史的原配方，换成更甜的新配方，公众称之为"新可乐"（New Coke）。公司此前做了近20万次盲测，结果一致显示新配方胜过原版可乐和百事可乐。
S2 Wikipedia/Damn Interesting：此前，百事可乐在美国各地商场设"百事挑战"摊位，让路人品尝两杯（罐）不标品牌的可乐并说出偏好；虽然各地数字不一，品尝者一般更常选百事。（市场份额具体数字说法不一——不写）
S3 Mental Floss/Chowhound：改配方后，公司消费者热线每天接到约1,500个电话，而改配方前每天约400个，几乎全是抱怨；亚特兰大总部收到成千上万封信和电话。出现有组织的抗议团体和抢购囤积原版可乐的现象。
S4 Mental Floss：盖伊·马林斯（Gay Mullins）带头组织抗议（"美国老可乐饮用者"团体），1985年6月在美国地区法院提起集体诉讼，要求禁止用原版可乐那样的包装销售新可乐；一周后法院驳回。
S5 Damn Interesting 等：百事可乐首席执行官给员工放了一天假以示庆祝，认为可口可乐终于"认输"。
S6 EBSCO/CBS/ABC：仅79天后，1985年7月11日，公司恢复原配方，命名为"可口可乐经典"（Coca-Cola Classic）上市。ABC 电视台打断下午播出的肥皂剧插播这一消息；它成为两大电视网新闻的头条，几乎登上所有主要报纸的头版。
