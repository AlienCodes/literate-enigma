# 第40篇来源摘录（检索摘要，不得直接引用）
S1 Wikipedia（AlphaGo / Fan Hui）：2015年10月，AlphaGo 以5:0击败欧洲冠军樊麾，首次在19×19全尺寸棋盘、不让子的条件下战胜人类职业棋手。最初的训练数据来自网络围棋服务器上强业余棋手的对局，此后与自己对弈数千万盘进行训练。
S2 Wikipedia（Lee Sedol）：截至2016年2月，李世石拥有18个国际冠军头衔，仅次于李昌镐（21个）。2016年3月在首尔与 AlphaGo 进行五番棋，1:4落败；这是计算机围棋程序首次在不让子条件下战胜九段职业棋手。
S3 BritGo / 多个来源：第二局（2016年3月10日），AlphaGo 第37手在第五线"肩冲"，位置偏到一侧；解说员称这是很奇怪的一手，有人认为是失误。AlphaGo 团队事后用诊断工具查询，AlphaGo 估算人类棋手下出这一手的概率只有万分之一。李世石离开对局室，约12至15分钟后才回来下第38手（各来源说法不一）。李世石后来称这一手"有创造性、很美"（不得直接引用）。
S4 Korea Herald 等：第四局（2016年3月13日），李世石获胜，其第78手是转折点，许多职业棋手称之为"神之一手"。DeepMind 团队负责人称，人类职业棋手下出这一手的概率同样约为万分之一。AlphaGo 最终以4:1赢得五番棋。
S5 Wikipedia/多家媒体：2019年11月，李世石宣布退役，称由于人工智能日益占据主导，他再也不可能成为围棋第一人，并把 AI 称作"无法被击败的存在"（不得直接引用）。
S6 常见说法：围棋可能的局面数比宇宙中的原子还多。
