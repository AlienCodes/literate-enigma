# 切换到新管（接锁后一次推送做完）

前提：第七棒交出改门锁；主会话已把“停用 8 套看门机制”的用户原话写进 用户同意记录。

1. `cp -r 新管 视频/工具/新管`（新管里的程序自动认出 视频/工具 是检查程序目录）。
2. `python3 视频/工具/新管/切换.py 视频/工具 --停用`：给 交付核查、草稿声音、快速重建核查、生成文本、推送两仓库 打 13 处一行补丁，写 管道.json {"看门":"停用"}。
   要回到旧做法只改 管道.json 为 {"看门":"启用"}（补丁都读这个开关）。
3. 提交前钩子（主会话批准后改，K16 闸门不许会话自己改）：看门停用时只跑 `python3 视频/工具/新管/印章.py`，不再跑 会话开工 --提交前、规则执行核查。
   开工钩子：看门停用时只打印 写稿须知.md 的路径。
4. `python3 视频/工具/新管/原话存档.py --写入 CLAUDE.md 视频/用户原话.md`，再 `cp 视频/工具/新管/CLAUDE.一页.md CLAUDE.md`；
   `python3 视频/工具/新管/原话存档.py --查 <旧 CLAUDE.md> 视频/用户原话.md` 必须 0 段丢失。
5. 在出片工作目录跑 `python3 视频/工具/新管/快测.py`（全过才盖印章），提交，用老的全量链推最后一次。
6. 之后每篇：写 genNN → `bash 视频/工具/新管/做.sh NN` → 用户说定稿 → `bash 视频/工具/新管/定稿.sh NN`。
   全量门变异改为每周后台体检（推请求.py 门变异），不拦人。

不变的：所有检查程序（踩坑核查、译文核查、check_all、读音核对、交付核查的全部声音和画面检查、出片守门、定稿视频核对）、出片程序、钩子里的行为闸门（不许 --no-verify、发文件一次一个、不派子代理）。
